20. 有效的括号 简单

标记本题：
给定一个只包含 ( ) [ ] { } 的字符串 s，判断括号是否有效：左括号必须由相同类型的右括号闭合，且闭合顺序正确。
示例：输入 s = "()[]{}" → 输出 true 输入 s = "(]" → 输出 false 输入 s = "([)]" → 输出 false

解题思路

先想清楚两个问题：

Q1：为什么用栈？括号配对是「最近未闭合的左括号先被匹配」的后进先出关系，栈是天然结构。用哈希表存「右括号 → 对应左括号」的映射，配对判断一行搞定。

Q2：什么情况立即判无效、什么情况看最后结果？遍历时遇左括号入栈；遇右括号立刻检查：栈空（没人跟它配）或栈顶不是对应左括号，当场返回 false。遍历结束后还要看栈是否为空——非空说明有左括号没被闭合，也是 false。

照着写的 5 步：

① 长度为奇数直接返回 false（必无法两两配对）；
② 建映射表：')'→'('、']'→'['、'}'→'{'，再建一个空栈；
③ 遍历每个字符 c：c 在映射表里（是右括号）→ 若栈空或弹出的栈顶 ≠ 对应左括号，返回 false；
④ 否则 c 是左括号，入栈；
⑤ 遍历结束返回 stack.isEmpty()。

易错点：弹栈前必须先判栈空（是 stack.isEmpty() 检查在前，不是先 pop 再判断）；最后返回栈是否为空不是直接 return true（如 "(((" 会漏判）；映射表存的是右括号到左括号，不是左到右（这样才能用 containsKey 区分左右括号）。

s = "([)]"

操作         栈（右侧为栈顶）   结果
读 '('  → 入栈      [(]
读 '['  → 入栈      [(, []
读 ')'  → 查表需 '('，弹栈得到 '['
          '[' ≠ '(' → 返回 false ✗

---------------------------------

s = "()[]{}" 的完整过程：

操作         栈（右侧为栈顶）   结果
读 '('  → 入栈      [(]
读 ')'  → 弹出 '(' 配对成功    []
读 '['  → 入栈      [[]
读 ']'  → 弹出 '[' 配对成功    []
读 '{'  → 入栈      [{]
读 '}'  → 弹出 '{' 配对成功    []
遍历结束，栈空 → 返回 true ✓

代码（Java）

class Solution {
    public boolean isValid(String s) {
        // ① 奇数长度必然无效，提前剪枝
        if (s.length() % 2 == 1) return false;
        // ② 映射表：右括号 → 对应左括号；栈存等待配对的左括号
        Map<Character, Character> pair = new HashMap<>();
        pair.put(')', '(');
        pair.put(']', '[');
        pair.put('}', '{');
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (pair.containsKey(c)) {
                // ③ 右括号：栈空或栈顶不匹配都立即判无效
                if (stack.isEmpty() || stack.pop() != pair.get(c)) {
                    return false;
                }
            } else {
                stack.push(c);           // ④ 左括号入栈等待配对
            }
        }
        return stack.isEmpty();          // ⑤ 栈空才说明全部配对
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)
