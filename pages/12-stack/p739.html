739. 每日温度 中等

标记本题：
给定每日温度数组 temperatures，返回等长数组 answer：answer[i] 表示第 i 天之后第几天温度才会更高；若之后都不会更高则为 0。
示例：输入 temperatures = [73,74,75,71,69,72,76,73] 输出 [1,1,4,2,1,1,0,0]

解题思路

先想清楚两个问题：

Q1：怎么避免对每一天都向后扫描？用单调递减栈：栈里存「还没等到更高温度的那些天」的下标，对应温度从栈底到栈顶单调递减。新一天的温度一出现，就是它之前所有比它低的天的「第一个更高温」。

Q2：什么时候结算、怎么算答案？遍历到第 i 天温度 t 时，循环比较栈顶：只要栈非空且 t ＞ 栈顶那天的温度，栈顶那天就等到了答案，弹出并记 ans[栈顶下标] = i - 栈顶下标；比不动了就把 i 自己入栈等待。每个下标只进出栈一次，均摊 O(n)。

照着写的 4 步：

① 建答案数组 ans（默认全 0）和空栈 stack（存下标）；
② 从左到右遍历 i = 0..n-1；
③ while 栈非空且 temperatures[i] ＞ temperatures[栈顶]：弹出 prev，令 ans[prev] = i - prev；
④ 把 i 入栈，继续下一天；遍历完直接返回 ans（栈中剩余天数的答案就是初始值 0）。

易错点：栈里存的是下标不是温度（答案要用下标算间隔）；比较对象是 temperatures[stack.peek()] 不是 stack.peek() 本身；while 循环弹栈不是 if 只弹一次（一天的高温可能同时结算多天）。

温度:  [73, 74, 75, 71, 69, 72, 76, 73]
下标:    0   1   2   3   4   5   6   7
（栈内左侧为栈底，右侧为栈顶；栈存下标）

i=0 (73): 栈空直接入栈            栈 [0]
i=1 (74): 74＞73 → 弹0，ans[0]=1-0=1；入栈   栈 [1]
i=2 (75): 75＞74 → 弹1，ans[1]=2-1=1；入栈   栈 [2]
i=3 (71): 71＜75 → 直接入栈        栈 [2, 3]
i=4 (69): 69＜71 → 直接入栈        栈 [2, 3, 4]
i=5 (72): 72＞69 → 弹4，ans[4]=5-4=1
          72＞71 → 弹3，ans[3]=5-3=2
          72＜75 停；入栈           栈 [2, 5]
i=6 (76): 76＞72 → 弹5，ans[5]=6-5=1
          76＞75 → 弹2，ans[2]=6-2=4
          栈空停；入栈              栈 [6]
i=7 (73): 73＜76 → 直接入栈        栈 [6, 7]

栈中残留的 6、7 等不到更高温 → ans 保持 0
结果: [1, 1, 4, 2, 1, 1, 0, 0] ✓

代码（Java）

class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        // ① 答案数组默认全 0，栈存「还没等到更高温的天」的下标
        int[] ans = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        // ② 从左到右扫描每一天
        for (int i = 0; i < n; i++) {
            // ③ 当前温度更高：结算栈中所有比它低的等待者
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prev = stack.pop();
                ans[prev] = i - prev;             // 等待天数 = 下标差
            }
            stack.push(i);                        // ④ 自己也入栈等待
        }
        return ans;                               // 残留栈中的天 ans 保持 0
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)
