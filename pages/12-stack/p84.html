84. 柱状图中最大的矩形 困难

标记本题：
给定 n 个非负整数表示柱状图各柱的高度（宽度均为 1），求能勾勒出的最大矩形面积。
示例：输入 heights = [2,1,5,6,2,3] → 输出 10 （以高度 5、6 横跨两根柱子，面积 5×2=10）

解题思路

本页代码参照力扣官方题解的写法：单调栈 + 首尾哨兵（一次遍历）。

先想清楚两个问题：

Q1：枚举什么才能不重不漏？枚举「以每根柱子 h 为高」的矩形：它能向左右扩展到「两边第一根比它矮的柱子」为止，面积 = h ×（右边界 - 左边界 - 1）。问题转化为对每根柱子快速找到这两个边界。

Q2：怎么用单调栈一次遍历求出所有边界？维护单调递增栈（存下标）。遍历到 i 时，一旦 h[i] 比栈顶矮，栈顶柱子的右边界就是 i，左边界是弹出后的新栈顶；于是宽度 = i - 新栈顶 - 1，结算面积。数组首尾各补一个高度 0 的哨兵：头部防栈空，尾部强制清算所有残留柱子，免去特判。

照着写的 5 步：

① 新数组 h 长度 n+2，原数据拷到 [1..n]，首尾为 0 哨兵；
② 建空栈（存下标，对应高度单调递增），ans = 0；
③ 遍历 i = 0..n+1：while 栈非空且 h[i] ＜ h[栈顶] → 弹出 top；
④ 结算：宽度 = i - 新栈顶 - 1，ans = max(ans, h[top] × 宽度)；
⑤ while 结束后把 i 入栈；遍历完返回 ans。

易错点：宽度是 i - stack.peek() - 1 不是 i - stack.peek()（两侧更矮的柱子本身不算进宽度）；弹栈后用于算左边界的是「新栈顶」不是刚弹出的 top；尾部哨兵 0 必须有，否则递增到结尾的柱子永远不被结算。

           弹5: 宽 = 7-2-1 = 4，面积 2×4 = 8

           栈 [0]，h[7]=0 不小于 h[0]=0，停

最大面积 = max(2, 6, 10, 3, 8, 6) = 10 ✓（高度5×宽2）

代码（Java · 力扣官方题解写法）

class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        // ① 首尾补 0 哨兵：头部防栈空，尾部强制清算栈中剩余柱子
        int[] h = new int[n + 2];
        System.arraycopy(heights, 0, h, 1, n);
        // ② 单调递增栈，存下标
        Deque<Integer> stack = new ArrayDeque<>();
        int ans = 0;
        // ③ 遍历含哨兵的整个数组
        for (int i = 0; i < h.length; i++) {
            while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
                int top = stack.pop();                // ③ 弹出以 h[top] 为高的柱子
                // ④ 右边界 = i，左边界 = 新栈顶，宽 = i - 新栈顶 - 1
                int width = i - stack.peek() - 1;
                ans = Math.max(ans, h[top] * width);
            }
            stack.push(i);                            // ⑤ 当前下标入栈
        }
        return ans;
    }
}
