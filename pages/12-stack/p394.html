394. 字符串解码 中等

标记本题：
编码规则：k[encoded_string] 表示方括号内的 encoded_string 重复 k 次，编码可嵌套。给定编码字符串 s，返回解码后的字符串。
示例：输入 s = "3[a2[c]]" → 输出 "accaccacc" 输入 s = "2[abc]3[cd]ef" → 输出 "abcabccdcdcdef"

解题思路

本页代码参照力扣官方题解的写法：辅助栈（倍数栈 + 外层字符串栈，逐字符解析）。

先想清楚两个问题：

Q1：嵌套括号怎么解析？嵌套结构是「后进先出」：内层先解码完，再拼回外层。用两个栈：stack_multi 存各层的重复倍数，stack_res 存进入本层之前外层已累计的字符串；再用 res 和 multi 记录「当前层正在解析的串」和「正在累计的倍数」。

Q2：四种字符各触发什么动作？'[' → 把当前 multi 和 res 分别压栈，然后 multi 清零、res 重置，开始解析内层；']' → 弹出外层倍数 cur_multi 和外层串，按「外层串 + 内层串重复 cur_multi 次」拼成新 res；数字 → multi = multi×10 + 数字（累计多位数）；普通字母 → 直接 append 到 res。

照着写的 5 步：

① 建 stack_multi、stack_res 两个栈，res = 空 StringBuilder，multi = 0；
② 遇 '['：stack_multi、stack_res 分别压入 multi 和 res 的字符串，然后 multi = 0、res 新建空串；
③ 遇 ']'：弹出 cur_multi 和外层串，把 res 重复 append cur_multi 次拼到外层串后面，令 res = 拼接结果；
④ 遇数字：multi = multi * 10 + (c - '0')；
⑤ 遇字母：res.append(c)；遍历结束返回 res.toString()。

易错点：数字可能是多位数（如 "12[a]"），必须 multi×10 累加不是直接赋值；遇 '[' 压栈后要同时重置 multi 和 res，漏一个就会串层；']' 处拼接顺序是「外层串在前、内层串重复 cur_multi 次在后」，写反结果就反。

s = "3[a2[c]]"
（栈内左侧为栈底，右侧为栈顶）

操作          stack_multi   stack_res      multi   res
读 '3'        []            []             3       ""
读 '['        [3]           [""]           0       ""      压栈后重置
读 'a'        [3]           [""]           0       "a"
读 '2'        [3]           [""]           2       "a"
读 '['        [3, 2]        ["", "a"]      0       ""      再压一层
读 'c'        [3, 2]        ["", "a"]      0       "c"
读 ']'        [3]           [""]           0       "acc"   弹 cur_multi=2、外层"a"
                                                          res = "a" + "c"×2
读 ']'        []            []             0       "accaccacc"
                                                   弹 cur_multi=3、外层""
                                                   res = "" + "acc"×3

返回 "accaccacc" ✓

代码（Java · 力扣官方题解写法）

class Solution {
    public String decodeString(String s) {
        // ① 当前层正在解析的串 res、正在累计的倍数 multi
        StringBuilder res = new StringBuilder();
        int multi = 0;
        // ① 两个栈：各层的重复倍数、进入本层前外层已累积的串
        LinkedList<Integer> stack_multi = new LinkedList<>();
        LinkedList<String> stack_res = new LinkedList<>();
        for (Character c : s.toCharArray()) {
            if (c == '[') {
                stack_multi.addLast(multi);     // ② 保存本层倍数
                stack_res.addLast(res.toString()); // ② 保存外层结果
                multi = 0;
                res = new StringBuilder();      // ② 重置，开始解析内层
            } else if (c == ']') {
                StringBuilder tmp = new StringBuilder();
                int cur_multi = stack_multi.removeLast(); // ③ 本层重复次数
                for (int i = 0; i < cur_multi; i++) {
                    tmp.append(res);            // ③ 内层串重复 cur_multi 次
                }
                res = new StringBuilder(stack_res.removeLast() + tmp); // ③ 外层串在前
            } else if (c >= '0' && c <= '9') {
                multi = multi * 10 + Integer.parseInt(c + ""); // ④ 累计多位数
            } else {
                res.append(c);                  // ⑤ 普通字符直接累积
            }
        }
        return res.toString();                  // ⑤
    }
}

时间复杂度 O(n × kmax)（解码后串长）· 空间复杂度 O(n)
