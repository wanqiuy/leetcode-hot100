155. 最小栈 中等

标记本题：
设计一个栈，支持 push、pop、top，并能在常数时间内检索到最小元素 getMin。
示例：push(-2), push(0), push(-3), getMin() → -3 pop(), top() → 0, getMin() → -2

解题思路

先想清楚两个问题：

Q1：为什么一个栈不够，怎么补救？单栈弹出最小值后，无法知道「新的最小值是谁」。补救办法：加一个辅助栈（最小栈），与主栈同进同出，但它每层存的是「此时主栈中的最小值」。

Q2：最小栈每层存什么？push 时存 min（新值， 最小栈栈顶）——即新值与历史最小值取小。这样最小栈栈顶永远是当前最小值，getMin 读栈顶即可；pop 时两栈同步弹出，最小值自动「恢复」到上一层的状态。四个操作全部 O(1)。

照着写的 5 步：

① 声明两个栈：stack（主栈）、minStack（最小栈）；
② push(val)：val 入主栈；再把「val 与 minStack 栈顶的较小者」入 minStack（minStack 为空时直接入 val）；
③ pop()：两栈各弹一次，保持同步；
④ top()：返回 stack.peek()；
⑤ getMin()：返回 minStack.peek()。

易错点：push 进最小栈的是「到当前层为止的最小值」不是 val 本身（否则 pop 后最小值无法恢复）；两栈必须同步弹出不是只弹主栈；最小栈为空时第一次 push 要直接存 val 不能去 peek（会空栈异常）。

操作序列: push(-2) push(0) push(-3) → getMin() → pop() → top() → getMin()

（栈内左侧为栈底，右侧为栈顶）

push(-2): 主栈 [-2]        最小栈 [-2]      存 min(-2, 空)=-2
push(0):  主栈 [-2, 0]     最小栈 [-2, -2]  存 min(0, -2)=-2
push(-3): 主栈 [-2, 0, -3] 最小栈 [-2, -2, -3]
                                      ↑ 栈顶 = -3 = 当前最小值

getMin() → 最小栈栈顶 = -3 ✓

pop():    主栈 [-2, 0]     最小栈 [-2, -2]  两栈同步弹
top()     → 主栈栈顶 = 0 ✓
getMin()  → 最小栈栈顶 = -2 ✓（最小值自动恢复，无需重算）

代码（Java）

class MinStack {
    // ① 主栈 + 最小栈（栈顶始终是当前最小值）
    private Deque<Integer> stack;
    private Deque<Integer> minStack;

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);
        // ② 最小栈存入「新值与历史最小值的较小者」
        int curMin = minStack.isEmpty() ? val : Math.min(val, minStack.peek());
        minStack.push(curMin);
    }

    public void pop() {
        stack.pop();
        minStack.pop();               // ③ 两栈同步弹出，保持对应
    }

    public int top() {
        return stack.peek();          // ④
    }

    public int getMin() {
        return minStack.peek();       // ⑤ O(1) 读最小值
    }
}

时间复杂度 所有操作 O(1) · 空间复杂度 O(n)
