763. 划分字母区间 中等

标记本题：
给定小写字母字符串 s，把它划分成尽可能多的片段，要求同一字母最多只能出现在其中一个片段中。返回每个片段的长度列表。
示例：输入 s = "ababcbacadefegdehijhklij" 输出 [9,7,8]（划分为 "ababcbaca" / "defegde" / "hijhklij"）

解题思路

本页代码参照力扣官方题解的写法：贪心 + 两次遍历（记录字母最后出现位置，扫描收割片段）。

先想清楚两个问题：

Q1：一个片段的边界由什么决定？由片段内所有字母的「最后出现位置」决定：只要片段包含某字母，片段就至少要延伸到它的最后一次出现处，否则同一字母会出现在两段。所以先扫一遍记录 last[c] = 字母 c 最后出现的下标。

Q2：什么时候可以收割一段？第二遍扫描维护 end = 本段必须延伸到的最远位置：到 i 时 end = max(end, last[s[i]])。当 i == end，说明段内所有字母都已在段内收尾，贪心收割（长度 = i - start + 1）并从 i+1 开新段。每段尽早结束，段数自然最多。

照着写的 5 步：

① 建 last[26]，第一遍扫描记录每个字母最后出现的下标；
② 初始化 ans 列表、start = 0、end = 0；
③ 第二遍扫描 i = 0..n-1：end = max(end, last[s[i] - 'a'])；
④ 若 i == end：收割，ans.add(i - start + 1)，并令 start = i + 1；
⑤ 扫描结束返回 ans。

易错点：段长是 i - start + 1 不是 i - start（闭区间含两端）；收割条件是 i == end 不是 i >= last[s[i]]（要被段内所有字母的最后位置共同决定）；end 的更新要取 max 不是直接赋值（后来的字母可能收尾更早，不能回退）。

s = "ababcbacadefegdehijhklij"

① last 表: a→8, b→5, c→7, d→14, e→15, f→11, g→13, h→19,
            i→22, j→23, k→20, l→21

②③④ 第二遍扫描（end 变化轨迹）：
i=0 'a': end = max(0, 8) = 8
i=1 'b': end = max(8, 5) = 8      i=4 'c': end = max(8, 7) = 8
... i=8 'a': i == end=8 → 收割 [0..8]，长度 9，start=9

i=9 'd': end = max(0→, 14) = 14

i=15 'e': i == end=15 → 收割 [9..15]，长度 7，start=16

i=16 'h': end = 19 → ... → i=23 'j': i == end=23
         → 收割 [16..23]，长度 8

答案 = [9, 7, 8] ✓

代码（Java · 力扣官方题解写法）

class Solution {
    public List<Integer> partitionLabels(String s) {
        // ① 第一遍：记录每个字母最后出现的下标
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }
        // ② start 是本段起点，end 是本段必须延伸到的最远位置
        List<Integer> ans = new ArrayList<>();
        int start = 0, end = 0;
        // ③ 第二遍扫描
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']); // 扩张段边界
            if (i == end) {                 // ④ 段内所有字母已收尾
                ans.add(i - start + 1);     // ④ 收割本段长度
                start = i + 1;              // ④ 开启新段
            }
        }
        return ans;                         // ⑤
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)（字母表固定 26）
