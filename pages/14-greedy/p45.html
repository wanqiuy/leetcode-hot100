45. 跳跃游戏 II 中等

标记本题：
与 55 题相同的跳跃规则，但保证一定可以到达终点。要求返回到达最后一个下标的最少跳跃次数。
示例：输入 nums = [2,3,1,1,4] → 输出 2（下标 0 → 1 → 4） 输入 nums = [2,3,0,1,4] → 输出 2

解题思路

先想清楚两个问题：

Q1：怎么把「最少跳几步」转化为逐层扩张？把跳跃看成贪心版 BFS：当前这一步能到达的范围是一「层」。维护两个边界——end（本层覆盖的右边界）和 farthest（扫描本层时下一步能到的最远位置）。每一步都贪心地选「能让下一跳跳得最远」的落点，总步数自然最少。

Q2：什么时候步数加一？遍历 i 时先用 i + nums[i] 刷新 farthest；当 i 走到 end（本层探完），说明必须再跳一步：steps + 1，同时把 end 推进到 farthest 进入下一层。循环只需跑到 i = n-2：最后一次扩张边界已含终点，不必对终点本身再计步。

照着写的 5 步：

① steps = 0，end = 0，farthest = 0；
② 遍历 i = 0..n-2；
③ farthest = max(farthest, i + nums[i])；
④ 若 i == end：steps++ 且 end = farthest；
⑤ 循环结束返回 steps。

易错点：循环上界是 i < n - 1 不是 i < n（终点不计步，否则多数一步）；计步时机是 i == end 时不是每次更新 farthest 时；end 推进为 farthest 不是 end + 1（跳着走不是走着走）。

nums = [2, 3, 1, 1, 4]
i:      0   1   2   3   4     n - 2 = 3（只遍历到 i=3）

初始: steps=0, end=0, farthest=0
第 1 层（第 1 跳覆盖范围）：end 将推进到 farthest

i=0: farthest = max(0, 0+2) = 2
     i == end=0 → 本层探完，steps=1，end=2
     含义：第 1 跳最多到 2，扫描 [0..2] 决定第 2 跳
i=1: farthest = max(2, 1+3) = 4   ← 从下标 1 能直跳终点
i=2: farthest = max(4, 2+1) = 4
     i == end=2 → 本层探完，steps=2，end=4
     第 2 跳已覆盖终点 4
i=3: farthest = max(4, 3+1) = 4，i ≠ end，不动

返回 steps = 2 ✓（下标 0 → 1 → 4）

代码（Java）

class Solution {
    public int jump(int[] nums) {
        // ① steps 步数；end 本跳覆盖的右边界；farthest 下一跳最远处
        int steps = 0;
        int end = 0;
        int farthest = 0;
        // ② 只需遍历到 n-2：最后一次扩张已含终点
        for (int i = 0; i < nums.length - 1; i++) {
            farthest = Math.max(farthest, i + nums[i]); // ③ 刷新下一跳最远处
            if (i == end) {          // ④ 本层探完，必须再跳一步
                steps++;
                end = farthest;      // ④ 边界推进到下一跳范围
            }
        }
        return steps;                // ⑤
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
