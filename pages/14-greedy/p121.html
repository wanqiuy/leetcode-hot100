121. 买卖股票的最佳时机 简单

标记本题：
给定数组 prices，prices[i] 表示股票第 i 天的价格。只允许一次买入加一次卖出（先买后卖），求能获得的最大利润；无法获利则返回 0。
示例：输入 prices = [7,1,5,3,6,4] → 输出 5（第 2 天 1 元买入，第 5 天 6 元卖出） 输入 prices = [7,6,4,3,1] → 输出 0

解题思路

先想清楚两个问题：

Q1：只交易一次，需要跟踪什么状态？只需一个值：「到今天为止的最低价格」minPrice。贪心的依据：在最低点买入一定不劣于其他买入点，所以历史最低价是唯一的最佳买入候选。

Q2：每天做什么决策？假设今天卖出，利润 = 今天价格 - minPrice，与历史最大利润比较取大。从左到右扫描天然保证「买在卖前」的顺序约束，一趟结束。

照着写的 4 步：

① minPrice 初始化为 +∞（Integer.MAX_VALUE），maxProfit 初始化为 0；
② 遍历每个价格 p；
③ 先用 p 更新 minPrice = min(minPrice, p)；
④ 再算今天卖出的利润更新 maxProfit = max(maxProfit, p - minPrice)；遍历完返回 maxProfit。

易错点：minPrice 初值是 Integer.MAX_VALUE 不是 0（否则最低价永远更新不进去）；maxProfit 初值是 0 不是负无穷（利润为负时要求返回 0）；先更新 minPrice 再算利润，同一天买卖利润为 0，不影响正确性。

prices = [7, 1, 5, 3, 6, 4]

i:        0   1   2   3   4   5
价格 p:   7   1   5   3   6   4
操作③ minPrice:  7   1   1   1   1   1   ← 历史最低买入价
操作④ 今日利润:  0   0   4   2   5   3   ← p - minPrice
maxProfit:  0   0   4   4   5   5
                        ↑
              i=4 时 6-1=5 → 最大利润 = 5 ✓

（第 2 天 1 元买入，第 5 天 6 元卖出）

代码（Java）

class Solution {
    public int maxProfit(int[] prices) {
        // ① minPrice 记历史最低价，maxProfit 记最大利润
        int minPrice = Integer.MAX_VALUE;
        int maxProfit = 0;
        // ② 从左到右扫描，天然保证先买后卖
        for (int p : prices) {
            minPrice = Math.min(minPrice, p);              // ③ 更新最低买入点
            maxProfit = Math.max(maxProfit, p - minPrice); // ④ 假设今天卖出
        }
        return maxProfit;
    }
}
