128. 最长连续序列 中等

标记本题：
给定未排序的整数数组 nums，找出数字连续的最长序列的长度，要求时间复杂度 O(n)。
示例： 输入：nums = [100,4,200,1,3,2] 输出：4 解释：最长连续序列是 [1,2,3,4]，长度为 4

解题思路

本页代码参照力扣官方题解的写法：HashSet + 只从序列起点开始扩展。

先想清楚两个问题：

Q1：要求 O(n)、又不能排序，怎么快速知道 x+1 在不在？把所有数放进 HashSet，「某数是否存在」的查询降到 O(1)。

Q2：从哪个数开始往后数，才不会重复劳动？只从「序列起点」（x-1 不在 set 中）开始扩展；非起点直接跳过。这样每段连续序列只被完整数一遍，每个数最多被访问常数次，总体 O(n)。

照着写的四步：

① 所有数加入 HashSet，去重并支持 O(1) 查询；
② 遍历 set 中每个数 num，先判断 num-1 是否存在；
③ num-1 存在 → num 不是起点，直接跳过；
④ num-1 不存在 → num 是起点，从 num 开始反复查 currentNum+1 向后扩展，统计本段长度并刷新最大值。

易错点：起点判断 !set.contains(num-1) 漏掉会退化成 O(n²)；本段长度是 currentNum - num + 1（别写成 currentNum - num）；遍历 set 而不是原数组，顺带完成去重。

nums = [100,4,200,1,3,2] → set = {1,2,3,4,100,200}

num  num-1 在 set？  操作                    本次长度  longestStreak
100  99 不在→起点   向后数：100             1        1
4    3 在 →非起点   跳过                    -        1
200  199 不在→起点  向后数：200             1        1
1    0 不在 →起点   向后数：1→2→3→4         4        4 ← 最长
3    2 在 →非起点   跳过                    -        4
2    1 在 →非起点   跳过                    -        4

答案 = 4（最长连续序列 [1,2,3,4]）

代码（Java · 力扣官方题解写法）

class Solution {
    public int longestConsecutive(int[] nums) {
        // ① 全部入 HashSet，存在性查询 O(1)
        Set<Integer> num_set = new HashSet<Integer>();
        for (int num : nums) {
            num_set.add(num);
        }

        int longestStreak = 0;

        for (int num : num_set) {
            // ②③ num-1 在则 num 非起点直接跳过；不在才从 num 扩展
            if (!num_set.contains(num - 1)) {
                // ④ 起点向后逐个扩展，统计本段长度
                int currentNum = num;
                int currentStreak = 1;

                while (num_set.contains(currentNum + 1)) {
                    currentNum += 1;
                    currentStreak += 1;
                }

                longestStreak = Math.max(longestStreak, currentStreak);
            }
        }

        return longestStreak;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)
