49. 字母异位词分组 中等

标记本题：
给定字符串数组 strs，将「字母异位词」（由相同字母重排而成的单词）组合在一起，按任意顺序返回分组结果。
示例： 输入：strs = ["eat","tea","tan","ate","nat","bat"] 输出：[["bat"],["nat","tan"],["ate","eat","tea"]]

解题思路

先想清楚两个问题：

Q1：怎么判断两个字符串互为异位词？不用两两比对——互为异位词的字符串，字符排序后必然完全相同，「排序结果」就是天然的分组标识。

Q2：分组用什么数据结构存？哈希表：key = 排序后的字符串，value = 该组原字符串列表。computeIfAbsent 一句搞定「没有就建组、有就追加」。

照着写的四步：

① 建哈希表 map：key 为排序后的串，value 为原串列表；
② 遍历每个字符串，把字符数组排序得到 key；
③ 把原串追加到 map[key] 的列表（key 不存在先新建空列表）；
④ 遍历结束，map 的所有 value 就是分组结果。

易错点：排序要对 char 数组排（String 不可变）；加入列表的必须是原串 s，不是排序后的 key；最后别忘用 map.values() 包一层 ArrayList 返回。

strs = ["eat","tea","tan","ate","nat","bat"]

字符串  排序后 key  map 变化（key → 组内列表）
eat     aet         新建组 → {aet:[eat]}
tea     aet         追加   → {aet:[eat,tea]}
tan     ant         新建组 → {..., ant:[tan]}
ate     aet         追加   → {aet:[eat,tea,ate]}
nat     ant         追加   → {ant:[tan,nat]}
bat     abt         新建组 → {abt:[bat]}

map 的 values 即答案：
  aet → ["eat","tea","ate"]
  ant → ["tan","nat"]
  abt → ["bat"]

代码（Java）

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        // ① key = 排序后的字符串，value = 该异位词组的原串列表
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            // ② 字符排序得到分组标识（异位词排序后必然相同）
            char[] ch = s.toCharArray();
            Arrays.sort(ch);
            String key = new String(ch);
            // ③ key 不存在先建空组，再把原串追加进去
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        // ④ map 的所有 value 就是分组答案
        return new ArrayList<>(map.values());
    }
}

时间复杂度 O(n·k log k)，n 为字符串个数、k 为最长字符串长度 · 空间复杂度 O(n·k)
