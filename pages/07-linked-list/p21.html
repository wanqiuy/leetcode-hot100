21. 合并两个有序链表 简单

标记本题：
将两个升序链表合并为一个新的升序链表并返回。
示例： 输入：l1 = 1->2->4，l2 = 1->3->4 输出：1->1->2->3->4->4

解题思路

本页代码参照力扣官方题解的写法：迭代 + 虚拟头（dummy）哨兵。

先想清楚两个问题：

Q1：为什么要虚拟头节点 dummy？合并时第一个节点就要被"接到某个东西后面"，没有 dummy 就得特判头节点；有了 dummy，所有节点统一用 tail.next = x 接入，最后 return dummy.next 即可。

Q2：每轮做什么、循环结束后的尾巴怎么处理？每轮取两表当前节点中较小的那个接到 tail 后，并让该表指针前移；当一表走空时，另一表的剩余部分必然整体有序，直接整段接到 tail 后，不用再逐节点搬。

照着写的 4 步：

① 建 dummy 节点，tail = dummy；
② 循环条件 list1 != null && list2 != null：比较两表当前值，小的接 tail.next，该表指针前移，tail 也前移；
③ 循环结束后 tail.next = 没走完的那张表（可能为 null，接上也没事）；
④ return dummy.next。

易错点：接完节点后「tail = tail.next」不能漏，否则新节点会覆盖上一个；取节点用「<= 时取 list1」可保证稳定性，取谁不影响正确性但要和分支对应；剩余部分用「整体接上 tail.next = list1 或 list2」不是再开循环逐个接。

输入: l1 = 1 -> 2 -> 4，l2 = 1 -> 3 -> 4

逐步推演（每轮列出：取谁 / tail 链状态 / 两表指针位置）：
轮1  l1.val=1 <= l2.val=1，取 l1 的 1
     dummy -> 1    l1=2, l2=1
轮2  l1.val=2 > l2.val=1，取 l2 的 1
     dummy -> 1 -> 1    l1=2, l2=3
轮3  取 l1 的 2
     dummy -> 1 -> 1 -> 2    l1=4, l2=3
轮4  取 l2 的 3
     dummy -> 1 -> 1 -> 2 -> 3    l1=4, l2=4
轮5  取 l1 的 4（4 <= 4）
     dummy -> 1 -> 1 -> 2 -> 3 -> 4    l1=null, l2=4
循环退出，tail.next = l2 整段接上
结果: 1 -> 1 -> 2 -> 3 -> 4 -> 4

代码（Java · 力扣官方题解写法）

class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        // ① 虚拟头 + 尾指针，免去头节点特判
        ListNode dummy = new ListNode(-1), tail = dummy;
        // ② 两表都非空时逐节点取较小者
        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                tail.next = list1;       // ② 接入较小节点
                list1 = list1.next;      // ② 对应表指针前移
            } else {
                tail.next = list2;
                list2 = list2.next;
            }
            tail = tail.next;            // ② tail 跟上新末尾
        }
        // ③ 剩余部分整体接上（另一表为 null 也安全）
        tail.next = (list1 != null) ? list1 : list2;
        // ④ 真正的头在 dummy.next
        return dummy.next;
    }
}

时间复杂度 O(m+n) · 空间复杂度 O(1)
