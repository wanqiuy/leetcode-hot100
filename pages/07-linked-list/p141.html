141. 环形链表 简单

标记本题：
判断链表中是否有环。如果链表中某个节点可以通过 next 指针再次到达，则存在环。
示例： 输入：3->2->0->-4，尾节点 -4 指向节点 2 输出：true

解题思路

先想清楚两个问题：

Q1：为什么快慢指针能判环？slow 每次 1 步、fast 每次 2 步。若有环，fast 进环后相对 slow 以每轮 1 步的速度逼近，环内距离有限，必然追上并相遇；若无环，fast 先走到 null。

Q2：循环退出条件怎么写才安全？条件必须同时保证 fast != null 且 fast.next != null，因为循环体里要执行 fast.next.next，少一个判断就会空指针。

照着写的 3 步：

① slow、fast 都从头节点出发；
② 循环条件 fast != null && fast.next != null：slow 走一步、fast 走两步；
③ 每轮走完判断 slow == fast，相等返回 true；循环正常退出则返回 false。

易错点：fast 的判空是「fast != null && fast.next != null」不是「fast.next.next != null」（后者漏掉 fast 本身为 null 的情况）；相遇判断放在「两指针都移动之后」不是移动之前（初始时 slow == fast 都在头节点，会误判）；比较的是节点引用 slow == fast 不是 slow.val == fast.val。

输入: 3 -> 2 -> 0 -> -4，尾节点 -4 的 next 指回 2
      3 -> 2 -> 0 -> -4
           ^___________|

逐步推演（每轮列出 slow、fast 所在节点值）：
轮0  slow=3,  fast=3       （起点相同，不判）
轮1  slow=2,  fast=0
轮2  slow=0,  fast=2       （fast 已绕环一圈）
轮3  slow=-4, fast=-4      相遇！返回 true

若无环（如 1 -> 2 -> 3 -> null）：
轮1  slow=2, fast=3
轮2  slow=3, fast=null -> 退出循环，返回 false

代码（Java）

public class Solution {
    public boolean hasCycle(ListNode head) {
        // ① 双指针同从头出发
        ListNode slow = head, fast = head;
        // ② fast 走两步，要先保证 fast 和 fast.next 非空
        while (fast != null && fast.next != null) {
            slow = slow.next;        // ② slow 走 1 步
            fast = fast.next.next;   // ② fast 走 2 步
            // ③ 引用相等即相遇，有环
            if (slow == fast) return true;
        }
        // ③ fast 走到尽头，无环
        return false;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
