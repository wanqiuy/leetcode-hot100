25. K 个一组翻转链表 困难

标记本题：
每 k 个节点一组进行翻转，不足 k 个的剩余节点保持原样。
示例： 输入：1->2->3->4->5，k = 2 输出：2->1->4->3->5

解题思路

先想清楚两个问题：

Q1：一组一组翻转，每组的边界怎么确定？维护两个指针：pre 指向本组的前驱，end 从 pre 位置出发先走 k 步定位本组末尾；end 走到 null 说明剩余不足 k 个，直接结束不翻转。

Q2：翻转本组后怎么接回去？记 start = pre.next（本组原头）、nxt = end.next（下一组头）；先 end.next = null 把本组断开，翻转后 start 变成了本组的尾：于是 pre.next 接翻转后的新头，start.next 接回 nxt，再把 pre、end 都移到 start 继续处理下一组。

照着写的 5 步：

① 建 dummy 指向 head，pre、end 都指向 dummy；
② 死循环里先让 end 走 k 步（每步判 null），end 为 null 就 break；
③ 记 start = pre.next、nxt = end.next，end.next = null 断开本组；
④ pre.next = reverse(start)（组内翻转并接到前驱），start.next = nxt（翻转后 start 是组尾，接回后半段）；
⑤ pre = start、end = start，回到 ② 处理下一组；循环外 return dummy.next。

易错点：断开本组要在「记录 nxt = end.next 之后」再 end.next = null，顺序反了就丢后半段；翻转后组尾是「start」不是 end（reverse 返回的新头是原 end）；每轮结束 pre、end 都要移到「start」不是别的节点。

输入: 1 -> 2 -> 3 -> 4 -> 5，k = 2
挂上 dummy: dummy -> 1 -> 2 -> 3 -> 4 -> 5
            pre、end 都在 dummy

第 1 组：
  end 走 2 步到 2；start=1, nxt=3
  断开: 1 -> 2 | 3 -> 4 -> 5
  翻转 [1,2] -> [2,1]，pre.next=2，start(1).next=3
  状态: dummy -> 2 -> 1 -> 3 -> 4 -> 5
  pre、end 移到 1

第 2 组：
  end 走 2 步到 4；start=3, nxt=5
  断开: 3 -> 4 | 5
  翻转 [3,4] -> [4,3]，pre(1).next=4，start(3).next=5
  状态: dummy -> 2 -> 1 -> 4 -> 3 -> 5
  pre、end 移到 3

第 3 轮：end 从 3 出发走 2 步，第 2 步踩到 null
  => 剩余 [5] 不足 k=2，break

返回 dummy.next: 2 -> 1 -> 4 -> 3 -> 5

代码（Java）

class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        // ① dummy + 组前驱 pre + 组尾定位指针 end
        ListNode dummy = new ListNode(0, head);
        ListNode pre = dummy, end = dummy;
        while (true) {
            // ② end 走 k 步定位本组末尾（边走边判空）
            for (int i = 0; i < k && end != null; i++) end = end.next;
            // ② 不足 k 个，不翻转，直接结束
            if (end == null) break;
            // ③ 记录本组头和下一组头，再断开本组
            ListNode start = pre.next;
            ListNode nxt = end.next;
            end.next = null;
            // ④ 组内翻转接到前驱后；start 成了组尾，接回后半段
            pre.next = reverse(start);
            start.next = nxt;
            // ⑤ 移到下一组的前驱位置
            pre = start;
            end = start;
        }
        return dummy.next;
    }
    private ListNode reverse(ListNode head) {
        ListNode prev = null, cur = head;
        while (cur != null) {
            ListNode nxt = cur.next;
            cur.next = prev;
            prev = cur;
            cur = nxt;
        }
        return prev;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
