206. 反转链表 简单

标记本题：
给你单链表的头节点 head，反转链表并返回反转后的头节点。
示例： 输入：1->2->3->4->5 输出：5->4->3->2->1

解题思路

本页代码参照力扣官方题解的写法：迭代反转（prev / curr / nextTemp 三指针）。

先想清楚两个问题：

Q1：每到一个节点要做的事是什么？就一件：把当前节点的 next 从"指向后面"改成"指向前一个（prev）"。所有节点都这么干，整条链就反过来了。

Q2：改完指针后怎么继续往后走？改 next 之前必须先用一个临时变量 nextTemp 存下原来的后继，否则链条断掉就再也找不到后面的节点了。

照着写的 4 步：

① 初始化 prev = null、curr = head；
② 循环条件 curr != null：先用 nextTemp = curr.next 存住后继；
③ curr.next = prev 完成反转，然后 prev = curr、curr = nextTemp 双双前进；
④ 循环结束后 return prev（curr 已是 null，prev 停在原尾节点，即新头）。

易错点：nextTemp 的保存必须在「curr.next = prev 之前」不是之后；prev 初始值是 null 不是 head（这样原头节点的 next 才会被置成 null，成为新尾）；返回值是 prev 不是 curr（curr 已经是 null）。

输入: 1 -> 2 -> 3 -> null
逐步推演（每轮列出操作 / prev、curr 值 / 链表状态）：

初始    prev=null, curr=1
        1 -> 2 -> 3 -> null

轮1     操作: nextTemp=2; 1.next=null; prev=1; curr=2
        状态: null <- 1    2 -> 3 -> null
              prev=1       curr=2

轮2     操作: nextTemp=3; 2.next=1; prev=2; curr=3
        状态: null <- 1 <- 2    3 -> null
                     prev=2     curr=3

轮3     操作: nextTemp=null; 3.next=2; prev=3; curr=null
        状态: null <- 1 <- 2 <- 3
                            prev=3, curr=null

curr 为 null 退出循环，返回 prev=3：
3 -> 2 -> 1 -> null

代码（Java · 力扣官方题解写法）

class Solution {
    public ListNode reverseList(ListNode head) {
        // ① prev 初始为 null（新链表的末尾），curr 从头出发
        ListNode prev = null, curr = head;
        // ② 遍历每个节点
        while (curr != null) {
            ListNode nextTemp = curr.next; // ② 先保存后继节点
            curr.next = prev;              // ③ 反转当前节点的指针
            prev = curr;                   // ③ prev 前进
            curr = nextTemp;               // ③ curr 前进
        }
        // ④ prev 是新链表的头
        return prev;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
