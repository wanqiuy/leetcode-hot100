146. LRU 缓存 中等

标记本题：
设计 LRU（最近最少使用）缓存：get 和 put 都必须是 O(1)。容量满时 put 需淘汰最久未使用的键。
示例： cache = LRUCache(2); put(1,1); put(2,2); get(1)=1; put(3,3)（淘汰2）; get(2)=-1

解题思路

先想清楚两个问题：

Q1：为什么必须"哈希表 + 双向链表"组合？get/put 要 O(1) 定位就得用 HashMap；但哈希表记不住"谁最久没用"，需要一条按使用顺序排的链。用双向而不是单向，是因为删除中间节点要改前驱的指针，单向链找前驱得 O(n)。

Q2：链表头和尾各放什么？约定：越靠近头越"旧"（最久未用），越靠近尾越"新"（最近使用）。任何一次 get/put 命中都把节点挪到尾部；容量满时淘汰 head.next（最旧的那个）。

照着写的 7 步：

① 定义双向节点 Node（key、val、prev、next）；准备 map、capacity、虚拟头 head、虚拟尾 tail，构造时 head 与 tail 互指；
② get：map 查不到返回 -1；查到了 moveToTail(node) 再返回 node.val；
③ put 已存在的 key：更新 val，moveToTail，直接 return；
④ put 新 key 且 map.size() == capacity：取 lru = head.next，remove(lru) 并 map.remove(lru.key)；
⑤ 建 fresh 节点，addToTail(fresh)，map.put(key, fresh)；
⑥ remove(node)：node.prev.next = node.next；node.next.prev = node.prev（两条链都改）；
⑦ addToTail(node)：插到 tail 前面——node.prev = tail.prev、node.next = tail、tail.prev.next = node、tail.prev = node；moveToTail = remove + addToTail。

易错点：Node 里必须存「key」不是只存 val（淘汰时要从 map 里删掉对应键）；淘汰的是「head.next」不是 tail.prev（头侧才是最久未用）；addToTail 四句的顺序先把 node 自己的 prev/next 指好、再改邻居，最后一句是「tail.prev = node」收尾。

容量=2，操作序列: put(1,1) put(2,2) get(1) put(3,3) get(2)
约定: head 侧最旧 <-> ... <-> tail 侧最新

逐步推演（每步列出链表状态和 map 内容）：
① put(1,1): 新节点插到尾
   链: H <-> [1:1] <-> T        map: {1}
② put(2,2): 新节点插到尾
   链: H <-> [1:1] <-> [2:2] <-> T   map: {1,2}
③ get(1):   命中，remove(1) + addToTail(1)
   链: H <-> [2:2] <-> [1:1] <-> T   map: {1,2}   返回 1
④ put(3,3): size==capacity，先淘汰 head.next=[2:2]
   链: H <-> [1:1] <-> T        map: {1}
   再把 [3:3] 插到尾
   链: H <-> [1:1] <-> [3:3] <-> T   map: {1,3}
⑤ get(2):   map 里已没有 2，返回 -1   （2 刚被淘汰，验证正确）

代码（Java）

import java.util.HashMap;
import java.util.Map;

class LRUCache {
    // ① 双向链表节点（必须带 key，淘汰时要删 map 项）
    private static class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }
    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(-1, -1); // ① 虚拟头：其后是最久未使用
    private final Node tail = new Node(-1, -1); // ① 虚拟尾：其前是最近使用

    public LRUCache(int capacity) {
        this.capacity = capacity;
        // ① 初始头尾互指
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        // ② 查不到返回 -1
        Node node = map.get(key);
        if (node == null) return -1;
        // ② 命中则挪到尾部（变为最近使用）
        moveToTail(node);
        return node.val;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        // ③ 已存在：更新值并置为最近使用
        if (node != null) {
            node.val = value;
            moveToTail(node);
            return;
        }
        // ④ 满了：淘汰头部（最久未使用），别忘了同步删 map
        if (map.size() == capacity) {
            Node lru = head.next;
            remove(lru);
            map.remove(lru.key);
        }
        // ⑤ 新节点挂到尾部并登记进 map
        Node fresh = new Node(key, value);
        addToTail(fresh);
        map.put(key, fresh);
    }

    // ⑥ 摘节点：前后邻居互指，两条方向都要改
    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    // ⑦ 插到虚拟尾之前：先指好自己，再改邻居
    private void addToTail(Node node) {
        node.prev = tail.prev;
        node.next = tail;
        tail.prev.next = node;
        tail.prev = node;
    }

    // ⑦ 挪到尾部 = 摘下 + 插尾
    private void moveToTail(Node node) {
        remove(node);
        addToTail(node);
    }
}

时间复杂度 O(1)（get / put）· 空间复杂度 O(capacity)
