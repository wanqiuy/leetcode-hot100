142. 环形链表 II 中等

标记本题：
在判断有环的基础上，返回环的入口节点；无环返回 null。要求 O(1) 空间。
示例： 输入：3->2->0->-4，尾节点指向节点 2 输出：节点 2（环的入口）

解题思路

本页代码参照力扣官方题解的写法：快慢指针（Floyd 算法两阶段——先判环，再从头部和相遇点同步走求入口）。

先想清楚两个问题：

Q1：相遇点和环入口有什么关系？设头到入口距离 a、入口到相遇点 b、相遇点绕回入口 c。fast 路程是 slow 两倍：a + b + (b + c) = 2(a + b)，化简得 a = c——从"头"和"相遇点"各派一个指针同步走，相遇处就是环入口。

Q2：怎么区分"无环"和"有环求入口"？沿用 141 题的快慢指针：fast 走到 null 说明无环，直接返回 null；相遇了才进入第二阶段求入口。

照着写的 4 步：

① slow、fast 从头出发；
② 循环条件 fast != null && fast.next != null：slow 一步、fast 两步；
③ 若 slow == fast 相遇：令 p = head，p 与 slow 同步各走一步，直到 p == slow，返回 p；
④ 外层循环正常退出（fast 到 null）返回 null。

易错点：第二阶段 p 从「head」出发不是从 head.next；第二阶段的 slow 是「继续从相遇点走」不是重置回头节点；内层循环条件是 p != slow，且先判断再移动——若入口就是相遇点本身（如环在头节点），不移动直接命中。

输入: 3 -> 2 -> 0 -> -4，尾节点指回 2（环入口是 2）
head --2步--> 入口(2) --2步--> 相遇点(-4)
                 ^               |
                 |______ 2步 ____|       即 a=2, b=2, c=2，满足 a=c

第一阶段 快慢指针（slow 1 步、fast 2 步）：
轮0  slow=3,  fast=3
轮1  slow=2,  fast=0
轮2  slow=0,  fast=2
轮3  slow=-4, fast=-4   相遇，确认有环

第二阶段 p 从 head、slow 从相遇点同步走：
轮0  p=3, slow=-4
轮1  p=2, slow=2    相遇！返回节点 2（即环入口）

代码（Java · 力扣官方题解写法）

public class Solution {
    public ListNode detectCycle(ListNode head) {
        // ① 双指针同从头出发
        ListNode slow = head, fast = head;
        // ② fast 走两步，先保证 fast、fast.next 非空
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) { // ③ 相遇：确认有环
                ListNode p = head;           // ③ p 从头出发
                // ③ a = c，两指针同步前进必在入口相遇
                while (p != slow) {
                    p = p.next;
                    slow = slow.next;
                }
                return p;                    // ③ p 即环入口
            }
        }
        // ④ fast 走到 null，无环
        return null;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
