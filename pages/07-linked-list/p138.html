138. 随机链表的复制 中等

标记本题：
链表节点除 next 外还有一个 random 指针，指向链表中任意节点或 null。要求深拷贝整个链表（所有节点必须新建，不能复用原链表的任何节点），并返回新链表的头节点。
示例： 输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]] 输出：[[7,null],[13,0],[11,4],[10,2],[1,0]] 解释：序列化中每个节点用 [val, random下标] 表示——random下标 是该节点 random 指向的节点在链表中的位置（从 0 开始，null 表示不指向任何节点）。输出的序列化结果与输入完全相同，但它必须是一条由全新节点构成的链表（深拷贝），例如新链表中第 2 个节点的 random 应指向新链表中第 1 个节点，而不是原链表的节点。

解题思路

本页代码参照力扣官方题解的写法：方法二「交错复制」（复制节点插在原节点后，三遍循环，O(1) 空间）。

先想清楚两个问题：

Q1：random 指针乱指，怎么找到"复制节点对应的 random 目标"？哈希表能做但费空间。更巧的办法：把每个复制节点直接插在原节点后面，形成 A→A'→B→B' 的交错链——这样"原节点 random 的下一个"恰好就是"复制节点的 random"，不需要任何映射结构。

Q2：三遍循环各自干什么？第一遍只插复制节点（只动 next）；第二遍只设复制节点的 random（利用交错结构）；第三遍把交错链拆成原链和复制链两条。

照着写的 4 步：

① head 为 null 直接返回 null；
② 第一遍：cur 遍历原节点，每轮 new 一个同值节点 copy 插到 cur 后面，cur 跳到 copy.next（即下一个原节点）；
③ 第二遍：cur 步长为 2（cur = cur.next.next）只踩原节点，若 cur.random 非空则 cur.next.random = cur.random.next；
④ 第三遍：每轮取出 copy = cur.next，cur.next = copy.next 恢复原链，copy 依次挂到 dummy 链上，cur 前进；返回 dummy.next。

易错点：第二遍 random 的赋值是「cur.next.random = cur.random.next」不是 cur.random（指向的是复制节点不是原节点）；cur.random 为 null 时「跳过不设」不是设成 null.next（会空指针）；第三遍必须先「cur.next = copy.next 恢复原链」再让 cur 前进，顺序反了会丢节点。

原表: A -> B -> C（A.random=C, B.random=null, C.random=B）

第 1 遍 交错插入：
  cur=A: new A' 插到 A 后，cur 跳到 B
  cur=B: new B' 插到 B 后，cur 跳到 C
  cur=C: new C' 插到 C 后，cur 跳到 null
状态: A -> A' -> B -> B' -> C -> C'

第 2 遍 设 random（只踩原节点，步长 2）：
  cur=A: A.random=C 非空 -> A'.random = C.next = C'
  cur=B: B.random=null   -> 跳过
  cur=C: C.random=B 非空 -> C'.random = B.next = B'

第 3 遍 拆分（每轮：copy=cur.next；cur.next=copy.next；copy 挂新链）：
  cur=A: copy=A'，A.next=B， 新链: A'
  cur=B: copy=B'，B.next=C， 新链: A' -> B'
  cur=C: copy=C'，C.next=null，新链: A' -> B' -> C'

返回: A' -> B' -> C'（random 指向一一对应）

代码（Java · 力扣官方题解写法）

// 题目给定的节点定义：
// class Node { int val; Node next; Node random; ... }
class Solution {
    public Node copyRandomList(Node head) {
        // ① 空表直接返回
        if (head == null) return null;
        // ② 第一遍：每个原节点后插入它的复制节点
        for (Node cur = head; cur != null; ) {
            Node copy = new Node(cur.val);
            copy.next = cur.next;
            cur.next = copy;
            cur = copy.next;         // ② 跳到下一个原节点
        }
        // ③ 第二遍：设置复制节点的 random（cur 步长 2，只踩原节点）
        for (Node cur = head; cur != null; cur = cur.next.next) {
            if (cur.random != null) {
                // ③ random 的"下一个"即对应的复制节点
                cur.next.random = cur.random.next;
            }
        }
        // ④ 第三遍：拆分原链表与复制链表
        Node dummy = new Node(0), tail = dummy;
        for (Node cur = head; cur != null; ) {
            Node copy = cur.next;
            cur.next = copy.next;    // ④ 恢复原链表连接
            tail.next = copy;        // ④ 复制节点接入新链表
            tail = copy;
            cur = copy.next;
        }
        return dummy.next;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)（不含结果链表；哈希表写法为 O(n)）
