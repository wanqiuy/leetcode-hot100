2. 两数相加 中等

标记本题：
两个非空链表按逆序存储一个非负整数（每一位一个节点），返回两数之和的链表（同样逆序存储）。
示例： 输入：l1 = 2->4->3，l2 = 5->6->4（即 342 + 465） 输出：7->0->8（即 807）

解题思路

本页代码参照力扣官方题解的写法：模拟竖式加法（虚拟头 dummy + 进位 carry 逐位推进）。

先想清楚两个问题：

Q1：每一位怎么算？模拟竖式：当前位 sum = l1 的值 + l2 的值 + 上一位的进位 carry；写入结果的数字是 sum % 10，新的进位是 sum / 10。

Q2：循环什么时候停？两表不一样长怎么办？循环条件是 l1 != null || l2 != null || carry != 0——三者有一个成立就得继续，这样既能处理长短不一（走空的表当 0 加），也能处理最高位算完还冒出进位（如 5+5=10 要多写一位）。

照着写的 4 步：

① 建 dummy 和结果尾指针 cur，carry = 0；
② 循环条件 l1 != null || l2 != null || carry != 0：sum 先赋 carry，l1 非空就加 l1.val 并前移，l2 同理；
③ carry = sum / 10，cur.next = new ListNode(sum % 10)，cur 前移；
④ 循环结束 return dummy.next。

易错点：循环条件中间是「||」不是「&&」（短表走完还得继续算长表和进位）；每位 sum 的初始值是「carry」不是 0；判空后再取值，顺序是「先判断非空、再取值、再前移」，不是直接 l1.val。

输入: l1 = 2 -> 4 -> 3（342），l2 = 5 -> 6 -> 4（465）

逐步推演（每位列出：sum 计算 / carry / 结果链状态）：
位0  sum = 0 + 2 + 5 = 7     carry = 0
     dummy -> 7    l1=4, l2=6
位1  sum = 0 + 4 + 6 = 10    写 10%10=0，carry = 1
     dummy -> 7 -> 0    l1=3, l2=4
位2  sum = 1 + 3 + 4 = 8     carry = 0
     dummy -> 7 -> 0 -> 8    l1=null, l2=null
循环条件三者皆假，退出

结果: 7 -> 0 -> 8  （即 807 = 342 + 465，验证通过）

再看一个"多一位"的例子：5 + 5
位0  sum = 0 + 5 + 5 = 10    写 0，carry = 1
位1  l1、l2 均空但 carry=1，sum = 1，写 1
结果: 0 -> 1  （即 10）

代码（Java · 力扣官方题解写法）

class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        // ① 虚拟头 + 尾指针 + 进位
        ListNode dummy = new ListNode(0), cur = dummy;
        int carry = 0;
        // ② 任一表未走完或有进位就继续
        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;                       // ② sum 先带上进位
            if (l1 != null) { sum += l1.val; l1 = l1.next; }
            if (l2 != null) { sum += l2.val; l2 = l2.next; }
            carry = sum / 10;                      // ③ 算新进位
            cur.next = new ListNode(sum % 10);     // ③ 当前位写入新节点
            cur = cur.next;                        // ③ 尾指针前移
        }
        // ④ 真正的头在 dummy.next
        return dummy.next;
    }
}
