23. 合并 K 个升序链表 困难

标记本题：
给定 k 个升序链表，合并为一个升序链表并返回。
示例： 输入：[1->4->5, 1->3->4, 2->6] 输出：1->1->2->3->4->4->5->6

解题思路

本页代码参照力扣官方题解的写法：分治两两合并（区间劈半递归，合并复用第 21 题）。

先想清楚两个问题：

Q1：为什么用分治而不是两两顺序合并？顺序合并（l1+l2 再 +l3……）每条链表要被反复遍历，复杂度 O(N k)；分治两两配对合并，共 log k 轮、每轮总节点数 N，复杂度 O(N log k)。

Q2：分治的递归边界是什么？对数组区间 [l, r] 递归：l == r 时区间里只剩一条链表，直接返回它；否则取中点劈成两半，各自递归后再两两合并。合并逻辑完全复用第 21 题。

照着写的 4 步：

① 入口判空：lists 为 null 或长度为 0 返回 null，否则调 divide(lists, 0, length - 1)；
② divide 递归基：l == r 时 return lists[l]；
③ 取 mid = l + (r - l) / 2，递归求左半 [l, mid]、右半 [mid + 1, r] 的合并结果；
④ return merge(left, right)：dummy + tail 逐节点取较小者接入，剩余整段接上，返回 dummy.next。

易错点：mid 的计算用「l + (r - l) / 2」不是 (l + r) / 2（防溢出习惯）；右半区间是「mid + 1」不是 mid（否则两个元素时区间分不开会死循环）；divide 递归基是「l == r」不是 l > r（区间始终合法，不需要判 l > r）。

输入: [1->4->5, 1->3->4, 2->6]（记为 A, B, C）

分治过程（区间用下标表示）：
divide([0,2]):
  mid=1
  divide([0,1]): mid=0
    divide([0,0]) = A        （递归基，直接返回单链表）
    divide([1,1]) = B
    merge(A,B) = 1->1->3->4->4->5   （记为 AB）
  divide([2,2]) = C
  merge(AB, C):
    逐节点取小：1 -> 1 -> 2 -> 3 -> 4 -> 4 -> 5 -> 6

返回: 1 -> 1 -> 2 -> 3 -> 4 -> 4 -> 5 -> 6

合并轮数 = log k（k=3 时 2 轮），每轮总节点数 N = 8

代码（Java · 力扣官方题解写法）

class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        // ① 空数组直接返回
        if (lists == null || lists.length == 0) return null;
        // ① 对整个区间分治
        return divide(lists, 0, lists.length - 1);
    }
    // 分治：区间 [l, r] 内的链表两两合并
    private ListNode divide(ListNode[] lists, int l, int r) {
        // ② 只剩一条链表，直接返回
        if (l == r) return lists[l];
        // ③ 中点劈半（防溢出写法）
        int mid = l + (r - l) / 2;
        ListNode left = divide(lists, l, mid);       // ③ 左半
        ListNode right = divide(lists, mid + 1, r);  // ③ 右半
        // ④ 合并两半的有序结果
        return merge(left, right);
    }
    private ListNode merge(ListNode l1, ListNode l2) {
        // ④ dummy + tail，逐节点取较小者
        ListNode dummy = new ListNode(0), tail = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
            else { tail.next = l2; l2 = l2.next; }
            tail = tail.next;
        }
        // ④ 剩余部分整体接上
        tail.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}

时间复杂度 O(N log k)（N 为节点总数）· 空间复杂度 O(log k)（递归栈）
