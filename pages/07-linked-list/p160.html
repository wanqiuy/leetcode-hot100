160. 相交链表 简单

标记本题：
给你两个单链表的头节点 headA 和 headB，找出并返回两个链表相交的起始节点；如果不相交返回 null。要求空间复杂度 O(1)。
示例： 输入：A = 4->1->8->4->5，B = 5->6->1->8->4->5（相交于 8） 输出：节点 8

解题思路

先想清楚两个问题：

Q1：两个链表长度不同，怎么让两个指针"对齐"？让 pA 走完 A 表后接着走 B 表，pB 走完 B 表后接着走 A 表。这样两者都走 a+b 步后一定同时到达交点（或同为 null），长度差被抹平。

Q2：不相交时循环会不会死循环？不会。不相交时 pA、pB 最终同时走到 null，pA == pB 成立，循环照样退出，返回 null 恰好就是答案。

照着写的 3 步：

① pA 指向 headA、pB 指向 headB，任一输入为 null 直接返回 null；
② 循环条件 pA != pB：pA 为 null 就跳到 headB、否则走 next；pB 为 null 就跳到 headA、否则走 next；
③ 循环结束后 return pA（要么停在交点，要么是 null）。

易错点：判断条件是「pA != pB」不是「pA == null」；换表时机是「pA 自己走到 null 时跳到对方表头」不是「pA.next 为 null 时跳」（否则少走一步）；返回的是 pA 不是 pA.val。

A: a1 -> a2 -> c1 -> c2 -> c3
B: b1 -> b2 -> b3 -> c1 -> c2 -> c3   （相交于 c1）

逐步推演（每轮列出两指针所在节点）：
轮0  pA=a1     pB=b1
轮1  pA=a2     pB=b2
轮2  pA=c1     pB=b3
轮3  pA=c2     pB=c1
轮4  pA=c3     pB=c2
轮5  pA=null   pB=c3      -> 下一轮 pA 跳到 headB
轮6  pA=b1     pB=null    -> 下一轮 pB 跳到 headA
轮7  pA=b2     pB=a1
轮8  pA=b3     pB=a2
轮9  pA=c1     pB=c1      -> 相等，退出循环，返回 c1
（两指针各走了 a+b 步，路程相等，必在 c1 相遇）

代码（Java）

public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        // ① 边界：任一表为空必不相交
        if (headA == null || headB == null) return null;
        // ① 双指针各从自己的表头出发
        ListNode pA = headA, pB = headB;
        // ② 不相等就继续走；相遇时要么在交点，要么都是 null
        while (pA != pB) {
            pA = (pA == null) ? headB : pA.next; // ② 走完 A 去接 B
            pB = (pB == null) ? headA : pB.next; // ② 走完 B 去接 A
        }
        // ③ pA 即交点（或 null）
        return pA;
    }
}

时间复杂度 O(m+n) · 空间复杂度 O(1)
