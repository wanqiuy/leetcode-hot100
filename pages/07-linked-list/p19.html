19. 删除链表的倒数第 N 个结点 中等

标记本题：
删除链表的倒数第 n 个节点，并返回头节点。要求一次遍历完成。
示例： 输入：1->2->3->4->5，n = 2 输出：1->2->3->5

解题思路

本页代码参照力扣官方题解的写法：一次遍历快慢指针（fast 先走 n+1 步拉开身位）+ 虚拟头 dummy。

先想清楚两个问题：

Q1：删"倒数第 n 个"，怎么一次遍历就找到它？让 fast 先走 n+1 步，领先 slow 共 n+1 个身位；然后两指针同步走，fast 撞 null 时 slow 恰好停在"待删节点的前驱"上——多走的那 1 步就是为了让 slow 停在前驱而不是待删节点本身。

Q2：删掉的是头节点怎么办？在头前面挂一个 dummy 节点，slow、fast 都从 dummy 出发。删头节点时 slow 就停在 dummy 上，照样用 slow.next = slow.next.next 统一处理，返回 dummy.next。

照着写的 4 步：

① 建 dummy 指向 head，fast、slow 都指向 dummy；
② fast 先走 n+1 步；
③ 循环条件 fast != null：fast、slow 同步各走一步；
④ 退出时 slow 是待删节点的前驱，slow.next = slow.next.next 删除，return dummy.next。

易错点：fast 先走的步数是「n+1」不是 n（代码里 for i = 0..n 共 n+1 次），走 n 步 slow 会停在待删节点上而不是前驱；两指针起点是「dummy」不是 head；返回值是「dummy.next」不是 head（头可能被删掉）。

输入: 1 -> 2 -> 3 -> 4 -> 5，n = 2（要删倒数第 2 个，即 4）

挂上 dummy: dummy -> 1 -> 2 -> 3 -> 4 -> 5
            fast、slow 都在 dummy

fast 先走 n+1 = 3 步：
            dummy -> 1 -> 2 -> 3 -> 4 -> 5
            slow           fast（在 3 上）

同步走（每轮列出 fast、slow 位置）：
轮1  fast=4,    slow=1
轮2  fast=5,    slow=2
轮3  fast=null, slow=3    退出循环

slow=3 正是待删节点 4 的前驱：
slow.next = slow.next.next  =>  3 跳过 4 指向 5

返回 dummy.next: 1 -> 2 -> 3 -> 5

代码（Java · 力扣官方题解写法）

class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // ① dummy 挂在头前，统一处理"删头节点"
        ListNode dummy = new ListNode(0, head);
        ListNode fast = dummy, slow = dummy;
        // ② fast 先走 n+1 步，拉开 n+1 个身位
        for (int i = 0; i <= n; i++) fast = fast.next;
        // ③ 同步前进，fast 到 null 时 slow 在待删节点前驱
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }
        // ④ 跳过待删节点，完成删除
        slow.next = slow.next.next;
        return dummy.next;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
