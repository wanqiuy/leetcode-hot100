24. 两两交换链表中的节点 中等

标记本题：
两两交换相邻的节点并返回头节点。不允许只修改节点值，必须改变节点连接。
示例： 输入：1->2->3->4 输出：2->1->4->3

解题思路

先想清楚两个问题：

Q1：交换相邻两个节点要动几条指针？三条：前驱的 next 要指向 b，b.next 要指向 a，a.next 要指向原来 b 后面的节点。少改任何一条链就断了。

Q2：每轮处理完后 pre 移到哪里？交换完成后 a 落到了本对的第二个位置，它就是下一对的前驱，所以 pre = a，继续下一轮。

照着写的 4 步：

① 建 dummy 指向 head，pre = dummy；
② 循环条件 pre.next != null && pre.next.next != null（后面至少还有两个节点才够一对）；
③ 令 a = pre.next、b = a.next，依次执行 a.next = b.next、b.next = a、pre.next = b；
④ pre = a，进入下一轮；循环结束 return dummy.next。

易错点：三条指针的修改顺序是「a.next = b.next → b.next = a → pre.next = b」不能乱（先把 a 摘出去接到后面，再让 b 指向 a，最后前驱指向 b）；循环判断的是「pre.next 和 pre.next.next」不是 pre 自己；pre 更新为「a」不是 b（交换后 a 在后）。

输入: 1 -> 2 -> 3 -> 4
挂上 dummy: dummy -> 1 -> 2 -> 3 -> 4
            pre=dummy, a=1, b=2

第 1 对，三步改指针：
  ① a.next = b.next  ->  1 指向 3
  ② b.next = a       ->  2 指向 1
  ③ pre.next = b     ->  dummy 指向 2
状态: dummy -> 2 -> 1 -> 3 -> 4
pre 移到 a(1)：pre=1, a=3, b=4

第 2 对，同样三步：
状态: dummy -> 2 -> 1 -> 4 -> 3
pre 移到 a(3)，此时 pre.next=null，不足一对，退出

返回 dummy.next: 2 -> 1 -> 4 -> 3

代码（Java）

class Solution {
    public ListNode swapPairs(ListNode head) {
        // ① dummy 挂在头前，第一对也有前驱
        ListNode dummy = new ListNode(0, head);
        ListNode pre = dummy;
        // ② 后面至少剩两个节点才能凑一对
        while (pre.next != null && pre.next.next != null) {
            ListNode a = pre.next;   // ③ 本对第一个节点
            ListNode b = a.next;     // ③ 本对第二个节点
            a.next = b.next;         // ③ a 先接到 b 后面
            b.next = a;              // ③ b 指向 a
            pre.next = b;            // ③ 前驱指向 b，交换完成
            pre = a;                 // ④ a 是下一对的前驱
        }
        return dummy.next;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
