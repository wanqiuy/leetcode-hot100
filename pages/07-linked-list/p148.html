148. 排序链表 中等

标记本题：
将链表按升序排序并返回。要求 O(n log n) 时间复杂度。
示例： 输入：4->2->1->3 输出：1->2->3->4

解题思路

本页代码参照力扣官方题解的写法：自顶向下归并排序（快慢指针找中点劈半 + 合并两个有序链表）。

先想清楚两个问题：

Q1：为什么选归并排序？链表不能 O(1) 随机访问，快排/堆排都不顺手；归并只需要顺序遍历和合并两个有序链表（第 21 题现成），天然 O(n log n)。

Q2：怎么把链表均分成两段？快慢指针：slow 一步、fast 两步，但 fast 从 head.next 出发——这样偶数个节点时 slow 停在前半段末尾（而不是后半段开头），slow.next 就是后半段的头，断开即可。

照着写的 4 步：

① 递归基：head 为 null 或单节点，直接 return head；
② 快慢指针找中点：slow = head、fast = head.next，循环条件 fast != null && fast.next != null，退出后 slow 在前半末尾；
③ mid = slow.next，slow.next = null 断成两段，分别递归 sortList(head) 和 sortList(mid)；
④ merge(left, right) 合并两段有序链表并返回（合并逻辑同第 21 题：dummy + tail 取小者接入，剩余整段接上）。

易错点：fast 的初值是「head.next」不是 head（否则偶数个节点时 slow 会停在后半段开头，两段不均、甚至两个节点时死循环）；断开语句是「slow.next = null」不能漏（不断开递归时左右两段没真正分开）；递归基要同时覆盖「head == null 和 head.next == null」，不是只判 null。

输入: 4 -> 2 -> 1 -> 3

分（每层列出 slow、fast 与断开结果）：
  第1层 sortList(4->2->1->3):
    slow=4, fast=2 -> slow=2, fast=3 -> fast.next=null 退出
    mid = 1，断开: [4->2] 和 [1->3]
  第2层 sortList(4->2): 断成 [4] [2]
         sortList(1->3): 断成 [1] [3]
  第3层 单节点直接返回

治与合（merge 逐节点取小）：
  merge([4],[2])   -> [2->4]
  merge([1],[3])   -> [1->3]
  merge([2->4],[1->3]):
    取1 -> 取2 -> 取3 -> 左空，接4
    -> [1->2->3->4]

返回: 1 -> 2 -> 3 -> 4

代码（Java · 力扣官方题解写法）

class Solution {
    public ListNode sortList(ListNode head) {
        // ① 递归基：空表或单节点天然有序
        if (head == null || head.next == null) return head;
        // ② 快慢指针找中点（fast 先走一步，保证偶数个时 slow 在前半末尾）
        ListNode slow = head, fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        // ③ 断成前后两段，分别递归排序
        ListNode mid = slow.next;
        slow.next = null;
        ListNode left = sortList(head);
        ListNode right = sortList(mid);
        // ④ 合并两个有序链表
        return merge(left, right);
    }
    private ListNode merge(ListNode l1, ListNode l2) {
        // ④ dummy + tail，逐节点取较小者
        ListNode dummy = new ListNode(0), tail = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
            else { tail.next = l2; l2 = l2.next; }
            tail = tail.next;
        }
        // ④ 剩余部分整体接上
        tail.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}

时间复杂度 O(n log n) · 空间复杂度 O(log n)（递归栈；自底向上迭代可降到 O(1)）
