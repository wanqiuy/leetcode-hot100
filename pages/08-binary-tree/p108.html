108. 将有序数组转换为二叉搜索树 简单

标记本题：
给你一个升序整数数组 nums，将其转换为一棵高度平衡的二叉搜索树（每个节点的左右子树高度差不超过 1）。
输入：nums = [-10,-3,0,5,9] 输出：[0,-3,9,-10,null,5]

解题思路

先想清楚两个问题：

Q1：递归函数 build(nums, l, r) 的定义是什么？把闭区间 nums[l..r] 构造成一棵高度平衡 BST，返回这棵子树的根节点。

Q2：根选谁、为什么这样就平衡？选区间中点 mid 为根，左右各分一半递归——两侧节点数最多差 1，高度差自然不超过 1。

照着写的 4 步：

① l > r 返回 null；
② mid = (l+r)/2，用 nums[mid] 建新节点；
③ build(l, mid-1) 接成左子树；
④ build(mid+1, r) 接成右子树，返回新节点。

易错点：区间是闭区间，base case 是 l > r 不是 l == r（l==r 时还剩一个元素要建节点）；左右子区间都要把 mid 本身排除在外，否则会死循环或重复建点。

逐步推演：nums = [-10,-3,0,5,9]（下标 0..4）
build(0,4)：mid=2 → 根 0
  左 build(0,1)：mid=0 → 根 -10，右孩子 build(1,1) → -3
  右 build(3,4)：mid=3 → 根 5，右孩子 build(4,4) → 9

      0
     / \
  -10   5
     \   \
     -3   9
（中点分割 → 左右子树规模差 ≤1，天然平衡）

代码（Java）

class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }
    private TreeNode build(int[] nums, int l, int r) {
        if (l > r) return null;                     // ① 空区间
        int mid = (l + r) / 2;                      // ② 中点作根，保证平衡
        TreeNode node = new TreeNode(nums[mid]);
        node.left = build(nums, l, mid - 1);        // ③ 左半区间建左子树
        node.right = build(nums, mid + 1, r);       // ④ 右半区间建右子树
        return node;                                // ④ 返回子树根
    }
}

时间复杂度 O(n) · 空间复杂度 O(log n)（递归栈，树高）
