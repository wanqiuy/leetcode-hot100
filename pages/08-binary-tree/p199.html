199. 二叉树的右视图 中等

标记本题：
给定一个二叉树的根节点 root，想象自己站在它的右侧，返回从右侧所能看到的节点值（从顶到底）。
输入：root = [1,2,3,null,5,null,4] 输出：[1,3,4]

解题思路

本页代码参照力扣官方题解的写法：BFS 队列逐层展开，取每层最后一个节点。

先想清楚两个问题：

Q1：从右边看到的是每层的哪个节点？每层最右的那个。BFS 按层出队、每层先入左再入右时，最后出队的就是最右节点。

Q2：怎么识别「每层最后一个」？出队循环前固定 size = 当前层节点数，下标 i == size-1 的那个就是。

照着写的 4 步：

① root 为空返回空表，否则 root 入队；
② 队列不空就循环，先记录 size；
③ 循环 size 次出队，i == size-1 时把值加入结果；
④ 非空的左、右孩子依次入队。

易错点：收值条件是 i == size-1 不是 i == 0（先入队左孩子，最后出队的才最靠右）；size 在循环前固定不是循环内动态读；左右孩子入队顺序不能反，反了判定下标也要跟着改。

逐步推演：root = [1,2,3,null,5,null,4]
      1
     / \
    2   3
     \   \
      5   4

第 1 层 size=1：出 1（i=0=size-1）→ 收 1
第 2 层 size=2：出 2（i=0，跳过），出 3（i=1）→ 收 3
第 3 层 size=2：出 5（跳过），出 4 → 收 4
结果 [1,3,4]

代码（Java · 力扣官方题解写法）

class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) {
            return res;                            // ① 空树直接返回
        }
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);                         // ① 根入队
        while (!queue.isEmpty()) {                 // ② 逐层处理
            int size = queue.size();               // ② 固定当前层节点数
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                // ③ 每层最后一个出队的即右视图可见节点
                if (i == size - 1) {
                    res.add(node.val);
                }
                if (node.left != null) queue.offer(node.left);   // ④ 下一层入队
                if (node.right != null) queue.offer(node.right);
            }
        }
        return res;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)。另有 DFS「根 → 右 → 左、每层首访即收集」的写法，见官方题解方法二。
