437. 路径总和 III 中等

标记本题：
给定一个二叉树的根节点 root 和一个整数 targetSum，求该树中「节点值之和等于 targetSum」的路径条数。路径不需要从根开始或到叶子结束，但必须从上往下。
输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8 输出：3（路径 5→3、5→2→1、-3→11）

解题思路

先想清楚两个问题：

Q1：「路径可从任意节点开始」怎么破？前缀和。从根向下维护路径和 cur；若历史链上某处前缀和 = cur - target，则该处到当前节点的路径和恰为 target，出现过几次就有几条。

Q2：哈希表什么时候加、什么时候删？进入子树前把 cur 计入哈希表；左右子树递归完后减一（回溯）——保证表里只有「根到当前节点这条链上」的前缀和。

照着写的 6 步：

① 哈希表预放 (0, 1)：空前缀和 0 出现 1 次；
② 空节点返回 0；
③ cur 累加当前节点值；
④ 答案 += 表中 cur - target 的出现次数；
⑤ cur 入表；
⑥ 递归左右子树累加答案，返回前把 cur 次数减一。

易错点：预放 (0,1) 不能省（否则漏掉「从根开始」的合法路径）；回溯减一在递归「之后」不是之前，顺序反了会污染兄弟子树；路径和用 long 不是 int（节点值 ±10⁹，链长上千会溢出）。

逐步推演：root = [10,5,-3,3,2,null,11,3,-2,null,1]，target = 8
        10
       /  \
      5    -3
     / \     \
    3   2    11
   / \   \
  3  -2   1

到 5：cur=15，15-8=7 不在表 {0,10} → 0 条
到左下 3：cur=18，18-8=10 在表 1 次 → 路径 5→3 ✓
到 2：cur=17，17-8=9 不在 → 0 条
到 1：cur=18，18-8=10 → 路径 5→2→1 ✓
（5 这条链回溯后，表只剩 {0,10,7}）
到 11：cur=10-3+11=18，18-8=10 → 路径 -3→11 ✓
合计 3 条

代码（Java）

class Solution {
    public int pathSum(TreeNode root, int targetSum) {
        Map<Long, Integer> prefix = new HashMap<>();
        prefix.put(0L, 1);   // ① 空前缀和 0 出现 1 次（覆盖从根开始的路径）
        return dfs(root, 0, targetSum, prefix);
    }
    private int dfs(TreeNode node, long cur, int target, Map<Long, Integer> prefix) {
        if (node == null) return 0;                        // ② 空节点无贡献
        cur += node.val;                                   // ③ 累加当前路径和
        // ④ 历史前缀和中 cur-target 出现几次，就有几条合法路径
        int res = prefix.getOrDefault(cur - target, 0);
        prefix.put(cur, prefix.getOrDefault(cur, 0) + 1);  // ⑤ 进入子树前记录
        res += dfs(node.left, cur, target, prefix);        // ⑥ 递归左右子树
        res += dfs(node.right, cur, target, prefix);
        prefix.put(cur, prefix.get(cur) - 1);              // ⑥ 回溯，恢复现场
        return res;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)
