94. 二叉树的中序遍历 简单

标记本题：
给定二叉树的根节点 root，返回它的中序遍历结果（左 → 根 → 右）。
输入：root = [1,null,2,3] 输出：[1,3,2]

解题思路

本页代码参照力扣官方题解的写法：递归中序遍历。

先想清楚两个问题：

Q1：递归函数 inorder(root, res) 的定义是什么？把「以 root 为根的子树」按左 → 根 → 右的顺序，把节点值依次追加进结果列表 res。写代码时只信这个定义即可。

Q2：「左 → 根 → 右」的顺序怎么保证？就靠函数体三行的书写顺序：先递归左子树、再 add 当前节点、最后递归右子树。递归天然用系统栈保存现场，不需要自己开栈。

照着写的 4 步：

① 建结果列表 res，调 inorder(root, res) 后返回 res；
② 空节点直接 return（什么都不收集）；
③ 递归左子树；
④ 把根值 add 进 res，再递归右子树。

易错点：add 必须夹在两次递归「之间」——写在最前面是前序、写在最后是后序，位置决定遍历序；res 作为参数一路传下去，不是每层新建；空节点是 return 不是 add。

逐步推演：root = [1,null,2,3]，即
      1
       \
        2
       /
      3

inorder(1)：左子树为空 → add 1 → 递归右子树 inorder(2)
inorder(2)：递归左子树 inorder(3) → add 2 → 右子树为空
inorder(3)：左空 → add 3 → 右空
收集顺序 1, 3, 2，结果 [1,3,2]

代码（Java · 力扣官方题解写法）

class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();   // ① 结果列表
        inorder(root, res);
        return res;
    }

    private void inorder(TreeNode root, List<Integer> res) {
        if (root == null) {
            return;                              // ② 空节点直接返回
        }
        inorder(root.left, res);                 // ③ 先递归左子树
        res.add(root.val);                       // ④ 再访问根节点
        inorder(root.right, res);                // ④ 最后递归右子树
    }
}

时间复杂度 O(n) · 空间复杂度 O(h)（递归栈，h 为树高）。进阶写法：迭代（显式栈模拟递归）与 Morris 遍历（O(1) 空间），见官方题解方法二、三。
