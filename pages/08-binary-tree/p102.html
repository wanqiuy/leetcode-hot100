102. 二叉树的层序遍历 中等

标记本题：
给你二叉树的根节点 root，返回其节点值的层序遍历（即逐层地、从左到右访问所有节点）。
输入：root = [3,9,20,null,null,15,7] 输出：[[3],[9,20],[15,7]]

解题思路

本页代码参照力扣官方题解的写法：BFS 队列逐层展开。

先想清楚两个问题：

Q1：BFS 队列里混着两层的节点，怎么把「一层」隔开？每轮出队循环前记下 queue.size()，这个数正好是当前层的节点数，本轮只出队这么多个。

Q2：出队一个节点时做什么？值加入本层列表，非空的左右孩子入队（它们属于下一层，留给下一轮）。

照着写的 4 步：

① root 为空返回空表，否则 root 入队；
② 队列不空就循环：记录 size、新建本层列表 level；
③ 循环 size 次：出队收值、非空孩子入队；
④ level 加入结果集。

易错点：size 是在出队循环「之前」一次性读出的固定值，不是在循环内动态读 queue.size()（会因孩子入队而变大）；孩子入队前必须判空，否则会把 null 当节点出队。

逐步推演：root = [3,9,20,null,null,15,7]
      3
     / \
    9  20
      /  \
     15   7

第 1 轮：size=1，出 3 → level=[3]，入 9、20      队列=[9,20]
第 2 轮：size=2，出 9、20 → level=[9,20]，入 15、7  队列=[15,7]
第 3 轮：size=2，出 15、7 → level=[15,7]        队列=[]
结果 [[3],[9,20],[15,7]]

代码（Java · 力扣官方题解写法）

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> ret = new ArrayList<>();
        if (root == null) {
            return ret;                                     // ① 空树直接返回
        }
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);                                  // ① 根入队
        while (!queue.isEmpty()) {                          // ② 逐层处理
            List<Integer> level = new ArrayList<>();
            int currentLevelSize = queue.size();            // ② 先固定当前层节点数
            for (int i = 0; i < currentLevelSize; i++) {    // ③ 只出队 currentLevelSize 个
                TreeNode node = queue.poll();
                level.add(node.val);                        // ③ 收值
                if (node.left != null) queue.offer(node.left);   // ③ 下一层入队
                if (node.right != null) queue.offer(node.right);
            }
            ret.add(level);                                 // ④ 本层入结果
        }
        return ret;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)
