230. 二叉搜索树中第 K 小的元素 中等

标记本题：
给定一个二叉搜索树的根节点 root 和一个整数 k，返回其中第 k 小的元素（从 1 开始计数）。
输入：root = [5,3,6,2,4,null,null,1], k = 3 输出：3

解题思路

本页代码参照力扣官方题解的写法：中序遍历收集成升序数组，直接按下标取第 k 个。

先想清楚两个问题：

Q1：BST 的哪条性质直接给出第 k 小？中序遍历结果就是升序序列——把它完整收集进数组，下标 k-1 处的元素就是第 k 小，不需要排序。

Q2：递归函数 inorder(root, arr) 的定义是什么？把以 root 为根的子树按中序（左 → 根 → 右）把值追加进 arr 并返回 arr；三行代码的顺序就是遍历顺序。

照着写的 4 步：

① 建空数组，调 inorder(root, arr) 收集中序序列；
② 递归：空节点直接返回 arr；
③ 依次递归左子树、add 根值、递归右子树；
④ 返回 nums.get(k - 1)。

易错点：取下标是 k - 1 不是 k（k 从 1 开始计数，数组下标从 0 开始）；递归顺序必须先左后右（反了收集到的是降序）；add 夹在两次递归之间才是中序。

逐步推演：root = [5,3,6,2,4,null,null,1]，k = 3
      5
     / \
    3   6
   / \
  2   4
 /
1

中序展开：inorder(5) → inorder(3) → inorder(2) → inorder(1)
依次收集：1, 2, 3, 4, 5, 6
nums = [1,2,3,4,5,6]
第 k 小 = nums.get(k-1) = nums.get(2) = 3

代码（Java · 力扣官方题解写法）

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        // ① 中序遍历，收集完整升序序列
        ArrayList<Integer> nums = inorder(root, new ArrayList<Integer>());
        // ④ 第 k 小即下标 k-1 处的元素
        return nums.get(k - 1);
    }

    private ArrayList<Integer> inorder(TreeNode root, ArrayList<Integer> arr) {
        if (root == null) {
            return arr;             // ② 空节点直接返回
        }
        inorder(root.left, arr);    // ③ 先递归左子树（更小的一半）
        arr.add(root.val);          // ③ 再收集根值
        inorder(root.right, arr);   // ③ 最后递归右子树
        return arr;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)。想提前结束可用计数器在中序位置数到 k 即返回（O(h+k)）；进阶还有迭代中序与「记录子树节点数」的频繁增删优化，见官方题解方法二、三。
