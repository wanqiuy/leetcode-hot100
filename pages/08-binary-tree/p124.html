124. 二叉树中的最大路径和 困难

标记本题：
二叉树中的路径定义为节点序列中相邻节点间存在边，且同一节点至多出现一次。路径至少含一个节点，不一定经过根。给定根节点 root，返回最大路径和。
输入：root = [-10,9,20,null,null,15,7] 输出：42（路径 15 → 20 → 7）

解题思路

先想清楚两个问题：

Q1：递归函数 gain(node) 返回什么？「以 node 为起点、向父方向延伸」的单边最大增益 = node.val + max(左增益, 右增益)；子树增益为负时按 0 舍弃（不如不走那边）。

Q2：最大路径和在哪里更新？完整路径以 node 为「拐点」：node.val + 左增益 + 右增益，每个节点处更新一次全局 ans。这个值不返回给上层——路径在父节点处不能再分叉。

照着写的 4 步：

① 空节点返回 0；
② 递归求左右增益，分别与 0 取 max（负的舍弃）；
③ ans = max(ans, node.val + left + right)；
④ 返回 node.val + max(left, right)。

易错点：返回给父节点的是「单边」val + max(l, r) 不是 val + l + r（路径不能分叉）；负增益是舍弃（取 0）不是照加；ans 初值是 Integer.MIN_VALUE 不是 0（全负数树答案为负）。

逐步推演：root = [-10,9,20,null,null,15,7]
    -10
    / \
   9  20
     /  \
    15   7

gain(15)=15，gain(7)=7
节点 20：拐点路径 20+15+7=42 → ans=42；gain(20)=20+max(15,7)=35
节点 9：拐点路径 9+0+0=9 → ans 不变；gain(9)=9
节点 -10：拐点路径 -10+9+35=34 → ans 不变；gain(-10)=-10+35=25
答案 42（路径 15 → 20 → 7）

代码（Java）

class Solution {
    private int ans = Integer.MIN_VALUE;
    public int maxPathSum(TreeNode root) {
        gain(root);
        return ans;
    }
    // 返回以 node 为起点、向父方向延伸的单边最大增益
    private int gain(TreeNode node) {
        if (node == null) return 0;                     // ① 空节点增益为 0
        int left = Math.max(0, gain(node.left));        // ② 负增益舍弃，取 0
        int right = Math.max(0, gain(node.right));      // ②
        // ③ 以本节点为拐点的完整路径，更新全局最大
        ans = Math.max(ans, node.val + left + right);
        // ④ 作为父路径的一段只能选一侧向上延伸
        return node.val + Math.max(left, right);
    }
}

时间复杂度 O(n) · 空间复杂度 O(h)
