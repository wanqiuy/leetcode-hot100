101. 对称二叉树 简单

标记本题：
给你一个二叉树的根节点 root，检查它是否轴对称（即左右子树互为镜像）。
输入：root = [1,2,2,3,4,4,3] 输出：true

解题思路

先想清楚两个问题：

Q1：「一棵树轴对称」怎么转化成递归子问题？定义 check(p, q)：判断以 p、q 为根的两棵树是否互为镜像。原问题 = check(root.left, root.right)。

Q2：p、q 互为镜像的判定规则？都空 → true；一空一不空或值不等 → false；否则要求 p.left 与 q.right 镜像 且 p.right 与 q.left 镜像（交叉配对）。

照着写的 4 步：

① 入口对 root 的左右孩子调 check；
② p、q 都为空返回 true；
③ 只有一个为空或值不等返回 false；
④ 返回 check(p.left, q.right) && check(p.right, q.left)。

易错点：递归配对是「左对右、右对左」的交叉配对不是同侧配对；入口传的是 root 的左右孩子不是 root 本身；三种失败判断（一空一不空、值不等）要写在递归之前。

逐步推演：root = [1,2,2,3,4,4,3]
      1
     / \
    2   2
   / \ / \
  3  4 4  3

check(2左, 2右)：值相等 → check(3, 3) && check(4, 4)
check(3, 3)：叶子，左右皆空、值相等 → true
check(4, 4)：同理 true → 整体 true

反例 [1,2,2,null,3,null,3]：
check(2, 2) → check(2左.left=null, 2右.right=3)
一空一不空 → false

代码（Java）

class Solution {
    public boolean isSymmetric(TreeNode root) {
        return check(root.left, root.right);         // ① 从根的左右孩子开始比
    }
    private boolean check(TreeNode p, TreeNode q) {
        if (p == null && q == null) return true;     // ② 都为空 → 镜像
        if (p == null || q == null) return false;    // ③ 一空一不空 → 否
        if (p.val != q.val) return false;            // ③ 值不等 → 否
        // ④ 交叉递归：左的左对右的右，左的右对右的左
        return check(p.left, q.right) && check(p.right, q.left);
    }
}

时间复杂度 O(n) · 空间复杂度 O(h)
