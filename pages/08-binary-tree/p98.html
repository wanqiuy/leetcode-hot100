98. 验证二叉搜索树 中等

标记本题：
给你一个二叉树的根节点 root，判断其是否是一个有效的二叉搜索树（左子树所有值小于根，右子树所有值大于根，且左右子树也都是 BST）。
输入：root = [2,1,3] 输出：true

解题思路

本页代码参照力扣官方题解的写法：递归，上下界（开区间）向下传递。

先想清楚两个问题：

Q1：为什么不能只比较父子节点？BST 的约束来自所有祖先：每个节点都继承一个合法开区间 (lower, upper)。官方用方法重载定义 isValidBST(node, lower, upper)：判断 node 子树是否为 BST 且所有值落在该区间内。

Q2：区间怎么向下传递？左孩子继承 (lower, node.val)，右孩子继承 (node.val, upper)——当前节点的值成为一侧的新边界。

照着写的 4 步：

① 空节点返回 true；
② node.val 不在开区间 (lower, upper) 内，返回 false；
③ 递归查左子树，上界收紧为 node.val；
④ 递归查右子树，下界收紧为 node.val。

易错点：越界判断是 val <= lower || val >= upper（严格开区间，相等也非法）不是 < 和 >；初始边界用 Long 的最值不是 Integer 的（节点值可能恰好等于 int 边界）；判断依据是「值与区间」不是「父与子」。

逐步推演（反例）：root = [5,1,6,null,null,3,7]
      5
     / \
    1   6
       / \
      3   7     ← 3 比父亲 6 小，但违背祖先 5 的约束

isValidBST(5, -∞, +∞)：5 在区间内 ✓
isValidBST(1, -∞, 5)：1 ✓，左右皆空 → true
isValidBST(6, 5, +∞)：6 ✓
isValidBST(3, 5, +∞)：3 <= 5，越界 → false，整棵树 false

代码（Java · 力扣官方题解写法）

class Solution {
    public boolean isValidBST(TreeNode root) {
        return isValidBST(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean isValidBST(TreeNode node, long lower, long upper) {
        if (node == null) {
            return true;                                  // ① 空树合法
        }
        // ② 节点值必须严格落在开区间 (lower, upper) 内
        if (node.val <= lower || node.val >= upper) {
            return false;
        }
        // ③ 左子树上界收紧为当前值
        return isValidBST(node.left, lower, node.val)
            && isValidBST(node.right, node.val, upper);  // ④ 右子树下界收紧为当前值
    }
}

时间复杂度 O(n) · 空间复杂度 O(h)（递归栈，h 为树高）。另可用中序遍历（BST 中序必为严格升序）验证，见官方题解方法二。
