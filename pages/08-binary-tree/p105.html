105. 从前序与中序遍历序列构造二叉树 中等

标记本题：
给定两个整数数组 preorder 和 inorder，分别是同一棵二叉树的前序遍历和中序遍历（无重复元素），请构造并返回这棵二叉树。
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7] 输出：[3,9,20,null,null,15,7]

解题思路

先想清楚两个问题：

Q1：递归函数 build(pre, pl, pr, il, ir) 的定义是什么？用前序区间 [pl,pr] 和中序区间 [il,ir]（二者描述同一棵子树）构造并返回根节点。

Q2：怎么切出左右子树的区间？pre[pl] 必是根；用哈希表查它在中序的位置 k，则左子树共 leftSize = k - il 个节点：前序左半 [pl+1, pl+leftSize]、中序左半 [il, k-1]；右半对称切分。

照着写的 5 步：

① 预处理：哈希表存「中序值 → 下标」；
② pl > pr 返回 null；
③ 取 pre[pl] 建根节点；
④ 查 k、算 leftSize = k - il；
⑤ 按切分区间递归建左、右子树并接上，返回根。

易错点：前序右半起点是 pl + leftSize + 1（跳过根和左子树）不是 k + 1（k 是中序下标，两套下标别混）；leftSize 从中序区间算出不是从前序数；两个区间长度始终相等，可用来自检切分是否写对。

逐步推演：pre = [3, 9, 20, 15, 7]，in = [9, 3, 15, 20, 7]
build(pre[0..4], in[0..4])：根=pre[0]=3，k=1，leftSize=1
  左 build(pre[1..1], in[0..0])：根 9，左右区间皆空 → 叶子
  右 build(pre[2..4], in[2..4])：根=pre[2]=20，k=3，leftSize=1
    左 build(pre[3..3], in[2..2]) → 15
    右 build(pre[4..4], in[4..4]) → 7

      3
     / \
    9  20
      /  \
     15   7

代码（Java）

class Solution {
    private Map<Integer, Integer> indexMap = new HashMap<>();
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        for (int i = 0; i < inorder.length; i++) {
            indexMap.put(inorder[i], i);   // ① 中序值 → 下标，O(1) 定位根
        }
        return build(preorder, 0, preorder.length - 1, 0, inorder.length - 1);
    }
    // pre 区间 [pl, pr]，inorder 区间 [il, ir]，二者是同一棵子树
    private TreeNode build(int[] pre, int pl, int pr, int il, int ir) {
        if (pl > pr) return null;                     // ② 空区间
        TreeNode root = new TreeNode(pre[pl]);        // ③ 前序首元素为根
        int k = indexMap.get(pre[pl]);                // ④ 根在中序中的位置
        int leftSize = k - il;                        // ④ 左子树节点数
        root.left = build(pre, pl + 1, pl + leftSize, il, k - 1);          // ⑤ 左子树
        root.right = build(pre, pl + leftSize + 1, pr, k + 1, ir);         // ⑤ 右子树
        return root;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)
