105. 从前序与中序遍历序列构造二叉树 中等

标记本题：
给定两个整数数组 preorder 和 inorder，分别是同一棵二叉树的前序遍历和中序遍历（无重复元素），请构造并返回这棵二叉树。
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7] 输出：[3,9,20,null,null,15,7]

解题思路

本页代码参照力扣官方题解的写法：递归 + 哈希表 O(1) 定位根在中序中的下标。

先想清楚两个问题：

Q1：递归函数 myBuildTree(preorder, inorder, preorder_left, preorder_right, inorder_left, inorder_right) 的定义是什么？用前序区间 [preorder_left, preorder_right] 和中序区间 [inorder_left, inorder_right]（二者描述同一棵子树）构造并返回根节点。

Q2：怎么切出左右子树的区间？前序区间首元素 preorder[preorder_left] 必是根；用哈希表查它在中序的位置 inorder_root，则左子树共 size_left_subtree = inorder_root - inorder_left 个节点：前序左半 [preorder_left+1, preorder_left+size_left_subtree]、中序左半 [inorder_left, inorder_root-1]；右半对称切分。

照着写的 5 步：

① 预处理：哈希表 indexMap 存「中序值 → 下标」；
② preorder_left > preorder_right 返回 null；
③ 取 preorder[preorder_left] 建根节点；
④ 查 inorder_root、算 size_left_subtree = inorder_root - inorder_left；
⑤ 按切分区间递归建左、右子树并接上，返回根。

易错点：前序右半起点是 preorder_left + size_left_subtree + 1（跳过根和左子树）不是 inorder_root + 1（inorder_root 是中序下标，两套下标别混）；size_left_subtree 从中序区间算出不是从前序数；前序、中序两个区间长度始终相等，可用来自检切分是否写对。

逐步推演：preorder = [3, 9, 20, 15, 7]，inorder = [9, 3, 15, 20, 7]
myBuildTree(pre[0..4], in[0..4])：根=pre[0]=3，inorder_root=1，size_left_subtree=1
  左 myBuildTree(pre[1..1], in[0..0])：根 9，左右区间皆空 → 叶子
  右 myBuildTree(pre[2..4], in[2..4])：根=pre[2]=20，inorder_root=3，size_left_subtree=1
    左 myBuildTree(pre[3..3], in[2..2]) → 15
    右 myBuildTree(pre[4..4], in[4..4]) → 7

      3
     / \
    9  20
      /  \
     15   7

代码（Java · 力扣官方题解写法）

class Solution {
    private Map<Integer, Integer> indexMap;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        int n = preorder.length;
        indexMap = new HashMap<>();
        for (int i = 0; i < n; i++) {
            indexMap.put(inorder[i], i);    // ① 中序值 → 下标，O(1) 定位根
        }
        return myBuildTree(preorder, inorder, 0, n - 1, 0, n - 1);
    }

    // 前序区间 [preorder_left, preorder_right] 与中序区间 [inorder_left, inorder_right] 是同一棵子树
    private TreeNode myBuildTree(int[] preorder, int[] inorder, int preorder_left,
                                 int preorder_right, int inorder_left, int inorder_right) {
        if (preorder_left > preorder_right) {
            return null;                                    // ② 空区间
        }
        int preorder_root = preorder_left;                  // ③ 前序首元素为根
        TreeNode root = new TreeNode(preorder[preorder_root]);
        int inorder_root = indexMap.get(preorder[preorder_root]);  // ④ 根在中序中的位置
        int size_left_subtree = inorder_root - inorder_left;       // ④ 左子树节点数
        // ⑤ 前序左半 [preorder_left+1, preorder_left+size_left_subtree]，中序左半 [inorder_left, inorder_root-1]
        root.left = myBuildTree(preorder, inorder, preorder_left + 1,
                preorder_left + size_left_subtree, inorder_left, inorder_root - 1);
        // ⑤ 前序右半 [preorder_left+size_left_subtree+1, preorder_right]，中序右半 [inorder_root+1, inorder_right]
        root.right = myBuildTree(preorder, inorder, preorder_left + size_left_subtree + 1,
                preorder_right, inorder_root + 1, inorder_right);
        return root;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)（哈希表 + 递归栈）
