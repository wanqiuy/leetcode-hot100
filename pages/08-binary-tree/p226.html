226. 翻转二叉树 简单

标记本题：
给你一棵二叉树的根节点 root，翻转这棵二叉树（每个节点的左右孩子互换），并返回其根节点。
输入：root = [4,2,7,1,3,6,9] 输出：[4,7,2,9,6,3,1]

解题思路

先想清楚两个问题：

Q1：递归函数 invertTree(root) 的定义是什么？把以 root 为根的整棵树翻转（每个节点左右孩子互换），返回翻转后的根——还是 root 自己。

Q2：每个节点做哪两件事？先交换自己的左右孩子，再让（交换后的）左右子树各自递归翻转，子树内部怎么翻不用管。

照着写的 4 步：

① root 为空返回 null；
② 交换 root 的左右孩子；
③ 递归翻转左子树；
④ 递归翻转右子树，返回 root。

易错点：返回的是 root 本身不是新建节点；交换的是孩子指针不是节点值；「先交换再递归」和「先递归再交换」都可以，但本节点这次交换不能省。

逐步推演：root = [4,2,7,1,3,6,9]
     4              4
    / \            / \
   2   7    →     7   2
  / \ / \        / \ / \
 1  3 6  9      9  6 3  1

invertTree(4)：交换 2、7 → 递归 invertTree(7)、invertTree(2)
invertTree(7)：交换 6、9；invertTree(2)：交换 1、3
叶子 9/6/3/1：孩子皆空，交换无效，直接返回自身

代码（Java）

class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;  // ① 空树直接返回
        TreeNode tmp = root.left;       // ② 交换左右孩子
        root.left = root.right;
        root.right = tmp;
        invertTree(root.left);          // ③ 递归翻转左子树
        invertTree(root.right);         // ④ 递归翻转右子树
        return root;                    // ④ 返回翻转后的根（还是 root）
    }
}

时间复杂度 O(n) · 空间复杂度 O(h)
