236. 二叉树的最近公共祖先 中等

标记本题：
给定一个二叉树，找到该树中两个指定节点 p、q 的最近公共祖先（LCA）。允许节点是自身的后代。
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1 输出：3

解题思路

本页代码参照力扣官方题解的写法：递归，dfs 返回「子树是否包含 p 或 q」的布尔值，自底向上锁定 LCA。

先想清楚两个问题：

Q1：递归函数 dfs(root, p, q) 返回值的含义是什么？布尔值：root 的子树中是否含有 p 或 q。ans 用成员变量另存，递归本身只负责向上汇报「找没找到」。

Q2：什么情况下 root 就是 LCA？两种：① 左右子树各含一个（lson && rson）；② root 本身就是 p 或 q，且某一侧子树含另一个（题目允许节点是自身的祖先）。因为判定发生在左右递归「之后」（后序、自底向上），第一个满足条件的 root 就是最近的公共祖先。

照着写的 4 步：

① 空节点返回 false；
② 递归左、右子树得 lson、rson；
③ (lson && rson) 或（root 是 p/q 且 lson || rson）→ ans = root；
④ 返回 lson || rson || root 是 p/q。

易错点：ans 的判定必须写在递归左右子树「之后」（后序），写之前就成了自顶向下、找到的不是最近祖先；dfs 返回值含义是「子树含 p 或 q」不是「找到了 LCA」，LCA 只在③处落袋；官方按值比较 root.val == p.val（题目保证节点值互不相同）。

逐步推演：root = [3,5,1,6,2,0,8,null,null,7,4]
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4

例1 p=5, q=1：节点 5 自身是 p → dfs 返回 true；节点 1 自身是 q → 返回 true
  节点 3：lson=true 且 rson=true → ans=3

例2 p=5, q=4：dfs(4)=true（自身是 q）→ 节点 2 的 rson=true → dfs(2)=true
  节点 5：自身是 p 且 rson=true → ans=5（最近祖先就是它自己）
  节点 3：仅 lson=true，不满足条件 → 答案仍为 5

代码（Java · 力扣官方题解写法）

class Solution {
    private TreeNode ans = null;

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        dfs(root, p, q);
        return ans;
    }

    // 返回 root 的子树中是否含有 p 或 q
    private boolean dfs(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null) {
            return false;                            // ① 空节点不含 p/q
        }
        boolean lson = dfs(root.left, p, q);         // ② 左子树是否含 p/q
        boolean rson = dfs(root.right, p, q);        // ② 右子树是否含 p/q
        // ③ 分居两侧，或自身是其一且另一侧含另一个 → 当前即最近公共祖先
        if ((lson && rson) || ((root.val == p.val || root.val == q.val) && (lson || rson))) {
            ans = root;
        }
        return lson || rson || (root.val == p.val || root.val == q.val);  // ④ 向上汇报
    }
}

时间复杂度 O(n) · 空间复杂度 O(h)（递归栈，h 为树高）。另有「父指针 + 哈希集合」的写法，见官方题解方法二。
