236. 二叉树的最近公共祖先 中等

标记本题：
给定一个二叉树，找到该树中两个指定节点 p、q 的最近公共祖先（LCA）。允许节点是自身的后代。
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1 输出：3

解题思路

先想清楚两个问题：

Q1：递归函数 lowestCommonAncestor(root, p, q) 返回值的含义是什么？「在 root 的子树里找 p、q」：都没找到返回 null；只找到一个返回那个节点；两个都找到返回它们的最近公共祖先。把这个定义想清楚，代码就是直译。

Q2：拿到左右子树的返回后怎么合并？left、right 都非空 → p、q 分居两侧，root 即 LCA；否则答案在非空的那一侧（或都没找到）。

照着写的 5 步：

① root 为空、或 root 就是 p/q → 直接返回 root；
② 递归左子树得 left；
③ 递归右子树得 right；
④ left、right 都非空，返回 root；
⑤ 否则返回非空的一侧。

易错点：命中 p/q 时立即返回、不再向下找（题目允许 p 是 q 的祖先，此时 p 就是 LCA）；「返回值非空」只说明这一侧找到了 p 或 q，不代表已找到 LCA——是不是 LCA 由上层判断；比较的是节点引用 == 不是值相等。

逐步推演：root = [3,5,1,6,2,0,8,null,null,7,4]
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4

例1 p=5, q=1：左子树根 5 命中 p 返回 5，右子树根 1 命中 q 返回 1
  → 节点 3 左右都非空 → LCA = 3

例2 p=5, q=4：左子树根 5 命中 p，直接返回 5（不再向下找 4——
  4 若在 5 的子树里，5 就是 LCA）；右子树没找到返回 null
  → 节点 3 仅左侧非空 → 返回 5

代码（Java）

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // ① 为空、或命中 p/q，直接返回（p/q 可以是自身的祖先）
        if (root == null || root == p || root == q) return root;
        TreeNode left = lowestCommonAncestor(root.left, p, q);    // ② 左子树查找
        TreeNode right = lowestCommonAncestor(root.right, p, q);  // ③ 右子树查找
        if (left != null && right != null) return root;           // ④ 分居两侧，当前即 LCA
        return left != null ? left : right;                       // ⑤ 答案在非空一侧
    }
}

时间复杂度 O(n) · 空间复杂度 O(h)
