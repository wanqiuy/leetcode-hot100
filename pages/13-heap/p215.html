215. 数组中的第 K 个最大元素 中等

标记本题：
给定整数数组 nums 和整数 k，返回数组中第 k 个最大的元素（排序后的第 k 大，不是第 k 个不同元素）。
示例：输入 nums = [3,2,1,5,6,4], k = 2 → 输出 5 输入 nums = [3,2,3,1,2,4,5,5,6], k = 4 → 输出 4

解题思路

先想清楚两个问题：

Q1：要「第 k 大」，用大顶堆还是小顶堆、容量多大？用容量固定为 k 的小顶堆：堆里始终只留「目前见过的最大的 k 个数」，堆顶是这 k 个里最小的——它正好就是第 k 大的候选。容量超过 k 就弹堆顶，保证堆顶门槛越来越高。

Q2：遍历时每个数怎么处理？堆未满 k 个直接放；满了以后，只有当前值比堆顶大才有资格进堆（先 poll 堆顶再 offer），否则直接跳过。遍历结束堆顶即答案。O(n log k)，k 小时远优于全排序；快速选择可平均 O(n)，但堆写法通用、还能应付数据流。

照着写的 4 步：

① 建容量为 k 的小顶堆（PriorityQueue 默认就是小顶堆）；
② 遍历每个数 x：若 heap.size() ＜ k，直接 offer(x)；
③ 否则若 x ＞ heap.peek()，先 poll() 再 offer(x) 替换堆顶；不大于堆顶则跳过；
④ 遍历结束返回 heap.peek()。

易错点：求「第 k 大」用小顶堆不是大顶堆（大顶堆存全部 n 个才弹，退化成 O(n log n)）；替换时先 poll 后 offer 不是先 offer 再 poll（先 offer 堆就超容量了）；堆满后的进入条件是 x > 堆顶不是 x >= 堆顶（相等不必换）。

nums = [3, 2, 1, 5, 6, 4]   k = 2
（堆里只留 2 个最大元素；堆顶在左，堆顶 = 当前第 2 大候选）

读 3: 堆未满 → 入堆     堆 [3]
读 2: 堆未满 → 入堆     堆 [2, 3]        堆顶 2
读 1: 1 ＜ 堆顶 2 → 跳过 堆 [2, 3]
读 5: 5 ＞ 堆顶 2 → 替换 堆 [3, 5]        堆顶 3
读 6: 6 ＞ 堆顶 3 → 替换 堆 [5, 6]        堆顶 5
读 4: 4 ＜ 堆顶 5 → 跳过 堆 [5, 6]

遍历结束，堆顶 = 5 → 第 2 大元素 ✓

代码（Java）

class Solution {
    public int findKthLargest(int[] nums, int k) {
        // ① 小顶堆，容量保持为 k，存「目前最大的 k 个数」
        PriorityQueue<Integer> heap = new PriorityQueue<>(k);
        for (int x : nums) {
            if (heap.size() < k) {
                heap.offer(x);                    // ② 堆未满直接放
            } else if (x > heap.peek()) {
                heap.poll();                      // ③ 挤掉堆里最小的（先弹）
                heap.offer(x);                    // ③ 再放入新值（后插）
            }
        }
        return heap.peek();                       // ④ 堆顶即第 k 大
    }
}

时间复杂度 O(n log k) · 空间复杂度 O(k)
