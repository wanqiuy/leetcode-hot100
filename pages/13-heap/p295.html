295. 数据流的中位数 困难

标记本题：
设计一个数据结构支持：addNum(int num) 从数据流中添加一个整数；findMedian() 返回目前所有元素的中位数（偶数个时取中间两数平均值）。
示例：addNum(1), addNum(2), findMedian() → 1.5 addNum(3), findMedian() → 2.0

解题思路

先想清楚两个问题：

Q1：数据流动态到达，怎么 O(1) 拿到中位数？用两个堆把数据切成两半：大顶堆 left 存较小的一半（堆顶 = 左半最大值），小顶堆 right 存较大的一半（堆顶 = 右半最小值）。中位数只与这两个堆顶有关，findMedian 读堆顶即可。

Q2：怎么维持「左半 ≤ 右半」且两堆大小差 ≤ 1？addNum 固定三步：新数先全进 left；立刻把 left 堆顶挪给 right——保证 left 里所有元素 ≤ right；若此时 right 比 left 多，就把 right 堆顶回挪一个给 left。约定 left 可多存一个：总数为奇数时中位数 = left 堆顶，偶数 = 两堆顶平均。

照着写的 4 步：

① 建大顶堆 left（比较器 (a,b) -> b-a）和小顶堆 right（默认）；
② addNum：left.offer(num)；
③ right.offer(left.poll()) 保证左半 ≤ 右半；若 right.size() ＞ left.size() 则 left.offer(right.poll()) 恢复平衡；
④ findMedian：left 比 right 多则返回 left.peek()，否则返回 (left.peek() + right.peek()) / 2.0。

易错点：left 是大顶堆要传反向比较器，right 是小顶堆用默认，写反整个结构就错；每次 addNum 都必须经过「left → right」的倒手不是直接按大小选堆（倒手同时完成排序与平衡）；奇数时中位数取 left 堆顶不是 right 堆顶（因为约定 left 可多存一个）。

依次 addNum(1), addNum(2), addNum(3)
（left = 大顶堆存较小半，right = 小顶堆存较大半；堆顶在左）

加 1: left=[1] → 倒手 1 给 right=[1] → right 多，回挪
      结果: left=[1]        right=[]
加 2: left=[2,1] → 倒手堆顶 2 给 right
      结果: left=[1]        right=[2]   大小相等，不动
加 3: left=[3,1] → 倒手堆顶 3 给 right=[2,3] → right 多，回挪 2
      结果: left=[2,1]      right=[3]

         left 堆顶 = 2       right 堆顶 = 3
             ↑ 左半最大          ↑ 右半最小

findMedian: 共 3 个（奇数）→ left 堆顶 = 2 ✓
若只加了 1 和 2（偶数）→ (1 + 2) / 2 = 1.5 ✓

代码（Java）

class MedianFinder {
    // ① left 大顶堆存较小一半（可多存一个），right 小顶堆存较大一半
    private PriorityQueue<Integer> left;
    private PriorityQueue<Integer> right;

    public MedianFinder() {
        left = new PriorityQueue<>((a, b) -> b - a);   // 大顶堆
        right = new PriorityQueue<>();                  // 小顶堆
    }

    public void addNum(int num) {
        left.offer(num);                  // ② 新数先进 left
        right.offer(left.poll());         // ③ 倒手：保证左半所有元素 ≤ 右半
        if (right.size() > left.size()) {
            left.offer(right.poll());     // ③ right 多了就回挪，维持差 ≤ 1
        }
    }

    public double findMedian() {
        if (left.size() > right.size()) {
            return left.peek();                       // ④ 奇数个：left 堆顶
        }
        return (left.peek() + right.peek()) / 2.0;    // ④ 偶数个：两堆顶平均
    }
}

时间复杂度 addNum O(log n) / findMedian O(1) · 空间复杂度 O(n)
