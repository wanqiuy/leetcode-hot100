347. 前 K 个高频元素 中等

标记本题：
给定整数数组 nums 和整数 k，返回其中出现频率最高的前 k 个元素（可按任意顺序返回，答案唯一）。
示例：输入 nums = [1,1,1,2,2,3], k = 2 → 输出 [1,2] 输入 nums = [1], k = 1 → 输出 [1]

解题思路

先想清楚两个问题：

Q1：按什么筛选、用什么容器？先 HashMap 统计每个数的频率；再用容量 k 的小顶堆按频率筛选——堆里始终留「频率最高的 k 个」，堆顶是其中频率最低的门槛。

Q2：堆里放什么、比较器怎么写？堆元素用 Map.Entry（键是数字、值是频率），比较器按 entry.getValue()（频率）升序，PriorityQueue 默认小顶。遍历频率表：堆未满直接放；满了后当前频率高于堆顶频率才替换（先 poll 后 offer）。这样只对 m 个不同元素维护大小 k 的堆，O(m log k) 优于全排序 O(m log m)。

照着写的 4 步：

① 遍历 nums，用 HashMap 统计频率（freq.merge(x, 1, Integer::sum)）；
② 建按频率比较的小顶堆：PriorityQueue 比较器取 Map.Entry::getValue；
③ 遍历频率表：堆未满 k 直接 offer；否则当前 entry 频率 ＞ 堆顶频率时先 poll 再 offer；
④ 把堆里 k 个 entry 的 key 依次取出放进数组返回。

易错点：比较器比的是频率 getValue() 不是数字本身 getKey()；求「频率最高」用小顶堆不是大顶堆（小顶堆堆顶是最低门槛，方便淘汰）；替换是先 poll 后 offer 不是先 offer 再 poll。

nums = [1, 1, 1, 2, 2, 3]   k = 2

① 统计频率:  1 → 3 次,  2 → 2 次,  3 → 1 次

②③ 小顶堆（按频率比，容量 2；堆顶在左 = 最低门槛）：
  放入 1(3): 堆未满 → 堆 [1(3)]
  放入 2(2): 堆未满 → 堆 [2(2), 1(3)]     堆顶 = 2(2)
  放入 3(1): 频率 1 ＜ 堆顶频率 2 → 跳过，3 淘汰

④ 堆中剩余 {1(3), 2(2)} → 取出 key

答案 = [1, 2] ✓

代码（Java）

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // ① 统计每个数的出现频率
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) {
            freq.merge(x, 1, Integer::sum);
        }
        // ② 小顶堆：按频率（value）比较，容量 k
        PriorityQueue<Map.Entry<Integer, Integer>> heap =
            new PriorityQueue<>(Comparator.comparingInt(Map.Entry::getValue));
        // ③ 遍历频率表，堆里只留频率最高的 k 个
        for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
            if (heap.size() < k) {
                heap.offer(e);
            } else if (e.getValue() > heap.peek().getValue()) {
                heap.poll();                     // 淘汰堆顶最低门槛（先弹）
                heap.offer(e);                   // 再放入新 entry（后插）
            }
        }
        // ④ 取出堆中 k 个高频元素的 key
        int[] ans = new int[k];
        for (int i = 0; i < k; i++) {
            ans[i] = heap.poll().getKey();
        }
        return ans;
    }
}

时间复杂度 O(n log k) · 空间复杂度 O(n)
