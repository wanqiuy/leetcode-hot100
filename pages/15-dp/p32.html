32. 最长有效括号 困难

标记本题：
给定只含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号子串的长度。
输入：s = "(()())" 输出：6 解释：整个字符串就是有效括号子串

解题思路

本页代码参照力扣官方题解的写法：动态规划，dp[i] 表示以 s[i] 结尾的最长有效括号子串长度。

DP 四件套，想清楚这四个问题就是代码：

① 状态定义：dp[i] = 以 s[i] 结尾的最长有效括号子串长度（以 '(' 结尾必为 0，所以只需处理 s[i] = ')' 的位置）；
② 转移方程：分两种情况——情况一：s[i-1] = '('，形如「...()」，则 dp[i] = dp[i-2] + 2；情况二：s[i-1] = ')'，形如「...))」，跨过 dp[i-1] 那一整段，看更前面的字符 s[i-dp[i-1]-1] 是否为 '('，是则 dp[i] = dp[i-1] + 2 + dp[i-dp[i-1]-2]（把跨过段前面已有的有效段也接上）；
③ 初始化：全 0，以 '(' 结尾的位置天然是 0，无需处理；
④ 遍历顺序：i 从 1 到 n-1 正序，因为 dp[i] 依赖前面的 dp 值；遍历时同步维护最大值。

易错点：① 状态是「以 i 结尾」不是「前 i 个字符中」，以 '(' 结尾必为 0 不是沿用前一个；② 情况二跨段看的下标是 i-dp[i-1]-1，不是简单的 i-1；③ 访问 dp[i-2]、dp[i-dp[i-1]-2] 前必须判断下标 >= 0，越界按 0 算。

示例 s = "(()())"，逐步填 dp 表：
第1步（③初始化）：dp 全 0
第2步（②情况一）：i=2，s[2]=')'，s[1]='(' → dp[2]=dp[0]+2=0+2=2
第3步（②情况一）：i=4，s[4]=')'，s[3]='(' → dp[4]=dp[2]+2=2+2=4
第4步（②情况二）：i=5，s[5]=')'，s[4]=')'，跨过 dp[4]=4 的整段，
   看 s[5-4-1]=s[0]='(' 可配对
   → dp[5]=dp[4]+2+dp[5-4-2]（下标 -1 越界按 0）=4+2+0=6

i =   0  1  2  3  4  5
s =   (  (  )  (  )  )
dp =  0  0  2  0  4  6
答案：max(dp) = 6

代码（Java · 力扣官方题解写法）

class Solution {
    // ① 状态定义：dp[i] = 以 s[i] 结尾的最长有效括号子串长度（以 '(' 结尾必为 0）
    public int longestValidParentheses(String s) {
        int maxans = 0;
        int[] dp = new int[s.length()]; // ③ 初始化：全 0
        for (int i = 1; i < s.length(); i++) { // ④ 遍历顺序：正序，dp[i] 依赖前面的 dp 值
            if (s.charAt(i) == ')') {
                if (s.charAt(i - 1) == '(') {
                    // ② 转移情况一：...() 直接成对，长度 = 前面有效段 + 2
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else if (i - dp[i - 1] - 1 >= 0
                        && s.charAt(i - dp[i - 1] - 1) == '(') {
                    // ② 转移情况二：...))，跨过内部有效段与更前面的 '(' 配对
                    dp[i] = dp[i - 1] + ((i - dp[i - 1]) >= 2 ? dp[i - dp[i - 1] - 2] : 0) + 2;
                }
                maxans = Math.max(maxans, dp[i]);
            }
        }
        return maxans;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)（另有 O(1) 空间的栈/计数法）
