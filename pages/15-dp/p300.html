300. 最长递增子序列 中等

标记本题：
给定整数数组 nums，找到其中最长严格递增子序列的长度（子序列不要求连续）。
输入：nums = [10,9,2,5,3,7,101,18] 输出：4 解释：最长递增子序列是 [2,3,7,101]，长度为 4

解题思路

先想清楚两个问题（O(n²) 写法，另有 O(n log n) 贪心+二分）：

Q1：状态怎么定义？dp[i] = 以 nums[i] 结尾的最长递增子序列长度（注意是「以它结尾」，不是「前 i 个里」）；答案不在最后一格，而是 max(dp)。

Q2：状态怎么转移？dp[i] = max(dp[j] + 1)，其中 j < i 且 nums[j] < nums[i]——nums[i] 接在任何一个比它小的 nums[j] 后面，长度加 1，所有可接位置取最大；初始化每个 dp[i]=1（最差只含自己）；外层 i 正序、内层 j 从 0 到 i-1 枚举前驱。

照着写的 3 步：

① 开长度 n 的 dp 数组，逐格初始化 base case dp[i]=1；
② 按 i 正序遍历，内层枚举前驱 j，若 nums[j] < nums[i] 则用 dp[i] = max(dp[i], dp[j]+1) 填表，同步更新 ans = max(ans, dp[i])；
③ 返回 ans（即 max(dp)）；

易错点：① 状态是「以 nums[i] 结尾」不是「前 i 个元素中」，两者含义不同；② 答案是 dp 数组的最大值，不是 dp[n-1]——最长子序列未必以最后一个元素结尾；③ 每个位置初始值是 1 不是 0。

示例 nums = [10,9,2,5,3,7,101,18]，逐步填 dp 表：
① 初始化：所有 dp[i]=1
② i=3（nums=5）：j=2（2<5）→ dp[3]=dp[2]+1=2
② i=4（nums=3）：j=2（2<3）→ dp[4]=dp[2]+1=2
② i=5（nums=7）：j=2→2，j=3→dp[3]+1=3，j=4→3 → dp[5]=3
② i=6（nums=101）：前面全比它小，最大 dp[5]+1=4 → dp[6]=4
② i=7（nums=18）：j=5（7<18）→ dp[7]=dp[5]+1=4

i       0   1  2  3  4  5   6    7
nums   10   9  2  5  3  7  101  18
dp      1   1  1  2  2  3   4    4
③ 返回 max(dp) = 4（子序列 [2,3,7,101] 或 [2,3,7,18]）

代码（Java）

class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length, ans = 0;
        int[] dp = new int[n]; // ① 开长度 n 的 dp 数组
        for (int i = 0; i < n; i++) { // ② 按 i 正序遍历，dp[i] 依赖前面的 dp[j]
            dp[i] = 1; // ① base case：至少包含自己，长度为 1
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1); // ② 转移方程：接到 j 后面，长度 +1
                }
            }
            ans = Math.max(ans, dp[i]); // 答案是 max(dp)，不是 dp[n-1]
        }
        return ans; // ③ 返回 max(dp)
    }
}

时间复杂度 O(n²)（贪心+二分可降至 O(n log n)） · 空间复杂度 O(n)
