198. 打家劫舍 中等

标记本题：
一排房屋，每家藏有一定现金。不能偷相邻的两家（会触发警报），求最多能偷到的金额。
输入：nums = [2,7,9,3,1] 输出：12 解释：偷第 1、3、5 家，2 + 9 + 1 = 12

解题思路

本页代码参照力扣官方题解的写法：动态规划 + 滚动数组（first、second 滚动代替 dp 数组）。

先想清楚两个问题：

Q1：状态怎么定义？dp[i] = 只考虑前 i+1 家时，能偷到的最大金额；答案在 dp[length-1]。代码不开数组，用滚动变量 first = dp[i-2]、second = dp[i-1] 表达同一含义。

Q2：状态怎么转移？dp[i] = max(dp[i-1], dp[i-2] + nums[i])——第 i 家不偷得 dp[i-1]，偷则前一家不能偷、得 dp[i-2] + nums[i]，两者取大；初始化 first = nums[0]（只考虑第一家）、second = max(nums[0], nums[1])（前两家取大）作 base case，从 i=2 开始正序填。

照着写的 3 步：

① 特判空数组和只有一家的情况，然后初始化滚动变量 first=nums[0]、second=max(nums[0], nums[1])；
② 按正序从 i=2 逐家遍历，用 temp 暂存旧 second，以转移方程 second = max(first + nums[i], second) 填表，再令 first=temp 滚动前进；
③ 返回 second（考虑完全部家的最大金额）；

易错点：① 偷第 i 家时前一家不能偷，所以是 first + nums[i]（first 是 dp[i-2]），不是 second + nums[i]；② 只有一家时要直接返回 nums[0]，否则取 nums[1] 会越界；③ 滚动交换必须用 temp 暂存旧 second，先更新 second 再让 first 接住旧值，顺序不能乱。

示例 nums = [2,7,9,3,1]，逐步滚动填表：
① 初始化：first=2，second=max(2,7)=7
② i=2（x=9）：temp=7，second=max(2+9, 7)=11，first=7
② i=3（x=3）：temp=11，second=max(7+3, 11)=11，first=11
② i=4（x=1）：temp=11，second=max(11+1, 11)=12，first=11

i       0   1   2    3    4
nums    2   7   9    3    1
dp      2   7  11   11   12
③ 返回 12（偷第 1、3、5 家：2+9+1）

代码（Java · 力扣官方题解写法）

class Solution {
    public int rob(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0; // ① 特判：没有房屋可偷
        }
        int length = nums.length;
        if (length == 1) {
            return nums[0]; // ① 特判：只有一家，直接偷
        }
        // ① 初始化：first = dp[i-2]，second = dp[i-1]（前两家取大）
        int first = nums[0], second = Math.max(nums[0], nums[1]);
        for (int i = 2; i < length; i++) { // ② 按正序逐家决策，dp[i] 依赖前两家
            int temp = second;
            // ② 转移方程：偷第 i 家得 first + nums[i]，不偷得 second，取大
            second = Math.max(first + nums[i], second);
            first = temp;
        }
        return second; // ③ 返回考虑完全部家的最大金额
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
