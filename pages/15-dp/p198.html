198. 打家劫舍 中等

标记本题：
一排房屋，每家藏有一定现金。不能偷相邻的两家（会触发警报），求最多能偷到的金额。
输入：nums = [2,7,9,3,1] 输出：12 解释：偷第 1、3、5 家，2 + 9 + 1 = 12

解题思路

先想清楚两个问题：

Q1：状态怎么定义？dp[i] = 只考虑前 i 家时，能偷到的最大金额；答案在考虑完全部家后的最后一格。

Q2：状态怎么转移？dp[i] = max(dp[i-1], dp[i-2] + nums[i])——第 i 家不偷得 dp[i-1]，偷则前一家不能偷、得 dp[i-2] + nums[i]，两者取大；初始化相当于 dp[-2]=dp[-1]=0（代码用滚动变量 a=b=0 起步），正序逐家填。

照着写的 3 步：

① 初始化滚动变量 a=0（dp[i-2]）、b=0（dp[i-1]）作为 base case；
② 按正序逐家遍历，用转移方程 c = max(b, a + x) 填表，滚动更新 a、b；
③ 返回 b（考虑完全部家的最大金额）；

易错点：① 偷第 i 家时前一家不能偷，所以是 dp[i-2] + nums[i]，不是 dp[i-1] + nums[i]；② 比较的是「不偷」和「偷」两种方案，不是相邻两家谁钱多；③ 滚动变量 a、b 初始值是 0，不是 nums[0]，这样第一家自然取到。

示例 nums = [2,7,9,3,1]，逐步填 dp 表：
① 初始化：a=0（dp[i-2]），b=0（dp[i-1]）
② x=2：c=max(b=0, a+2)=2  → a=0,  b=2
② x=7：c=max(b=2, a+7)=7  → a=2,  b=7
② x=9：c=max(b=7, a+9)=11 → a=7,  b=11
② x=3：c=max(11, 7+3)=11  → a=11, b=11
② x=1：c=max(11, 11+1)=12 → a=11, b=12

i       0   1   2    3    4
nums    2   7   9    3    1
dp      2   7  11   11   12
③ 返回 12（偷第 1、3、5 家：2+9+1）

代码（Java）

class Solution {
    public int rob(int[] nums) {
        int a = 0, b = 0; // ① 初始化：a = dp[i-2]，b = dp[i-1]，未经过任何家时为 0
        for (int x : nums) { // ② 按正序逐家遍历决策
            // ② 转移方程：不偷当前家得 b；偷当前家（前一家不能偷）得 a + x，取大
            int c = Math.max(b, a + x);
            a = b;
            b = c;
        }
        return b; // ③ 返回考虑完全部家的最大金额
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
