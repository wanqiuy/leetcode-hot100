152. 乘积最大子数组 中等

标记本题：
给定整数数组 nums，找出乘积最大的连续子数组，返回其乘积。
输入：nums = [2,3,-2,4] 输出：6 解释：子数组 [2,3] 的乘积 6 最大

解题思路

本页代码参照力扣官方题解的写法：动态规划，同时维护 maxF、minF 两个 dp 数组。

先想清楚两个问题：

Q1：状态怎么定义？要维护两个状态：maxF[i] = 以第 i 个元素结尾的连续子数组最大乘积，minF[i] = 以第 i 个元素结尾的最小乘积（负数会把「最小 × 负数」翻转成最大）；答案在 maxF 的最大值 ans。

Q2：状态怎么转移？每个位置的候选有三个：x 自己重新开头、maxF[i-1] × x、minF[i-1] × x——maxF[i] 取三者最大，minF[i] 取三者最小；初始化直接把 nums 拷进两个数组（首元素自成一段）；从 i=1 开始正序填。

照着写的 3 步：

① 开 maxF、minF 两个数组并用 arraycopy 拷入 nums 作为 base case（首格就是 nums[0]）；
② 按正序从 i=1 遍历，用 maxF[i] = max(maxF[i-1]*x, x, minF[i-1]*x)、minF[i] = min(minF[i-1]*x, x, maxF[i-1]*x) 填表；
③ 再扫一遍 maxF 取最大值 ans 返回；

易错点：① 要同时维护最大和最小两个状态，不是只维护最大——负数会让最小值翻转成最大值；② 每步候选有三个：x 自己、maxF[i-1]×x、minF[i-1]×x，不是只比较两个；③ 答案是 maxF 数组的最大值，不是 maxF 最后一格——最大段未必以末尾元素结尾。

示例 nums = [2,3,-2,4]，逐步填表：
① 初始化：maxF = minF = nums 拷贝，首格 maxF[0]=minF[0]=2
② i=1，x=3：maxF[1]=max(2×3, 3, 2×3)=6，minF[1]=min(2×3, 3, 2×3)=3
② i=2，x=-2：maxF[2]=max(6×-2, -2, 3×-2)=-2，minF[2]=min(3×-2, -2, 6×-2)=-12
② i=3，x=4：maxF[3]=max(-2×4, 4, -12×4)=4，minF[3]=min(-12×4, 4, -2×4)=-48

i      0   1    2    3
nums   2   3   -2    4
maxF   2   6   -2    4
minF   2   3  -12  -48
③ 返回 max(maxF) = 6（子数组 [2,3]）

代码（Java · 力扣官方题解写法）

class Solution {
    public int maxProduct(int[] nums) {
        int length = nums.length;
        // ① 状态定义：maxF[i] = 以 i 结尾的最大乘积，minF[i] = 以 i 结尾的最小乘积
        int[] maxF = new int[length];
        int[] minF = new int[length];
        // ① base case：首元素自成一段，直接把 nums 拷进两个数组
        System.arraycopy(nums, 0, maxF, 0, length);
        System.arraycopy(nums, 0, minF, 0, length);
        for (int i = 1; i < length; i++) { // ② 按正序逐个元素决策，依赖 i-1
            // ② 转移方程：x 自己重新开头，或乘上前面的最大/最小段（负数会翻转大小）
            maxF[i] = Math.max(maxF[i - 1] * nums[i], Math.max(nums[i], minF[i - 1] * nums[i]));
            minF[i] = Math.min(minF[i - 1] * nums[i], Math.min(nums[i], maxF[i - 1] * nums[i]));
        }
        int ans = maxF[0];
        for (int i = 1; i < length; i++) {
            ans = Math.max(ans, maxF[i]); // ③ 答案是 max(maxF)，不是最后一格
        }
        return ans;
    }
}

时间复杂度 O(n) · 空间复杂度 O(n)（可改用滚动变量降到 O(1)）
