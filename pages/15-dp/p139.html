139. 单词拆分 中等

标记本题：
给定字符串 s 和字典 wordDict，判断 s 能否被拆分成一个或多个在字典中出现的单词（单词可重复使用）。
输入：s = "leetcode", wordDict = ["leet","code"] 输出：true 解释："leetcode" = "leet" + "code"

解题思路

先想清楚两个问题（布尔型 DP）：

Q1：状态怎么定义？dp[i] = s 的前 i 个字符（s[0..i-1]）能否被成功拆分，布尔值；答案在 dp[n]。

Q2：状态怎么转移？只要存在一个 j < i，使 dp[j] 为 true 且子串 s[j..i-1] 在字典中，则 dp[i] = true——前 j 个能拆、最后一段又是单词，前 i 个就能拆；初始化 dp[0]=true（空串视为可拆分，是递推起点）；i 从 1 到 n 正序、内层 j 从 0 到 i-1 枚举分割点。

照着写的 3 步：

① 开长度 n+1 的布尔 dp 数组并初始化 base case：dp[0]=true，其余默认 false；
② 按 i=1..n 正序遍历，内层枚举分割点 j，若 dp[j] 为 true 且 s.substring(j, i) 在字典中则置 dp[i]=true；
③ 返回 dp[n]；

易错点：① dp 数组长度是 n+1 不是 n，下标 i 表示「前 i 个字符」，不是「第 i 个字符」；② 子串是 s.substring(j, i)，对应 s[j..i-1]，右端不含 i；③ dp[0] 必须是 true 不是 false，否则后面所有位置都无法起步。

示例 s = "leetcode"，字典 = {"leet","code"}，逐步填 dp 表：
① 初始化：dp[0]=T（空串可拆分）
② i=1..3：没有任何 j 使 dp[j]=T 且 s[j..i-1] 在字典 → 全 F
② i=4：j=0，dp[0]=T 且 s[0..3]="leet" 在字典 → dp[4]=T
② i=5..7：无匹配 → 全 F
② i=8：j=4，dp[4]=T 且 s[4..7]="code" 在字典 → dp[8]=T

下标 i   0  1  2  3  4  5  6  7  8
dp       T  F  F  F  T  F  F  F  T
③ 返回 dp[8] = true（"leetcode" = "leet" + "code"）

代码（Java）

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> dict = new HashSet<>(wordDict); // Set 查询 O(1)
        int n = s.length();
        boolean[] dp = new boolean[n + 1]; // ① 开长度 n+1 的 dp 数组
        dp[0] = true; // ① base case：空串视为可拆分，是递推起点
        for (int i = 1; i <= n; i++) { // ② 按 i 正序遍历，dp[i] 依赖前面的 dp[j]
            for (int j = 0; j < i; j++) {
                // ② 转移方程：[0,j) 可拆，且 [j,i) 是字典单词 → [0,i) 可拆
                if (dp[j] && dict.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break; // 找到一种即可
                }
            }
        }
        return dp[n]; // ③ 返回 dp[n]
    }
}

时间复杂度 O(n² · 子串均长) · 空间复杂度 O(n)
