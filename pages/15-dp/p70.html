70. 爬楼梯 简单

标记本题：
每次可以爬 1 或 2 级台阶，爬到 n 级楼梯共有多少种不同的方法？
输入：n = 3 输出：3 解释：1+1+1、1+2、2+1 共 3 种

解题思路

本页代码参照力扣官方题解的写法：动态规划，用滚动变量 p、q、r 代替 dp 数组。

先想清楚两个问题：

Q1：状态怎么定义？dp[i] = 爬到第 i 级台阶的不同方法数；答案在 dp[n]。代码不开数组，用滚动变量 p = dp[i-2]、q = dp[i-1]、r = dp[i] 表达同一含义。

Q2：状态怎么转移？r = p + q，即 dp[i] = dp[i-1] + dp[i-2]——到第 i 级只有两种来法：从第 i-1 级走 1 步，或从第 i-2 级走 2 步；初始化 p=0、q=0、r=1（第 0 级即地面，1 种方法作递推起点）；i 从 1 到 n 正序递推。

照着写的 3 步：

① 初始化滚动变量 p=0、q=0、r=1 作为 base case（r 是第 0 级的方法数）；
② 按正序遍历 i=1..n，每轮依次 p=q、q=r、r=p+q 滚动填表，即转移方程 dp[i]=dp[i-1]+dp[i-2]；
③ 返回 r（即 dp[n]）；

易错点：① 初始化是 p=0、q=0、r=1——r=1 代表地面（第 0 级）的 1 种方法，不是 0；② 每轮三句赋值顺序固定为 p=q、q=r、r=p+q，不能颠倒；③ 数列首两项是 1、2，不是斐波那契的 1、1。

示例 n = 5，逐步滚动填表：
① 初始化：p=0，q=0，r=1（第 0 级：1 种）
② i=1：p=0，q=1，r=0+1=1
② i=2：p=1，q=1，r=1+1=2
② i=3：p=1，q=2，r=1+2=3
② i=4：p=2，q=3，r=2+3=5
② i=5：p=3，q=5，r=3+5=8

台阶 i   1   2   3   4   5
方法数   1   2   3   5   8
③ 返回 r = 8 种

代码（Java · 力扣官方题解写法）

class Solution {
    public int climbStairs(int n) {
        int p = 0, q = 0, r = 1; // ① 初始化：p=dp[i-2]，q=dp[i-1]，r=当前级方法数（第 0 级为 1）
        for (int i = 1; i <= n; i++) { // ② 按正序遍历，当前级依赖前两级
            p = q;
            q = r;
            r = p + q; // ② 转移方程：dp[i] = dp[i-1] + dp[i-2]
        }
        return r; // ③ 返回 dp[n]
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
