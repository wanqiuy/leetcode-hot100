118. 杨辉三角 简单

标记本题：
给定行数 numRows，生成杨辉三角的前 numRows 行。每个数是它左上方和右上方两数之和。
输入：numRows = 5 输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

解题思路

先想清楚两个问题：

Q1：状态怎么定义？第 i 行第 j 个数 row[j]（第 i 行共 i+1 个数），整表逐行存进 res；答案就是 res 整体。

Q2：状态怎么转移？row[j] = 上一行[j-1] + 上一行[j]——每个数由它左上方和右上方两数相加得到；初始化每行首尾（j=0 和 j=i）固定填 1；按行从上到下、行内从左到右填。

照着写的 3 步：

① 开空表 res，逐行开空行 row；
② 按从上到下遍历每一行、从左到右填：首尾初始化 base case 填 1，中间用 row[j] = 上一行[j-1] + 上一行[j] 填表，每行填完加入 res；
③ 返回 res（整个三角）；

易错点：① 第 i 行有 i+1 个数，内层循环条件是 j <= i，不是 j < i；② 首尾填的是 1，不是 0；③ 取的是上一行 res.get(i-1)，不是当前行自己。

示例 numRows = 5，逐行构造：
① 初始化：第0行 = [1]
① 初始化：第1行 = [1,1]（首尾都是 1）
② 第2行 j=1：上1+上1=2 → [1,2,1]
② 第3行 j=1：1+2=3；j=2：2+1=3 → [1,3,3,1]
② 第4行 j=1：1+3=4；j=2：3+3=6；j=3：3+1=4 → [1,4,6,4,1]

最终三角：
        1
      1   1
    1   2   1
  1   3   3   1
1   4   6   4   1
③ 返回 res

代码（Java）

class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>(); // ① 开 res 存整表
        for (int i = 0; i < numRows; i++) { // ② 按行从上到下遍历，当前行依赖上一行
            List<Integer> row = new ArrayList<>();
            for (int j = 0; j <= i; j++) {
                if (j == 0 || j == i) {
                    row.add(1); // ① base case：每行首尾固定填 1
                } else {
                    // ② 转移方程：当前位置 = 上一行左上方 + 上一行右上方
                    row.add(res.get(i - 1).get(j - 1) + res.get(i - 1).get(j));
                }
            }
            res.add(row);
        }
        return res; // ③ 返回整个杨辉三角
    }
}

时间复杂度 O(numRows²) · 空间复杂度 O(1)（不计返回结果）
