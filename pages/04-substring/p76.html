76. 最小覆盖子串 困难

标记本题：
给定字符串 s 和 t，返回 s 中「涵盖 t 所有字符」的最小子串；不存在则返回空串。t 中重复字符必须被同等数量覆盖。
示例： 输入：s = "ADOBECODEBANC", t = "ABC" 输出："BANC"

解题思路

先想清楚两个问题：

Q1：怎么 O(1) 判断当前窗口已覆盖 t？need 数组记录 t 中各字符的需求量（被减成负值表示富余），required 记录「还缺几个字符」；右端每收到一个必需字符就 required--，减到 0 即覆盖，不用每次扫描窗口。

Q2：窗口两端怎么动？右端一直扩张；一旦 required == 0 就进入收缩循环：先更新最短答案，再移出左端字符（移走的是必需字符则 required++），直到不再覆盖，继续右扩。

照着写的五步：

① need[128] 统计 t 的字符需求，required = t.length()；
② 右端 i 扩张：need[c] > 0 说明 c 是必需字符，required--；然后 need[c]--；
③ required == 0 时循环收缩：先更新最短窗口的起点和长度；
④ 左端字符移出：need[left]++，若还回后 > 0 说明移走的是必需字符，required++；left++；
⑤ 扫描结束按起点截取子串；minLen 没更新过则返回空串。

易错点：need[c]-- 对不在 t 中的字符也要执行（变负表示富余），这样收缩时「need > 0」才恰好等价于「移走的是必需字符」；是先更新答案、再移出左端，顺序不能反；结尾判断看 minLen 是否仍为初始最大值，不是看 required。

s = "ADOBECODEBANC", t = "ABC"   need = {A:1, B:1, C:1}, required = 3

i      窗口（left~i）   required  过程
0~5    ADOBEC           0         首次覆盖，窗口长 6 → 记 start=0, minLen=6
       移出 A           1         不再覆盖，停止收缩，继续右扩
6~9    DOBECODEB        1         进来的 B 是还富余（need[B]≤0），仍缺 A
10     DOBECODEBA       0         A 补齐，重新覆盖
       收缩 D,O,B,E     0         均非必需，窗口 [5,10] 长 6，不更短
       移出 C           1         停止收缩
11     ...N             1         N 非必需
12     ...C             0         C 补齐，重新覆盖
       收缩 O,D,E       0         窗口缩到 BANC 长 4 ✓ 记 start=9, minLen=4
       移出 B           1         扫描结束

最短覆盖子串 = BANC

代码（Java）

class Solution {
    public String minWindow(String s, String t) {
        // ① need 统计 t 的字符需求，required = 还缺的字符数
        int[] need = new int[128];
        for (char c : t.toCharArray()) need[c]++;
        int required = t.length();
        int left = 0, start = 0, minLen = Integer.MAX_VALUE;
        char[] ch = s.toCharArray();
        for (int i = 0; i < ch.length; i++) {
            // ② 右端扩张：必需字符才 required--，然后 need 一律减一
            if (need[ch[i]] > 0) required--;
            need[ch[i]]--;
            // ③ 已覆盖 t，循环收缩：先更新答案
            while (required == 0) {
                if (i - left + 1 < minLen) {
                    minLen = i - left + 1;
                    start = left;
                }
                // ④ 移出左端：还回后 >0 说明是必需字符，缺口 +1
                need[ch[left]]++;
                if (need[ch[left]] > 0) required++;
                left++;
            }
        }
        // ⑤ 没更新过说明无解，返回空串
        return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
    }
}

时间复杂度 O(|s| + |t|) · 空间复杂度 O(128) = O(1)
