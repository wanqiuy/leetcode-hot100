76. 最小覆盖子串 困难

标记本题：
给定字符串 s 和 t，返回 s 中「涵盖 t 所有字符」的最小子串；不存在则返回空串。t 中重复字符必须被同等数量覆盖。
示例： 输入：s = "ADOBECODEBANC", t = "ABC" 输出："BANC"

解题思路

本页代码参照力扣官方题解的写法：滑动窗口 + 哈希表计数，用 need/have 判断窗口是否覆盖 t。

先想清楚两个问题：

Q1：怎么 O(1) 判断当前窗口已覆盖 t？用两个哈希表：need 统计 t 中各字符的需求量，window 统计当前窗口内各字符的数量；再维护 cnt 表示「窗口内已满足需求的字符种数」，当 cnt == need.size() 时说明全部覆盖，不用每次扫描窗口逐个比对。

Q2：窗口两端怎么动？右端 right 一直扩张，每纳入一个字符就更新 window 与 cnt；一旦 cnt == need.size() 就进入收缩循环：先更新最短答案，再移出左端字符（某字符数量降回需求以下则 cnt--），直到不再覆盖，继续右扩。

照着写的五步：

① need 统计 t 的字符需求，window 记录窗口计数，left = 0、cnt = 0；
② 右端 right 扩张：字符纳入 window，数量恰好达到需求时 cnt++；
③ cnt == need.size() 时循环收缩：先更新最短窗口的长度和起点；
④ 左端字符移出：数量降回需求以下则 cnt--，left++；
⑤ 扫描结束按起点截取子串；长度没更新过则返回空串。

易错点：cnt++ 的时机是「数量恰好等于需求」（多收不再重复计数），cnt-- 的时机是「移出后数量低于需求」；是先更新答案、再移出左端，顺序不能反；结尾判断看记录的长度是否仍为初始值，不是看 cnt。

s = "ADOBECODEBANC", t = "ABC"   need = {A:1, B:1, C:1}

right    窗口（left~right） cnt   过程
0~5      ADOBEC           3     首次覆盖，窗口长 6 → 记 len=6, start=0
         移出 A           2     不再覆盖，停止收缩，继续右扩
6~9      DOBECODEB        2     进来的 B 已富余，仍缺 A
10       DOBECODEBA       3     A 补齐，重新覆盖
         收缩 D,O,B,E     3     均富余，窗口 [5,10] 长 6，不更短
         移出 C           2     停止收缩
11       ...N             2     N 非必需
12       ...C             3     C 补齐，重新覆盖
         收缩 O,D,E       3     窗口缩到 BANC 长 4 ✓ 记 len=4, start=9
         移出 B           2     扫描结束

最短覆盖子串 = BANC

代码（Java · 力扣官方题解写法）

class Solution {
    public String minWindow(String s, String t) {
        // ① need 统计 t 的字符需求，window 统计窗口内字符数量
        Map<Character, Integer> need = new HashMap<Character, Integer>();
        Map<Character, Integer> window = new HashMap<Character, Integer>();
        for (char c : t.toCharArray()) {
            need.put(c, need.getOrDefault(c, 0) + 1);
        }
        int left = 0, cnt = 0; // cnt：窗口内已满足需求的字符种数
        int len = Integer.MAX_VALUE, start = 0;
        for (int right = 0; right < s.length(); right++) {
            // ② 右端扩张：纳入字符，数量恰好达到需求时 cnt++
            char c = s.charAt(right);
            if (need.containsKey(c)) {
                window.put(c, window.getOrDefault(c, 0) + 1);
                if (window.get(c).equals(need.get(c))) {
                    cnt++;
                }
            }
            // ③ 已覆盖 t，循环收缩：先更新答案
            while (cnt == need.size()) {
                if (right - left + 1 < len) {
                    len = right - left + 1;
                    start = left;
                }
                // ④ 移出左端：数量降回需求以下则 cnt--
                char d = s.charAt(left);
                if (need.containsKey(d)) {
                    if (window.get(d).equals(need.get(d))) {
                        cnt--;
                    }
                    window.put(d, window.get(d) - 1);
                }
                left++;
            }
        }
        // ⑤ 没更新过说明无解，返回空串
        return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
    }
}

时间复杂度 O(|s| + |t|) · 空间复杂度 O(|Σ|)，|Σ| 为字符集大小
