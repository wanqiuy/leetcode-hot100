239. 滑动窗口最大值 困难

标记本题：
给定数组 nums 和滑动窗口大小 k，窗口每次向右移动一位，返回每个窗口中的最大值。
示例： 输入：nums = [1,3,-1,-3,5,3,6,7], k = 3 输出：[3,3,5,5,6,7]

解题思路

本页代码参照力扣官方题解的写法：单调递减双端队列（单调队列），队首永远是当前窗口最大值。

先想清楚两个问题：

Q1：每个窗口重新找最大值是 O(nk)，怎么降？用单调递减双端队列：队首永远是当前窗口最大值；新元素入队前把队尾所有比它小的弹掉（它们再也不可能成为任何后续窗口的最大值），每元素只进出一次，均摊 O(1)。

Q2：队列里存值还是存下标？存下标。既能取出对应值做比较，又能用「队首下标 ≤ i-k」判断它是否已滑出窗口。

照着写的四步：

① 建双端队列（存下标，对应值保持单调递减）和答案数组；
② 遍历 i：弹出队首已滑出窗口的下标（≤ i-k）；
③ 队尾对应值 ≤ nums[i] 的全部弹出，然后 i 入队尾；
④ i ≥ k-1 时窗口已满，队首对应值就是本窗口最大值，写入 ans[i-k+1]。

易错点：判滑出用的是下标比较（peekFirst() <= i-k），不是值比较；顺序是先判滑出、再弹队尾、最后入队，不能乱；答案下标是 i-k+1，不是 i-k。

nums = [1,3,-1,-3,5,3,6,7], k = 3
（队列显示 下标:值，保持单调递减）

i  操作                              队列（下标:值）  窗口          答案
0  入队                               0:1             未满          -
1  1 < 3，弹 0:1，入队               1:3             未满          -
2  -1 < 3，保留，入队尾              1:3, 2:-1       [1,3,-1]      3
3  -3 < -1，保留，入队尾             1:3, 2:-1, 3:-3 [3,-1,-3]     3
4  下标 1 滑出；5 弹 -3,-1,3，入队   4:5             [-1,-3,5]     5
5  3 < 5，保留，入队尾               4:5, 5:3        [-3,5,3]      5
6  6 弹 3、5，入队                   6:6             [5,3,6]       6
7  7 弹 6，入队                      7:7             [3,6,7]       7

ans = [3,3,5,5,6,7]

代码（Java · 力扣官方题解写法）

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        // ① 双端队列：存下标，对应值保持单调递减
        Deque<Integer> deque = new LinkedList<Integer>();
        for (int i = 0; i < k; ++i) { // ① 初始化前 k 个元素
            while (!deque.isEmpty() && nums[i] >= nums[deque.peekLast()]) {
                deque.pollLast();
            }
            deque.offerLast(i);
        }
        int[] ans = new int[n - k + 1];
        ans[0] = nums[deque.peekFirst()]; // ④ 第一个窗口的最大值
        for (int i = k; i < n; ++i) {
            // ③ 队尾对应值比 nums[i] 小的永不可能再当最大值，弹出后入队
            while (!deque.isEmpty() && nums[i] >= nums[deque.peekLast()]) {
                deque.pollLast();
            }
            deque.offerLast(i);
            // ② 队首下标已滑出窗口（≤ i-k），弹出
            while (deque.peekFirst() <= i - k) {
                deque.pollFirst();
            }
            // ④ 窗口已满：队首即本窗口最大值
            ans[i - k + 1] = nums[deque.peekFirst()];
        }
        return ans;
    }
}

时间复杂度 O(n) · 空间复杂度 O(k)
