Dijkstra 最短路径 知识点

Dijkstra 求带权图中单源最短路径：从起点出发，每次用最小堆取出当前距离最小的节点，用它去松弛所有邻居。节点一旦被取出，其最短距离就已确定，不再更新。

核心思想

贪心策略：dist 数组记录起点到各节点的当前最短估计，初始 dist[起点]=0、其余为 ∞。把 (距离, 节点) 放入小顶堆，每次弹出距离最小的节点 u——由于所有边权非负，不存在「绕路更短」的可能，u 的距离就此定死。随后遍历 u 的邻居 v，若 dist[u] + w(u,v) < dist[v] 则更新 dist[v] 并入堆。堆里会残留过期的大距离副本，弹出时用 if (d > dist[u]) continue 跳过即可。

什么时候用

1. 边权非负的带权图，问「起点到某点/所有点的最短路径、最少时间、最小代价」。
2. 网格中每格代价不同、求最小总代价路径（可视为隐式图）。
3. 前提必须是边权非负；有负权边改用 Bellman-Ford（SPFA）。

模板代码（Java）

// 堆优化版 Dijkstra：graph[u] = [[v, w], ...]，返回起点 s 到各点最短距离
int[] dijkstra(List<int[]>[] graph, int n, int s) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[s] = 0;
    // 小顶堆，按距离排序，元素 = {距离, 节点}
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, s});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > dist[u]) continue; // 过期副本，跳过（关键！）
        for (int[] e : graph[u]) { // 松弛所有邻居
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    return dist; // 不可达的节点仍为 Integer.MAX_VALUE
}

图解

4 节点带权图，起点 0：
  0 --2-- 1     边：0→1(2), 0→2(5), 1→2(1), 1→3(4), 2→3(1)
  |       |
  5       4
  |       |
  2 --1-- 3

初始：dist = [0, ∞, ∞, ∞]   堆 = [(0,0)]

第1轮：弹出 (0,0)，节点 0 距离定死 = 0
  松弛：dist[1]=0+2=2，dist[2]=0+5=5
  dist = [0, 2, 5, ∞]        堆 = [(2,1), (5,2)]
第2轮：弹出 (2,1)，节点 1 距离定死 = 2
  松弛：dist[2]=min(5, 2+1)=3，dist[3]=2+4=6
  dist = [0, 2, 3, 6]        堆 = [(3,2), (5,2), (6,3)]
第3轮：弹出 (3,2)，节点 2 距离定死 = 3
  松弛：dist[3]=min(6, 3+1)=4
  dist = [0, 2, 3, 4]        堆 = [(4,3), (5,2), (6,3)]
第4轮：弹出 (4,3)，节点 3 距离定死 = 4，无更优松弛
第5轮：弹出 (5,2)，5 > dist[2]=3，过期跳过
第6轮：弹出 (6,3)，6 > dist[3]=4，过期跳过，堆空结束

最终：dist = [0, 2, 3, 4]，弹出顺序 0 → 1 → 2 → 3（按距离从小到大定死）

复杂度

堆优化版时间 O(E log V)：每条边最多触发一次入堆；空间 O(V + E)。朴素 O(V²) 版适合稠密图，堆优化版适合稀疏图。
