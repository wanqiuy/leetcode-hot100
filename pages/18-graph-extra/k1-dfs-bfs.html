DFS 与 BFS 遍历 知识点

DFS（深度优先）和 BFS（广度优先）是图与网格遍历的两大基本范式：DFS 沿一条路走到底再回溯，BFS 从起点一圈圈向外扩散。几乎所有图论题的搜索部分都由这两个模板演化而来。

核心思想

DFS 用递归（隐式栈）实现：访问当前节点后立刻钻进第一个未访问的邻居，走到底再回退，天然适合枚举所有路径、判断连通性。BFS 用队列实现：起点入队，每次取出队首、把所有未访问邻居入队，节点按「离起点的层数」从小到大被访问，因此第一次到达终点时步数一定最少。

什么时候用

1. 问「最短路径 / 最少步数 / 最少几分钟扩散完」→ 用 BFS（层序即步数）。
2. 问「连不连通 / 存不存在 / 枚举所有方案 / 数连通块个数」→ 用 DFS。
3. 网格题中两者常可互换（如岛屿数量），但涉及「层数」语义的（腐烂扩散、最近距离）必须 BFS。

模板代码（Java）

// ---------- 网格 DFS 模板 ----------
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}}; // 四方向
void dfs(char[][] g, int i, int j) {
    // 1. 越界判断 + 已访问/非法判断
    if (i < 0 || i >= g.length || j < 0 || j >= g[0].length || g[i][j] != '1') return;
    g[i][j] = '0'; // 2. 标记访问（就地标记，省 visited 数组）
    for (int[] d : dirs) dfs(g, i + d[0], j + d[1]); // 3. 四方向递归
}

// ---------- BFS 层序模板 ----------
void bfs(char[][] g, int si, int sj) {
    Queue<int[]> q = new ArrayDeque<>();
    q.offer(new int[]{si, sj});
    g[si][sj] = '0'; // 入队时立刻标记，防止重复入队
    while (!q.isEmpty()) {
        int size = q.size();      // 当前层的节点数
        for (int s = 0; s < size; s++) { // 一层一层处理，层数=步数
            int[] cur = q.poll();
            for (int[] d : dirs) {
                int ni = cur[0] + d[0], nj = cur[1] + d[1];
                if (ni >= 0 && ni < g.length && nj >= 0 && nj < g[0].length && g[ni][nj] == '1') {
                    g[ni][nj] = '0';
                    q.offer(new int[]{ni, nj});
                }
            }
        }
    }
}

图解

3x4 网格，从 (0,0) 出发，数字 = 访问顺序

DFS 访问顺序（一路钻到底再回溯）：
  1  2  3  4
  10 11 12  5
  9  8  7   6
过程：(0,0)→(0,1)→(0,2)→(0,3) 到头 → 向下 (1,3)→(2,3)
      →(2,2)→(2,1)→(2,0) 到头 → 向上 (1,0)→(1,1)→(1,2) 全部走完

BFS 访问顺序（按层一圈圈扩散）：
  1  2  4  7
  2  3  5  8
  3  4  6  9
过程：第0层 {(0,0)} → 第1层 {(0,1),(1,0)} → 第2层 {(0,2),(1,1),(2,0)}
      → 第3层 {(0,3),(1,2),(2,1)} → 第4层 {(1,3),(2,2)} → 第5层 {(2,3)}
关键差异：DFS 序号沿一条蛇形路径递增；BFS 序号按「到起点的曼哈顿距离」分层递增

复杂度

时间 O(m×n)：每个格子最多访问一次；空间 O(m×n)：DFS 递归栈 / BFS 队列最坏情况下装下整个网格。
