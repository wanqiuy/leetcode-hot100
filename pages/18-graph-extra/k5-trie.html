Trie 前缀树 知识点

Trie（前缀树 / 字典树）把一堆字符串按「共享前缀」组织成一棵树：每条从根出发的路径拼出一个前缀，节点上挂 isEnd 标记表示此处是否构成完整单词。插入和查询都只需 O(单词长度)，是字符串前缀匹配问题的专用结构。

核心思想

每个节点含 26 个子指针（小写字母场景）和一个 isEnd 布尔标记。插入单词时从根出发逐字符走，缺节点就新建，走完把末尾节点 isEnd 置 true。search 查完整单词：逐字符走到底且末尾 isEnd 为 true 才算存在；startsWith 查前缀：只需逐字符走到底，不关心 isEnd。共享前缀的单词共用同一段路径，省空间也让前缀查询一步到位。

什么时候用

1. 大量字符串中反复做「前缀匹配 / 自动补全 / 是否存在某单词」。
2. 需要按字典序枚举、或配合回溯在网格中匹配词典（单词搜索 II）。
3. 判断信号：题目给出「词典 / 单词列表」且查询次数多——先建 Trie 再查，远优于逐个字符串比较。

模板代码（Java）

class Trie {
    class Node {
        Node[] next = new Node[26]; // 26 个子指针
        boolean isEnd;              // 是否某单词的结尾
    }
    Node root = new Node();

    public void insert(String word) {        // 插入：逐字符走，缺则新建
        Node cur = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (cur.next[i] == null) cur.next[i] = new Node();
            cur = cur.next[i];
        }
        cur.isEnd = true;                    // 末尾打标记
    }
    public boolean search(String word) {     // 查完整单词：走到底且 isEnd
        Node cur = root;
        for (char c : word.toCharArray()) {
            cur = cur.next[c - 'a'];
            if (cur == null) return false;
        }
        return cur.isEnd;
    }
    public boolean startsWith(String prefix) { // 查前缀：能走到底即可
        Node cur = root;
        for (char c : prefix.toCharArray()) {
            cur = cur.next[c - 'a'];
            if (cur == null) return false;
        }
        return true;
    }
}

图解

依次插入 "app"、"apple"、"bat"（* 表示 isEnd = true）

插入 "app"：root → a → p → p*，沿途新建 3 个节点
  root
   └─ a
       └─ p
           └─ p*          ← "app" 结束标记

插入 "apple"：前 3 个字符 a-p-p 已存在，直接复用！
  从第二个 p 继续新建 l → e*
  root
   └─ a
       └─ p
           └─ p*          ← "app"
               └─ l
                   └─ e*  ← "apple"（共享前缀 a-p-p，只多建 2 个节点）

插入 "bat"：root 下没有 b，从根另开一支 b → a → t*
  root
   ├─ a
   │   └─ p
   │       └─ p*
   │           └─ l
   │               └─ e*
   └─ b
       └─ a
           └─ t*          ← "bat"

查询演示：
  search("app")   → a→p→p 走到底且 isEnd=true  ✓
  search("appl")  → a→p→p→l 走到底但 isEnd=false ✗（它只是前缀）
  startsWith("appl") → 能走到底 ✓
  search("ba")    → b→a 走到底但 isEnd=false ✗

复杂度

insert / search / startsWith 时间均为 O(L)，L 为单词长度，与词典规模无关；空间 O(所有单词字符总数 × 26)，共享前缀可显著省空间。
