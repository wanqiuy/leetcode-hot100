拓扑排序 知识点

拓扑排序处理「有先后依赖关系」的任务排序问题：给定有向无环图（DAG），输出一个满足所有依赖的线性顺序；如果图中有环，则不存在合法顺序——因此它也是判环的标准手段。

核心思想

Kahn 算法（BFS 版）：入度为 0 的节点没有任何前置依赖，可以直接摘走；摘掉后它的邻居入度减 1，可能产生新的入度 0 节点。不断重复直到队列为空。如果摘走的节点数等于总节点数，说明无环且得到了合法顺序；否则剩下的节点都在环上，拓扑排序不存在。

什么时候用

1. 题目出现「先修 / 前置 / 依赖 / 先后顺序」等关键词，要求给出顺序或判断能否完成。
2. 需要判断有向图是否有环。
3. 需要按依赖层级逐层处理（如课程按学期安排）。

模板代码（Java）

// Kahn 算法：numCourses = n，prerequisites[i] = [a, b] 表示先修 b 才能学 a
public boolean canFinish(int n, int[][] prerequisites) {
    // 第一步：建图 + 入度表
    List<Integer>[] g = new List[n];
    for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
    int[] indeg = new int[n];
    for (int[] p : prerequisites) {
        g[p[1]].add(p[0]); // b -> a
        indeg[p[0]]++;
    }
    // 第二步：所有入度 0 的节点入队
    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++)
        if (indeg[i] == 0) q.offer(i);
    // 第三步：出队，邻居入度 -1，减到 0 再入队
    int cnt = 0; // 已摘走的节点数（需要顺序时用 List 记录出队顺序）
    while (!q.isEmpty()) {
        int u = q.poll();
        cnt++;
        for (int v : g[u])
            if (--indeg[v] == 0) q.offer(v);
    }
    return cnt == n; // 摘完有剩 = 有环
}

图解

课程表例子：4 门课，依赖 [[1,0],[2,1],[3,1],[3,2]]
含义：学 1 先学 0；学 2 先学 1；学 3 先学 1 和 2
图：0 → 1 → 2 → 3，另有 1 → 3

初始入度表：indeg = [0, 1, 1, 2]   队列 = [0]

第1轮：出队 0，cnt=1
  邻居 1：indeg[1] 1→0，入队      indeg = [0, 0, 1, 2]   队列 = [1]
第2轮：出队 1，cnt=2
  邻居 2：indeg[2] 1→0，入队
  邻居 3：indeg[3] 2→1，不入队    indeg = [0, 0, 0, 1]   队列 = [2]
第3轮：出队 2，cnt=3
  邻居 3：indeg[3] 1→0，入队      indeg = [0, 0, 0, 0]   队列 = [3]
第4轮：出队 3，cnt=4，队列空

出队顺序：0 → 1 → 2 → 3，cnt == n == 4，无环，可以完成所有课程
若存在依赖 [0,3]（学 0 先学 3），则 0/1/2/3 入度都 ≥1，队列为空 cnt=0，直接判有环

复杂度

时间 O(V + E)：每个节点入出队一次，每条边松弛一次；空间 O(V + E)：邻接表 + 入度数组 + 队列。
