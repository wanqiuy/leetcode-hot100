并查集 知识点

并查集（Union-Find）是一种维护「元素分组」的数据结构：每个节点记录自己的祖宗，find 查询根、union 合并两个集合，配合路径压缩后单次操作近乎 O(1)，专门高效回答动态连通性问题。

核心思想

用 parent 数组表示森林：parent[i] 是 i 的父节点，根节点的父节点是自己。find(x) 沿父指针一路找到根，并在回溯时把路径上的节点直接挂到根下（路径压缩），树高被压到接近 1。union(x, y) 先各自 find 出根，若根不同则把一个根挂到另一个根下，两个集合即合并。判断 x、y 是否连通，只需比较 find(x) == find(y)。

什么时候用

1. 题目反复问「两个元素连不连通」「图里有几个连通块 / 省份 / 岛屿」。
2. 边是一条条动态加入的（离线加边、冗余连接、最小生成树 Kruskal）。
3. 不需要求具体路径，只需要连通性结论——要路径请用 DFS/BFS。

模板代码（Java）

class UnionFind {
    int[] parent;
    int count; // 连通块个数

    UnionFind(int n) {           // 初始化：每个节点自成一派
        parent = new int[n];
        count = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    int find(int x) {            // 找根 + 路径压缩
        if (parent[x] != x)
            parent[x] = find(parent[x]); // 递归路上全部指向根
        return parent[x];
    }
    void union(int x, int y) {   // 合并两集合
        int rx = find(x), ry = find(y);
        if (rx == ry) return;    // 已连通，无需合并
        parent[rx] = ry;
        count--;                 // 连通块少一个
    }
    boolean connected(int x, int y) { return find(x) == find(y); }
}

图解

6 个节点 0~5，依次执行 union(0,1)、union(1,2)、union(3,4)

初始：parent = [0, 1, 2, 3, 4, 5]   每个节点是自己的根，count=6

union(0,1)：find(0)=0, find(1)=1，根 0 挂到根 1 下
  parent = [1, 1, 2, 3, 4, 5]   count=5     结构：1 ← 0

union(1,2)：find(1)=1, find(2)=2，根 1 挂到根 2 下
  parent = [1, 2, 2, 3, 4, 5]   count=4     结构：2 ← 1 ← 0（链长 2）

union(3,4)：find(3)=3, find(4)=4，根 3 挂到根 4 下
  parent = [1, 2, 2, 4, 4, 5]   count=3     结构：{2←1←0}、{4←3}、{5}

find(2)：2 本身是根，直接返回 2，无压缩
find(0) 路径压缩前后对比：
  压缩前：0 → 1 → 2，走 2 步，parent = [1, 2, 2, 4, 4, 5]
  压缩后：0 直接挂到根 2 下，parent = [2, 2, 2, 4, 4, 5]
  下次 find(0) 只需 1 步；树被压平，后续查询近乎 O(1)

复杂度

路径压缩后单次 find / union 均摊 O(α(n))，α 为反阿克曼函数，实际可视为 O(1)；空间 O(n)。

关联题目：200. 岛屿数量（并查集思路：每个 '1' 与右、下邻居 union，最终 count 即岛屿数）；推荐练习：547 省份数量、684 冗余连接
