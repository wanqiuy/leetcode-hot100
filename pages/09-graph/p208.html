208. 实现 Trie (前缀树) 中等

标记本题：
实现前缀树的三个方法：insert(word) 插入单词、search(word) 查询完整单词是否存在、startsWith(prefix) 查询是否存在以 prefix 开头的单词。
insert("apple"); search("apple") → true; search("app") → false; startsWith("app") → true

解题思路

本页代码参照力扣官方题解的写法：每个节点存 26 个子槽位 + isEnd 结束标记。

先想清楚两个问题：

Q1：Trie 节点里存什么？每个节点只存两样东西：26 个子节点槽位 children[26]（下标 ch-'a' 对应字母）和一个布尔 isEnd 标记「是否有单词恰好在这里结束」。字符本身由「从父节点走哪条边过来」隐含表示。

Q2：search 和 startsWith 的区别在哪？两者都先沿字符路径逐层走到底；区别只在终点判断——search 要求末节点 isEnd 为 true（存在完整单词），startsWith 只要能走到底（末节点非空）就行。

照着写的 4 步：

① 定义节点结构：Trie[] children = new Trie[26]，boolean isEnd；
② insert：从根出发逐字符走，槽位为空就新建节点，走完把末节点 isEnd 置 true；
③ 抽公共方法 searchPrefix：逐字符走，途中槽位为空返回 null，走完返回末节点；
④ search 返回 node!=null 且 node.isEnd；startsWith 返回 node!=null。

易错点：search 是「node!=null 且 isEnd」不是只判 node!=null（否则 "app" 会命中只插过 "apple" 的树）；插入时是「没有才新建」不是每次都新建（否则覆盖已有分支）。

逐步推演：insert("app") 再 insert("apple")
插入 "app"：root → 建 a → 建 p → 建 p，末尾 isEnd=true
插入 "apple"：root → a 已存在复用 → p 复用 → p 复用
             → 建 l → 建 e，e 的 isEnd=true
最终结构：
root
 └─ a
     └─ p
         └─ p(★"app")
             └─ l
                 └─ e(★"apple")
search("app")：走到第二个 p，isEnd=true → true
search("ap")：走到第一个 p，isEnd=false → false
startsWith("ap")：能走到底 → true

代码（Java · 力扣官方题解写法）

class Trie {
    // ① 节点结构：26 个槽位 + 结束标记
    private Trie[] children;
    private boolean isEnd;

    public Trie() {
        children = new Trie[26];
        isEnd = false;
    }

    // ② 插入：逐字符走，缺节点就建，末尾打标记
    public void insert(String word) {
        Trie node = this;
        for (int i = 0; i < word.length(); i++) {
            int index = word.charAt(i) - 'a';
            if (node.children[index] == null) node.children[index] = new Trie();
            node = node.children[index];
        }
        node.isEnd = true;
    }
    // ③ 公共方法：沿路径走到底，返回末节点（走不通返回 null）
    private Trie searchPrefix(String prefix) {
        Trie node = this;
        for (int i = 0; i < prefix.length(); i++) {
            int index = prefix.charAt(i) - 'a';
            if (node.children[index] == null) return null;
            node = node.children[index];
        }
        return node;
    }
    // ④ search 要求末节点是单词结尾；startsWith 只要求走到底
    public boolean search(String word) {
        Trie node = searchPrefix(word);
        return node != null && node.isEnd;
    }
    public boolean startsWith(String prefix) {
        return searchPrefix(prefix) != null;
    }
}

时间复杂度 O(L)（L 为字符串长度） · 空间复杂度 O(所有插入字符串的字符总数)
