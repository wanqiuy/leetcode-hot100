207. 课程表 中等

标记本题：
共 numCourses 门课，prerequisites[i]=[a,b] 表示学 a 前必须先修 b，判断能否完成所有课程（等价于判断有向图是否有环）。
输入：numCourses=2, prerequisites=[[1,0]] 输出：true

解题思路

先想清楚两个问题：

Q1：「能否完成所有课程」等价于什么图论问题？等价于判断有向图是否有环：有环则互相依赖永远学不完。用 Kahn 拓扑排序——不断摘掉「没有先修要求」（入度为 0）的课。

Q2：怎么判断有环？统计成功弹出的课程数 done：若 done==numCourses 说明所有课都被摘掉、无环；若队列提前空了但还有课没弹出，说明剩下的课互相成环。

照着写的 4 步：

① 建邻接表 adj 和入度数组 indeg：对每条 [a,b] 加边 b→a 且 indeg[a]++；
② 把所有 indeg 为 0 的课入队；
③ 循环弹出课程 cur（done++），把它的每个后继 next 的入度减 1，减到 0 就入队；
④ 返回 done==numCourses。

易错点：边的方向是 b→a（先修课指向后修课）不是 a→b；入队时机是入度减到 0 的那一刻不是发现入度为 0 就重复入队。

逐步推演：numCourses=2, prerequisites=[[1,0]]
① 建图：0→1，indeg=[0,1]
② 入度0的课入队：q=[0]
③ 弹出 0（done=1），后继 1 的入度 1→0，入队 q=[1]
   弹出 1（done=2），无后继
④ done=2=numCourses → 返回 true
反例：若 prerequisites=[[1,0],[0,1]]，indeg=[1,1]，
② 没有入度0的课，队列空，done=0≠2 → 返回 false

代码（Java）

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> adj = new ArrayList<>();
        int[] indeg = new int[numCourses];
        for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());
        // ① 建图：边 b→a，a 的入度+1
        for (int[] p : prerequisites) {
            adj.get(p[1]).add(p[0]);
            indeg[p[0]]++;
        }
        Queue<Integer> q = new ArrayDeque<>();
        // ② 入度为 0 的课先入队
        for (int i = 0; i < numCourses; i++)
            if (indeg[i] == 0) q.offer(i);
        int done = 0;
        // ③ 弹出课程，后继入度减 1，减到 0 再入队
        while (!q.isEmpty()) {
            int cur = q.poll(); done++;
            for (int next : adj.get(cur))
                if (--indeg[next] == 0) q.offer(next);
        }
        // ④ 全部弹出 = 无环
        return done == numCourses;
    }
}

时间复杂度 O(V+E) · 空间复杂度 O(V+E)
