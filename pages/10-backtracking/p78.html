78. 子集 中等

标记本题：
给定不含重复元素的数组 nums，返回所有可能的子集（含空集，顺序不限）。
输入：[1,2,3] 输出：[[],[1],[1,2],[1,2,3],[1,3],[2],[2,3],[3]]

解题思路

先想清楚两个问题：

Q1：子集和全排列的回溯有什么区别？子集不讲究顺序、每个元素最多选一次，所以每进入一个递归节点，当前 path 本身就是一个合法子集，进节点就收集；不需要等到固定长度。

Q2：怎么保证不重复（[1,2] 和 [2,1] 算同一个）？用 start 参数限定「只能从 start 往后选」，递归时传 i+1，永远不回头选前面的元素，组合自然不重复。

照着写的 4 步：

① 进入递归第一件事：把当前 path 拷贝一份加入答案（每个节点都是子集，包括空集）；
② 循环 i 从 start 到 n-1；
③ 做选择：path.add(nums[i])，递归 backtrack(i+1)；
④ 撤销选择：path.remove(末尾)，继续枚举下一个。

易错点：收集答案是在循环外、进节点就收集不是只在叶子收集；递归传的是 i+1 不是 i（元素不可重复选）；撤销选择写在递归之后不是之后什么都不做。

逐步推演：nums=[1,2,3]
backtrack(start=0)：path=[] → 收集 []
  选1 → path=[1] → backtrack(start=1)：收集 [1]
    选2 → path=[1,2] → backtrack(start=2)：收集 [1,2]
      选3 → path=[1,2,3] → backtrack(start=3)：收集 [1,2,3]
      撤销3 → path=[1,2]
    撤销2 → path=[1]
    选3 → path=[1,3] → 收集 [1,3]；撤销3 → path=[1]
  撤销1 → path=[]
  选2 → path=[2] → 收集 [2]；选3 → 收集 [2,3]；撤销3、撤销2
  选3 → path=[3] → 收集 [3]
共 8 个子集

代码（Java）

class Solution {
    List<List<Integer>> ans = new ArrayList<>();
    public List<List<Integer>> subsets(int[] nums) {
        backtrack(nums, 0, new ArrayList<>());
        return ans;
    }
    private void backtrack(int[] nums, int start, List<Integer> path) {
        // ① 每个递归节点都是一个合法子集，进节点就收集
        ans.add(new ArrayList<>(path));
        // ② 从 start 开始枚举，保证不回头
        for (int i = start; i < nums.length; i++) {
            // ③ 做选择，递归时传 i+1
            path.add(nums[i]);
            backtrack(nums, i + 1, path);
            // ④ 撤销选择（回溯）
            path.remove(path.size() - 1);
        }
    }
}

时间复杂度 O(n·2ⁿ) · 空间复杂度 O(n)
