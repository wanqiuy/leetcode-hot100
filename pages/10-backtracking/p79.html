79. 单词搜索 中等

标记本题：
在 m×n 字符网格中搜索单词 word，相邻字符须上下左右相连，同一格子不可重复使用。
输入：board=[["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word="ABCCED" 输出：true

解题思路

先想清楚两个问题：

Q1：整体策略是什么？以每个格子为起点做 DFS 回溯：当前格匹配 word[k] 后，向四方向递归匹配 word[k+1]；只要某条路径把 k 推到 word.length() 就成功。

Q2：「同一格子不能重复使用」怎么落地？走过的格子先存下原字符再临时改成 '#'（做选择），四个方向都递归完后改回原字符（撤销选择/恢复现场），这样同一条路径内不会回头踩自己，换条路径又能正常使用。

照着写的 5 步：

① 主函数双重循环，每个格子都当一次起点，dfs 成功即返回 true；
② dfs 终止条件：k==word.length() 返回 true；越界或当前格不等于 word[k] 返回 false；
③ 做选择：暂存 b[i][j] 到 t，把 b[i][j] 改成 '#'；
④ 向上下左右递归 dfs(k+1)，用 || 短路合并结果；
⑤ 撤销选择：把 b[i][j] 改回 t，返回结果。

易错点：改 '#' 是在递归之前不是之后（否则路径会回头踩自己）；恢复现场是无论成功与否都要执行不是只在失败时恢复；先判 k==len 再判越界也可以，但越界判断必须在访问 b[i][j] 之前。

逐步推演：board 如下，word="ABCCED"
A B C E
S F C S
A D E E
从 (0,0) 出发：A==word[0] ✓，置'#'
 → 右 (0,1) B ✓ 置'#' → 右 (0,2) C ✓ 置'#'
   → 右 (0,3) E≠C ✗；上越界；左是'#' ✗
   → 下 (1,2) C ✓ 置'#'
     → 下 (2,2) E ✓ 置'#'
       → 左 (2,1) D ✓，k=6=len，返回 true
沿途每层把 '#' 恢复回原字符，最终返回 true

代码（Java）

class Solution {
    public boolean exist(char[][] board, String word) {
        // ① 每个格子都当起点试一次
        for (int i = 0; i < board.length; i++)
            for (int j = 0; j < board[0].length; j++)
                if (dfs(board, word, i, j, 0)) return true;
        return false;
    }
    private boolean dfs(char[][] b, String w, int i, int j, int k) {
        // ② 终止条件：全部匹配成功 / 越界 / 当前格不匹配
        if (k == w.length()) return true;
        if (i < 0 || j < 0 || i >= b.length || j >= b[0].length) return false;
        if (b[i][j] != w.charAt(k)) return false;
        // ③ 做选择：暂存原字符并标记已走过
        char t = b[i][j];
        b[i][j] = '#';
        // ④ 四方向递归匹配下一个字符
        boolean ok = dfs(b, w, i+1, j, k+1) || dfs(b, w, i-1, j, k+1)
                  || dfs(b, w, i, j+1, k+1) || dfs(b, w, i, j-1, k+1);
        // ⑤ 撤销选择：恢复现场
        b[i][j] = t;
        return ok;
    }
}

时间复杂度 O(mn·4^L)（L 为单词长度） · 空间复杂度 O(L)
