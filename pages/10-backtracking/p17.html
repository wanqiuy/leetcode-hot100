17. 电话号码的字母组合 中等

标记本题：
给定仅含数字 2-9 的字符串，按电话按键映射返回所有可能的字母组合。
输入："23" 输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]

解题思路

先想清楚两个问题：

Q1：第 i 层递归干什么？第 i 层只负责第 i 个数字：查映射表拿到它对应的字母串，逐个字母尝试拼到当前串末尾，然后交给第 i+1 层处理下一个数字。

Q2：什么时候收集、怎么回溯？i 走到 digits.length() 说明每位都选好了，收集当前串；用 StringBuilder 做路径，递归返回后 deleteCharAt 删掉刚拼的字母即完成撤销。

照着写的 4 步：

① 建映射表 MAP（下标即数字），空串直接返回空答案；
② 终止条件：i==digits.length()，把 sb.toString() 加入答案并 return；
③ 做选择：枚举 MAP[digits[i]] 的每个字母 c，sb.append(c)，递归 backtrack(i+1)；
④ 撤销选择：sb.deleteCharAt(末尾)。

易错点：入口要特判空串不是直接递归（否则会得到 [""]）；撤销是 deleteCharAt(length-1) 不是清空 sb；每层只处理一个数字不是一次处理完所有数字。

逐步推演：digits="23"（2→abc，3→def）
sb="" → 第0层处理 '2'：
  选a → sb="a" → 第1层处理 '3'：
    选d → sb="ad"，i=2 到底，收集 "ad"；撤销d → sb="a"
    选e → 收集 "ae"；撤销e
    选f → 收集 "af"；撤销f
  撤销a → sb=""
  选b → sb="b" → 依次收集 "bd","be","bf"；撤销b
  选c → 依次收集 "cd","ce","cf"
共 9 个组合

代码（Java）

class Solution {
    // ① 数字到字母的映射表
    private static final String[] MAP = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    public List<String> letterCombinations(String digits) {
        List<String> ans = new ArrayList<>();
        if (digits.isEmpty()) return ans; // ① 特判空串
        backtrack(digits, 0, new StringBuilder(), ans);
        return ans;
    }
    private void backtrack(String digits, int i, StringBuilder sb, List<String> ans) {
        // ② 每位都选完，收集
        if (i == digits.length()) { ans.add(sb.toString()); return; }
        // ③ 做选择：枚举当前数字对应的每个字母，递归下一位
        for (char c : MAP[digits.charAt(i) - '0'].toCharArray()) {
            sb.append(c);
            backtrack(digits, i + 1, sb, ans);
            // ④ 撤销选择（回溯）
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}

时间复杂度 O(4ⁿ)（n 为数字个数，7/9 对应 4 个字母） · 空间复杂度 O(n)
