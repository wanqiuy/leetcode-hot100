22. 括号生成 中等

标记本题：
给定 n 对括号，生成所有合法（正确匹配）的括号组合。
输入：n=3 输出：["((()))","(()())","(())()","()(())","()()()"]

解题思路

先想清楚两个问题：

Q1：怎么保证生成的括号串一定合法？逐位放置时守住两条规则：左括号只要还有剩余（open<n）就能放；右括号只有当 close<open 时才能放——这样任意前缀里右括号都不多于左括号，天然合法，无需事后校验。

Q2：什么时候收集？串长达到 2n 时收集。状态只需 open、close 两个计数器加一个 StringBuilder 路径。

照着写的 4 步：

① 终止条件：sb.length()==2n，收集 sb.toString() 并 return；
② 若 open<n：做选择 append('(')，递归 backtrack(open+1, close)，撤销 deleteCharAt；
③ 若 close<open：做选择 append(')')，递归 backtrack(open, close+1)，撤销 deleteCharAt；
④ 入口调用 backtrack(n, 0, 0, sb, ans)。

易错点：放右括号的条件是 close<open 不是 close<n（否则会出现 ")(" 这类非法前缀）；两个 if 是并列不是 if-else（同一层可能两种都能放）；每次递归后都要 deleteCharAt 撤销不是只撤销一次。

逐步推演：n=2
sb="", open=0, close=0：只能放左 → sb="(", open=1
  open<2 → 放左 → sb="((", open=2
    open=2 不能放左；close<open → 放右 → sb="(()", close=1
      只能放右 → sb="(())", 长度=4，收集 "(())"；撤销 → sb="(()"
    撤销 → sb="("
  close=0<open=1 → 放右 → sb="()", close=1
    放左 → sb="()(", open=2
      放右 → sb="()()", 收集；撤销
    撤销左；close=1 不小于 open=1，不能放右
    撤销右 → sb="("
  撤销 → sb=""
共收集 ["(())","()()"]

代码（Java）

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> ans = new ArrayList<>();
        // ④ 从 open=0, close=0 开始
        backtrack(n, 0, 0, new StringBuilder(), ans);
        return ans;
    }
    private void backtrack(int n, int open, int close, StringBuilder sb, List<String> ans) {
        // ① 长度够 2n，收集
        if (sb.length() == 2 * n) { ans.add(sb.toString()); return; }
        // ② 左括号有剩余就能放：做选择 → 递归 → 撤销
        if (open < n) {
            sb.append('(');
            backtrack(n, open + 1, close, sb, ans);
            sb.deleteCharAt(sb.length() - 1);
        }
        // ③ 右括号不超过左括号才能放：做选择 → 递归 → 撤销
        if (close < open) {
            sb.append(')');
            backtrack(n, open, close + 1, sb, ans);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}

时间复杂度 O(4ⁿ/√n)（第 n 个卡特兰数） · 空间复杂度 O(n)
