39. 组合总和 中等

标记本题：
给定无重复元素的候选数组（每个数字可以无限次使用），求所有和为 target 的组合。
输入：candidates=[2,3,6,7], target=7 输出：[[2,2,3],[7]]

解题思路

先想清楚两个问题：

Q1：「每个数字可无限次用」和「组合不重复」怎么同时满足？递归时传 i 而不是 i+1（当前数还能再选），同时循环从 start 开始（不回头选更小的数），这样既允许重复又不会产生 [2,3] 和 [3,2] 两种顺序。

Q2：怎么剪枝？先排序，循环中若 nums[i]>remain 直接 break——数组有序，后面的数更大，都不可能凑出 remain。

照着写的 4 步：

① 排序 candidates；
② 终止条件：remain==0，拷贝 path 收集并 return；
③ 循环 i 从 start 开始：若 nums[i]>remain 则 break 剪枝；否则做选择 path.add(nums[i])，递归 backtrack(remain-nums[i], i)；
④ 撤销选择：path.remove(末尾)。

易错点：递归传的是 i 不是 i+1（这是「可重复选」的关键）；剪枝是 break 不是 continue（有序数组后面只会更大）；收集条件是 remain==0 不是 remain<=0 之后再判断。

逐步推演：candidates=[2,3,6,7]（已排序），target=7
path=[], remain=7：
  选2 → path=[2], remain=5
    选2 → path=[2,2], remain=3
      选2 → path=[2,2,2], remain=1：2>1 break，本层无解
      撤销2 → path=[2,2]
      选3 → path=[2,2,3], remain=0 → 收集 [2,2,3]；撤销3
      6>3 break
    撤销2 → path=[2]
    选3 → path=[2,3], remain=2：3>2 break
    撤销3；6>5 break
  撤销2 → path=[]
  选3 → path=[3], remain=4：选3 → remain=1，3>1 break；撤销；6>4 break
  撤销3
  选6 → path=[6], remain=1：6>1 break；撤销6
  选7 → path=[7], remain=0 → 收集 [7]
答案：[[2,2,3],[7]]

代码（Java）

class Solution {
    List<List<Integer>> ans = new ArrayList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        // ① 排序，为剪枝做准备
        Arrays.sort(candidates);
        backtrack(candidates, target, 0, new ArrayList<>());
        return ans;
    }
    private void backtrack(int[] nums, int remain, int start, List<Integer> path) {
        // ② 凑满 target，收集
        if (remain == 0) { ans.add(new ArrayList<>(path)); return; }
        for (int i = start; i < nums.length; i++) {
            // ③ 剪枝：有序数组，后面都超界；否则做选择并递归（传 i 允许重复选）
            if (nums[i] > remain) break;
            path.add(nums[i]);
            backtrack(nums, remain - nums[i], i, path);
            // ④ 撤销选择（回溯）
            path.remove(path.size() - 1);
        }
    }
}

时间复杂度 O(指数级，取决于解的数量) · 空间复杂度 O(target)
