131. 分割回文串 中等

标记本题：
把字符串 s 分割成若干子串，使每个子串都是回文串，返回所有可能的分割方案。
输入："aab" 输出：[["a","a","b"],["aa","b"]]

解题思路

本页代码参照力扣官方题解的写法：动态规划预处理回文表 + 回溯枚举所有分割。

先想清楚两个问题：

Q1：每层递归的「选择」是什么？每层从当前起点 i 枚举终点 j：s[i..j] 这段是回文才有资格切下来放入路径，然后递归处理下一段起点 j+1；i 走到 n 说明整串切完，收集方案。

Q2：怎么避免重复判回文？先用 DP 预处理回文表 f[i][j] 表示 s[i..j] 是否回文：转移 f[i][j] = (s[i]==s[j]) && f[i+1][j-1]，i 从大到小填表（依赖更短的子串先算出来）；初始全部置 true，单字符和空串天然回文。回溯时 O(1) 查表即可。

照着写的 4 步：

① DP 预处理：f 全部初始化 true，i 从 n-1 递减、j 从 i+1 到 n-1，按转移方程填表；
② dfs 终止条件：i==n，拷贝 ans 收集并 return；
③ 枚举 j 从 i 到 n-1：若 f[i][j] 为真，做选择 ans.add(s.substring(i, j+1))，递归 dfs(j+1)；
④ 撤销选择：ans.remove(末尾)；f[i][j] 为假直接试更长的切法。

易错点：填表顺序是 i 从大到小不是从小到大（转移依赖 f[i+1][j-1]，要保证更短的子串先算好）；初始化全 true 不是全 false（让 f[i+1][j-1] 在 j=i+1 时落在空串上为 true）；substring(i, j+1) 右端是开区间，递归传 j+1；收集时拷贝一份不是直接 add(ans)。

逐步推演：s="aab"，n=3
① DP 填表（初始化全 true，i 从大到小）：
   i=1：j=2，s[1]='a'≠s[2]='b' → f[1][2]=false
   i=0：j=1，s[0]==s[1] 且 f[1][0]=true → f[0][1]=true
        j=2，s[0]='a'≠s[2]='b' → f[0][2]=false
   回文表 f：      j=0  j=1  j=2
              i=0  T    T    F
              i=1  .    T    F
              i=2  .    .    T
② 回溯：dfs(0)，ans=[]：
  j=0：f[0][0]=T → 切 "a" → dfs(1)
    j=1：f[1][1]=T → 切 "a" → dfs(2)
      j=2：f[2][2]=T → 切 "b" → dfs(3)=n，收集 ["a","a","b"]
    j=2：f[1][2]=F，跳过
  j=1：f[0][1]=T → 切 "aa" → dfs(2)
    j=2：切 "b" → dfs(3)，收集 ["aa","b"]
  j=2：f[0][2]=F，跳过
答案：[["a","a","b"],["aa","b"]]

代码（Java · 力扣官方题解写法）

class Solution {
    boolean[][] f;
    List<List<String>> ret = new ArrayList<>();
    List<String> ans = new ArrayList<>();
    int n;

    public List<List<String>> partition(String s) {
        n = s.length();
        // ① DP 预处理回文表：初始全 true（空串/单字符天然回文）
        f = new boolean[n][n];
        for (int i = 0; i < n; i++) Arrays.fill(f[i], true);
        for (int i = n - 1; i >= 0; i--)
            for (int j = i + 1; j < n; j++)
                f[i][j] = (s.charAt(i) == s.charAt(j)) && f[i + 1][j - 1];
        dfs(s, 0);
        return ret;
    }

    private void dfs(String s, int i) {
        // ② 切到末尾，收集方案
        if (i == n) {
            ret.add(new ArrayList<>(ans));
            return;
        }
        // ③ 枚举终点 j：s[i..j] 是回文才切
        for (int j = i; j < n; j++) {
            if (f[i][j]) {
                ans.add(s.substring(i, j + 1));
                dfs(s, j + 1);
                // ④ 撤销选择（回溯）
                ans.remove(ans.size() - 1);
            }
        }
    }
}

时间复杂度 O(n·2ⁿ) · 空间复杂度 O(n²)（DP 回文表）
