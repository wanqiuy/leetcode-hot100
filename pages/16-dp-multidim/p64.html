64. 最小路径和 中等

标记本题：
给定 m×n 的非负整数网格，从左上角到右下角每次只能向右或向下走，求路径上数字之和的最小值。
输入：grid = [[1,3,1],[1,5,1],[4,2,1]] 输出：7 解释：路径 1→3→1→1→1 的和为 7

解题思路

本页代码参照力扣官方题解的写法：二维动态规划，dp[i][j] 表示到达 (i,j) 的最小路径和。

DP 四件套，想清楚这四个问题就是代码：

① 状态定义：dp[i][j] = 从左上角走到格子 (i, j) 的最小路径数字和；
② 转移方程：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])——只能从上方或左方来，选较小的那条路，再加上当前格子的数字；
③ 初始化：dp[0][0] = grid[0][0]；第一行、第一列是前缀和，因为它们只有一个方向能来（第一行只能从左来，第一列只能从上来）；
④ 遍历顺序：按行从上到下、每行从左到右，因为 dp[i][j] 依赖上方和左方。

易错点：① 第一行、第一列是累加前缀和，不是只填 grid 单格的值；② 每个格子要加上 grid[i][j] 自己，不是只取 min；③ 边界行列单独初始化，主循环从 i=1、j=1 开始，不是从 0。

示例 grid = [[1,3,1],[1,5,1],[4,2,1]]，逐步填 dp 表：
第1步（③初始化）：dp[0][0]=1
   第一行：dp[0][1]=1+3=4，dp[0][2]=4+1=5
   第一列：dp[1][0]=1+1=2，dp[2][0]=2+4=6
第2步（②转移）：dp[1][1]=5+min(dp[0][1]=4, dp[1][0]=2)=5+2=7
第3步（②转移）：dp[1][2]=1+min(5,7)=6；dp[2][1]=2+min(7,6)=8
第4步（②转移）：dp[2][2]=1+min(dp[1][2]=6, dp[2][1]=8)=1+6=7

grid =       dp =
1 3 1        1  4  5
1 5 1   →    2  7  6
4 2 1        6  8 [7]
答案：dp[2][2] = 7（路径 1→3→1→1→1）

代码（Java · 力扣官方题解写法）

class Solution {
    // ① 状态定义：dp[i][j] = 到达 (i,j) 的最小路径和
    public int minPathSum(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0; // 特判空网格
        }
        int rows = grid.length, columns = grid[0].length;
        int[][] dp = new int[rows][columns];
        dp[0][0] = grid[0][0]; // ③ 初始化：起点
        for (int i = 1; i < rows; i++) dp[i][0] = dp[i - 1][0] + grid[i][0]; // ③ 初始化：第一列前缀和
        for (int j = 1; j < columns; j++) dp[0][j] = dp[0][j - 1] + grid[0][j]; // ③ 初始化：第一行前缀和
        for (int i = 1; i < rows; i++) { // ④ 遍历顺序：从上到下、从左到右，依赖上方和左方
            for (int j = 1; j < columns; j++) {
                // ② 转移方程：上方/左方较小者 + 当前格子
                dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
            }
        }
        return dp[rows - 1][columns - 1];
    }
}

时间复杂度 O(m×n) · 空间复杂度 O(m×n)（可原地改写 grid 降到 O(1)）
