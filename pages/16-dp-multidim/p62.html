62. 不同路径 中等

标记本题：
机器人位于 m×n 网格左上角，每次只能向右或向下走一步，问到达右下角共有多少条不同路径。
输入：m = 3, n = 7 输出：28

解题思路

本页代码参照力扣官方题解的写法：二维动态规划，f[i][j] 表示到达格子 (i,j) 的路径数。

DP 四件套，想清楚这四个问题就是代码：

① 状态定义：f[i][j] = 到达格子 (i, j) 的不同路径总数；
② 转移方程：f[i][j] = f[i-1][j] + f[i][j-1]——每次只能向右或向下走，所以到 (i,j) 只能从上方 (i-1,j) 或左方 (i,j-1) 来，两路路径数相加；
③ 初始化：第一行和第一列全为 1，因为只能一直向右（或一直向下）走，只有 1 种走法；
④ 遍历顺序：按行从上到下、每行从左到右，因为 f[i][j] 依赖上方和左方，这两个方向必须先算好。

易错点：① 第一行、第一列初始化为 1，不是 0；② 双重循环从 i=1、j=1 开始，不是从 0（避免越界且边界已填好）；③ 返回 f[m-1][n-1]，注意下标减 1。

示例 m=3, n=7，逐步填表：
第1步（③初始化）：第一行全 1，第一列全 1
第2步（②转移）：f[1][1]=f[0][1]+f[1][0]=1+1=2
第3步（②转移）：f[1][2]=f[0][2]+f[1][1]=1+2=3，同理填完第 2 行
第4步（②转移）：f[2][1]=f[1][1]+f[2][0]=2+1=3，同理填完第 3 行

填表结果：
  1   1   1   1   1   1   1
  1   2   3   4   5   6   7
  1   3   6  10  15  21 [28]
答案：f[2][6] = 28

代码（Java · 力扣官方题解写法）

class Solution {
    // ① 状态定义：f[i][j] = 到达格子 (i,j) 的不同路径数
    public int uniquePaths(int m, int n) {
        int[][] f = new int[m][n];
        for (int i = 0; i < m; i++) f[i][0] = 1; // ③ 初始化：第一列只能一路向下，仅 1 种走法
        for (int j = 0; j < n; j++) f[0][j] = 1; // ③ 初始化：第一行只能一路向右，仅 1 种走法
        for (int i = 1; i < m; i++) { // ④ 遍历顺序：从上到下、从左到右，依赖上方和左方
            for (int j = 1; j < n; j++) {
                f[i][j] = f[i - 1][j] + f[i][j - 1]; // ② 转移方程：上方来 + 左方来
            }
        }
        return f[m - 1][n - 1];
    }
}

时间复杂度 O(m×n) · 空间复杂度 O(m×n)（可压缩到 O(n)）
