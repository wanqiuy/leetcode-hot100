1143. 最长公共子序列 中等

标记本题：
给定两个字符串 text1 和 text2，返回它们最长公共子序列的长度（子序列不要求连续，但保持相对顺序）。
输入：text1 = "abcde", text2 = "ace" 输出：3 解释：最长公共子序列是 "ace"

解题思路

DP 四件套，想清楚这四个问题就是代码：

① 状态定义：dp[i][j] = text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度；
② 转移方程：若 text1[i-1] == text2[j-1]，这个字符可以同时纳入子序列，dp[i][j] = dp[i-1][j-1] + 1；若不相等，只能舍弃其中一个字符，取 dp[i-1][j] 与 dp[i][j-1] 的较大者；
③ 初始化：第 0 行、第 0 列全为 0——空串与任何串的公共子序列长度都是 0；
④ 遍历顺序：i 从 1 到 m、j 从 1 到 n，从上到下、从左到右，因为 dp[i][j] 依赖上方、左方和左上方。

易错点：① dp 数组大小是 (m+1)×(n+1)，不是 m×n——多出的一行一列留给空串；② 比较字符时用 text1[i-1]、text2[j-1]，下标比 dp 小 1；③ 字符不等时取 max(dp[i-1][j], dp[i][j-1]) 两项，不含 dp[i-1][j-1]（已被前两者覆盖）。

示例 text1 = "abcde"（行），text2 = "ace"（列），逐步填表：
第1步（③初始化）：第 0 行、第 0 列全 0
第2步（②转移）：i=1（a）：j=1，a==a → dp[1][1]=dp[0][0]+1=1；
   j=2、3 不等 → 取左/上较大 = 1
第3步（②转移）：i=3（c）：j=2，c==c → dp[3][2]=dp[2][1]+1=1+1=2
第4步（②转移）：i=5（e）：j=3，e==e → dp[5][3]=dp[4][2]+1=2+1=3

       ""  a  c  e
  ""    0  0  0  0
  a     0  1  1  1
  b     0  1  1  1
  c     0  1  2  2
  d     0  1  2  2
  e     0  1  2 [3]
答案：dp[5][3] = 3（LCS 为 "ace"）

代码（Java）

class Solution {
    // ① 状态定义：dp[i][j] = text1 前 i 个与 text2 前 j 个字符的 LCS 长度
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m + 1][n + 1]; // ③ 初始化：第 0 行第 0 列全 0（空串 LCS 为 0）
        for (int i = 1; i <= m; i++) { // ④ 遍历顺序：从上到下、从左到右，依赖上/左/左上
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1; // ② 转移：字符相等，同时纳入子序列
                } else {
                    // ② 转移：字符不等，舍弃其中一个，取两种舍弃的较大值
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[m][n];
    }
}

时间复杂度 O(m×n) · 空间复杂度 O(m×n)（可压缩到 O(min(m,n))）
