5. 最长回文子串 中等

标记本题：
给定字符串 s，返回 s 中最长的回文子串。
输入：s = "babad" 输出："bab" 解释："aba" 同样是有效答案

解题思路

DP 四件套，想清楚这四个问题就是代码（区间 DP）：

① 状态定义：dp[i][j] = 子串 s[i..j] 是否为回文串，布尔值；
② 转移方程：当 s[i] == s[j] 且（子串长度 ≤ 2，或内部 s[i+1..j-1] 已是回文即 dp[i+1][j-1] = true）时，dp[i][j] = true——两端相等、内部又是回文，整段就是回文；
③ 初始化：单个字符都是回文（代码中 len 从 2 开始，len ≤ 2 的分支天然覆盖了 len = 1、2 的情况，无需单独填对角线）；
④ 遍历顺序：必须按子串长度 len 从小到大填表，因为长串 dp[i][j] 依赖更短的内部子串 dp[i+1][j-1]，短串必须先算出来；填表时同步记录最长回文的起点 start 和长度 maxLen。

易错点：① 遍历顺序是按长度从小到大，不是常规的先行后列——否则 dp[i+1][j-1] 还没算出来；② len <= 2 的特殊判断不能少，「aa」两端相等即为回文，无需看内部；③ 答案记录的是起点和长度，最后 substring 取出，不是返回 dp 值。

示例 s = "babad"，逐步填表（T = 回文）：
第1步（③初始化）：len=1：所有 dp[i][i]=T（单字符必回文）
第2步（②转移，len=2）："ba""ab""ba""ad" 两端均不等 → 无新增
第3步（②转移，len=3）："bab"：s[0]==s[2] 且内部 dp[1][1]=T → dp[0][2]=T，记 start=0, len=3
            "aba"：s[1]==s[3] 且 dp[2][2]=T → dp[1][3]=T
            "bad"：s[2]≠s[4] → 否
第4步（②转移，len=4、5）：两端均不匹配 → 无新增

      j=0  j=1  j=2  j=3  j=4
       b    a    b    a    d
i=0 b   T    .    T    .    .
i=1 a        T    .    T    .
i=2 b             T    .    .
i=3 a                  T    .
i=4 d                       T
答案：s[0..2]="bab"（"aba" 也对），长度 3

代码（Java）

class Solution {
    // ① 状态定义：dp[i][j] = 子串 s[i..j] 是否为回文
    public String longestPalindrome(String s) {
        int n = s.length(), start = 0, maxLen = 1;
        boolean[][] dp = new boolean[n][n]; // ③ 初始化：默认全 false，单字符回文由 len<=2 分支覆盖
        for (int len = 2; len <= n; len++) { // ④ 遍历顺序：按子串长度从小到大，长串依赖短串
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                // ② 转移方程：两端相等且（长度≤2 或内部 dp[i+1][j-1] 已是回文）
                if (s.charAt(i) == s.charAt(j) && (len <= 2 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;
                    start = i;
                    maxLen = len; // 记录最长回文位置
                }
            }
        }
        return s.substring(start, start + maxLen);
    }
}

时间复杂度 O(n²) · 空间复杂度 O(n²)（中心扩展法可降至 O(1) 空间）
