3. 无重复字符的最长子串 中等

标记本题：
给定字符串 s，找出其中不含有重复字符的最长子串的长度。
示例： 输入：s = "abcabcbb" 输出：3 解释：无重复字符的最长子串是 "abc"，长度为 3

解题思路

本页代码参照力扣官方题解的写法：滑动窗口 + 哈希集合，右指针扩张、左指针收缩。

先想清楚两个问题：

Q1：什么样的子串符合要求？不含重复字符的子串就是一个「滑动窗口」：只要窗口内出现重复，一定是右端新进的那个字符与窗口里某个旧字符撞了，此时窗口左端必须右移，直到撞车的旧字符离开窗口。

Q2：怎么判断窗口里有没有重复？用 HashSet 装当前窗口 [left, i] 的所有字符。右指针每进一步，先查 s.charAt(i) 在不在集合里：在 → 左指针逐个收缩并移出字符，直到不重复；不在 → 加入集合，用当前窗口长度刷新答案。

照着写的五步：

① 建 HashSet 存窗口字符，left = 0、ans = 0；
② 右指针 i 从 0 扫到 n-1；
③ 每步先查：s.charAt(i) 已在集合 → 循环移出 s.charAt(left) 并 left++，直到不再重复；
④ 把 s.charAt(i) 加入集合，ans = max(ans, i - left + 1)；
⑤ 扫描结束返回 ans。

关键点：左右指针都只向右走，每个字符最多进出窗口各一次，所以总复杂度是 O(n)。

主例：s = "abcabcbb"

i:    0   1   2   3   4   5   6   7
s:    a   b   c   a   b   c   b   b
窗口: a   ab  abc bca cab abc cb  b
                      ↑ i=6 遇重复 b：收缩移出 a,b → 窗口 "cb"，left=5
                      ↑ i=7 遇重复 b：收缩移出 c,b → 窗口 "b"，left=7
最长窗口 = 3（abc）

左指针收缩演示（i=6, s[6]='b' 已在集合 {a,b,c}）：
  移出 s[3]='a' → 集合 {b,c}，仍含 b，left=4
  移出 s[4]='b' → 集合 {c}，不含 b，停止，left=5
  加入 'b' → 集合 {c,b}，窗口 "cb"，长度 2

代码（Java · 力扣官方题解写法）

class Solution {
    public int lengthOfLongestSubstring(String s) {
        // ① 哈希集合，记录每个字符是否出现过（即当前窗口内容）
        Set<Character> occ = new HashSet<Character>();
        int n = s.length();
        // 左指针，初始值为 0，相当于窗口左边界
        int left = 0, ans = 0;
        // ② 右指针 i 扫描整个字符串
        for (int i = 0; i < n; ++i) {
            // ③ 新字符已在窗口中：左指针右移，不断移出左端字符直到不重复
            while (occ.contains(s.charAt(i))) {
                occ.remove(s.charAt(left));
                ++left;
            }
            // ④ 纳入新字符，并用当前窗口长度刷新答案
            occ.add(s.charAt(i));
            ans = Math.max(ans, i - left + 1);
        }
        return ans; // ⑤
    }
}

时间复杂度 O(n)，左右指针各遍历字符串一次 · 空间复杂度 O(|Σ|)，|Σ| 为字符集大小（本题可视为 O(1)）
