438. 找到字符串中所有字母异位词 中等

标记本题：
给定字符串 s 和 p，返回 s 中所有「p 的异位词」子串的起始下标，顺序不限。
示例： 输入：s = "cbaebabacd", p = "abc" 输出：[0,6] 解释：起始下标 0 的子串 "cba"、下标 6 的子串 "bac" 都是 "abc" 的异位词

解题思路

本页代码参照力扣官方题解的写法：定长滑动窗口 + 两个 26 长计数数组，每步用 Arrays.equals 比较频次。

先回答两个问题，答案就是代码的骨架：

Q1：怎么判断一个子串是 p 的异位词？不要排序、不要逐字符比对。异位词 ⇔「26 个字母的频次完全相同」。所以给每个串开一个 int[26] 计数数组，Java 里直接 Arrays.equals(cntS, cntP) 比较两个数组即可，一次比较固定 26 步，是 O(1) 级别。

Q2：窗口怎么滑？p 的长度 m 是固定的，所以窗口长度恒为 m，不需要伸缩。右指针 i 每走一步只做三件事：进 → 出 → 比。

照着写的五步：

① 特判：s 比 p 短，直接返回空列表；
② 开两个数组：cntP[26] 存 p 的频次（先统计好，之后不变），cntS[26] 存当前窗口的频次；
③ 进：右端字符 s[i] 进窗口，cntS[s[i]-'a']++；
④ 出：只有当 i ≥ m（窗口超长）时，让左边掉出去的字符 s[i-m] 出窗口，cntS[s[i-m]-'a']--；
⑤ 比：Arrays.equals(cntS, cntP) 相等 → 当前窗口就是异位词，记录起始下标 i - m + 1（右端位置减去窗口长度加 1）。

容易写错的两个点：出窗口的字符是 s[i-m]（不是 s[i-1]）；记录的起始下标是 i-m+1（不是 i）。

s = "cbaebabacd", p = "abc"，m = 3，cntP = {a:1,b:1,c:1}

i   进       出(i≥m 时)   cntS 当前状态          比较 cntP
0   c        -            {c:1}                 窗口不足 3
1   b        -            {b:1,c:1}             窗口不足 3
2   a        -            {a:1,b:1,c:1}    ✓ 相等 → 记录 2-3+1 = 0
3   e        s[0]=c       {a:1,b:1,e:1}    ✗
4   b        s[1]=b       {a:1,b:1,e:1}    ✗
5   a        s[2]=a       {a:1,b:1,e:1}    ✗
6   b        s[3]=e       {a:1,b:2}        ✗
7   a        s[4]=b       {a:2,b:1}        ✗
8   c        s[5]=a       {a:1,b:1,c:1}    ✓ 相等 → 记录 8-3+1 = 6
9   d        s[6]=b       {a:1,c:1,d:1}    ✗

答案 = [0, 6]

直观理解：窗口 cba ✓                    窗口 bac ✓
c b a e b a b a c d
└─┴─┘
            └─┴─┘（起点下标 6）

代码（Java · 力扣官方题解写法）

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int sLen = s.length(), pLen = p.length();
        List<Integer> ans = new ArrayList<Integer>();
        // ① 特判：s 比 p 短不可能有异位词
        if (sLen < pLen) {
            return ans;
        }
        // ② cntP 存 p 的频次，cntS 存当前窗口的频次
        int[] cntS = new int[26];
        int[] cntP = new int[26];
        for (int i = 0; i < pLen; ++i) {
            ++cntP[p.charAt(i) - 'a'];
        }
        for (int i = 0; i < sLen; ++i) {
            // ③ 进：右端字符进窗口
            ++cntS[s.charAt(i) - 'a'];
            // ④ 出：窗口超长（i≥pLen）才让最左字符 s[i-pLen] 出窗口
            if (i >= pLen) {
                --cntS[s.charAt(i - pLen) - 'a'];
            }
            // ⑤ 比：频次完全相同 → 是异位词，记录起始下标 i-pLen+1
            if (Arrays.equals(cntS, cntP)) {
                ans.add(i - pLen + 1);
            }
        }
        return ans;
    }
}

时间复杂度 O(n × 26) ≈ O(n) · 空间复杂度 O(1)（两个固定 26 长度的数组）
