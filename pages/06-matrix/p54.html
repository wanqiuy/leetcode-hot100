54. 螺旋矩阵 中等

标记本题：
给定 m×n 矩阵，按从外到内的顺时针螺旋顺序返回所有元素。
输入：[[1,2,3],[4,5,6],[7,8,9]] 输出：[1,2,3,6,9,8,7,4,5]

解题思路

本页代码参照力扣官方题解的写法：按层模拟，四条边界围成一圈逐层剥离。

先想清楚两个问题：

Q1：整体策略是什么？把矩阵看成一层层同心圈，每圈按「上边左→右、右边上→下、下边右→左、左边下→上」四条边顺序剥下来；剥完一整圈，left/right/top/bottom 四条边界统一向内各缩一格，直到边界交错。

Q2：怎么保证角上不重复、单行单列时不多走？顶行和右列每圈完整走，但右列从 top+1 开始（左上角已被顶行覆盖）；底行只走到 left+1、左列只走到 top+1（左下角、右下角已被右列/底行覆盖）；并且底行和左列只在 left<right 且 top<bottom 时才走——只剩单行或单列时，顶行+右列已经把它走完，底行左列必须跳过。

照着写的 4 步：

① 初始化 order，特判空矩阵；left=0、right=columns-1、top=0、bottom=rows-1，循环条件 left<=right 且 top<=bottom；
② 顶行 column 从 left→right 收集；右列 row 从 top+1→bottom 收集；
③ 若 left<right 且 top<bottom：底行 column 从 right-1→left+1 收集，左列 row 从 bottom→top+1 收集；
④ 一圈结束，left++、right--、top++、bottom--，进入下一圈。

易错点：右列从 top+1 开始不是从 top 开始（左上角顶行走过）；底行不走到 left、左列不走到 top（角上不重复）；③ 的保护条件用的是收缩前的 left/right/top/bottom，四条边界在 ④ 才统一收缩；入口要特判空矩阵。

逐步推演：[[1,2,3],[4,5,6],[7,8,9]]
第1圈：left=0,right=2,top=0,bottom=2
 ② 顶行 1→2→3；右列 6(row=1)→9(row=2)
 ③ left<right 且 top<bottom：底行 8(column=1，止于 left+1)；左列 7(row=2)→4(row=1，止于 top+1)
 ④ 收缩：left=1,right=1,top=1,bottom=1
第2圈：顶行 5；右列无；left==right 跳过 ③
 ④ 收缩后 left=2>right=0，退出
结果：[1,2,3,6,9,8,7,4,5]

代码（Java · 力扣官方题解写法）

class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> order = new ArrayList<>();
        // ① 特判空矩阵
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return order;
        int rows = matrix.length, columns = matrix[0].length;
        int left = 0, right = columns - 1, top = 0, bottom = rows - 1;
        while (left <= right && top <= bottom) {
            // ② 顶行左→右；右列上→下（从 top+1 起，避开左上角）
            for (int column = left; column <= right; column++) order.add(matrix[top][column]);
            for (int row = top + 1; row <= bottom; row++) order.add(matrix[row][right]);
            // ③ 还有完整的底行和左列才走（端点均不重复覆盖）
            if (left < right && top < bottom) {
                for (int column = right - 1; column > left; column--) order.add(matrix[bottom][column]);
                for (int row = bottom; row > top; row--) order.add(matrix[row][left]);
            }
            // ④ 一圈剥完，四条边界统一内缩
            left++;
            right--;
            top++;
            bottom--;
        }
        return order;
    }
}

时间复杂度 O(mn) · 空间复杂度 O(1)（不计输出数组）
