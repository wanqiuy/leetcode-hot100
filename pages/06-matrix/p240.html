240. 搜索二维矩阵 II 中等

标记本题：
矩阵每行从左到右升序、每列从上到下升序，在其中搜索目标值 target。
输入：matrix=[[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target=5 输出：true

解题思路

先想清楚两个问题：

Q1：从哪个角出发才能每步都排除一整行或一整列？从右上角（或左下角）：站在右上角时，左边全比它小、下边全比它大，比较一次就能确定排除方向；若从左上角出发，右边和下边都更大，无法二选一。

Q2：每步怎么移动？当前值等于 target 直接返回 true；比 target 大说明这一列（下方更大）都不可能，j-- 左移；比 target 小说明这一行（左方更小）都不可能，i++ 下移。

照着写的 3 步：

① 初始化 i=0、j=n-1，即站在右上角；
② 循环条件 i<m 且 j>=0：相等返回 true，matrix[i][j]>target 则 j--，否则 i++；
③ 越界退出循环说明不存在，返回 false。

易错点：起点是右上角不是左上角；「大则左移、小则下移」的方向不要记反（可记：大了往小的方向走——左，小了往大的方向走——下）。

逐步推演：5×5 矩阵中找 target=5
 1  4  7 11 15
 2  5  8 12 19
 3  6  9 16 22
10 13 14 17 24
18 21 23 26 30
① 站 (0,4)=15：15>5 → j-- 到 (0,3)=11
② 11>5 → j-- 到 (0,2)=7；7>5 → j-- 到 (0,1)=4
③ 4<5 → i++ 到 (1,1)=5，相等，返回 true
共 5 步，每步排除一行或一列。

代码（Java）

class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length, n = matrix[0].length;
        // ① 站在右上角
        int i = 0, j = n - 1;
        // ② 相等命中；大了左移排除列；小了下移排除行
        while (i < m && j >= 0) {
            if (matrix[i][j] == target) return true;
            else if (matrix[i][j] > target) j--;
            else i++;
        }
        // ③ 走出边界仍未命中
        return false;
    }
}

时间复杂度 O(m+n) · 空间复杂度 O(1)
