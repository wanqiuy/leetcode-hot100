48. 旋转图像 中等

标记本题：
给定 n×n 矩阵表示的图像，将其顺时针旋转 90 度，要求原地修改。
输入：[[1,2,3],[4,5,6],[7,8,9]] 输出：[[7,4,1],[8,5,2],[9,6,3]]

解题思路

本页代码参照力扣官方题解的写法：先转置（transpose）、再每行反转（reflect）。

先想清楚两个问题：

Q1：不想做四个格子的环形交换，有没有更简单的等价变换？顺时针旋转 90° = 先沿主对角线转置（行列互换），再把每一行左右翻转，两步都是简单的原地交换。

Q2：转置时遍历哪些格子？只遍历主对角线一侧（j 从 i+1 开始），把 matrix[i][j] 与 matrix[j][i] 互换；若整个方阵都扫会交换两次等于没动。

照着写的 3 步：

① transpose：双重循环 i<j，交换 matrix[i][j] 和 matrix[j][i]，完成转置；
② reflect：对每一行，j 从 0 到 n/2-1，交换 matrix[i][j] 和 matrix[i][n-1-j]，完成左右翻转；
③ rotate 里依次调用两步即得结果，无需返回值（原地修改）。

易错点：转置内层循环是 j=i+1 不是 j=0（否则交换两次复原）；行翻转只循环到 n/2 不是 n（否则又翻回去）。

逐步推演：[[1,2,3],[4,5,6],[7,8,9]]
① 转置（交换 (0,1)↔(1,0)、(0,2)↔(2,0)、(1,2)↔(2,1)）：
   1 4 7
   2 5 8
   3 6 9
② 每行左右翻转（第0行 1↔7，第1行 2↔8，第2行 3↔9）：
   7 4 1
   8 5 2
   9 6 3
即顺时针旋转 90° 的结果。

代码（Java · 力扣官方题解写法）

class Solution {
    // ③ 两步组合完成顺时针旋转 90°
    public void rotate(int[][] matrix) {
        transpose(matrix);
        reflect(matrix);
    }
    // ① 沿主对角线转置：只扫 j>i 的上三角
    private void transpose(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++) {
                int tmp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = tmp;
            }
    }
    // ② 每行左右翻转：只扫左半行
    private void reflect(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n / 2; j++) {
                int tmp = matrix[i][j];
                matrix[i][j] = matrix[i][n - 1 - j];
                matrix[i][n - 1 - j] = tmp;
            }
    }
}

时间复杂度 O(n²) · 空间复杂度 O(1)
