42. 接雨水 困难

标记本题：
给定 n 个非负整数表示柱子的高度图，计算下雨之后能接多少雨水。
示例： 输入：height = [0,1,0,2,1,0,1,3,2,1,2,1] 输出：6

解题思路

本页代码参照力扣官方题解的写法：双指针，边走边维护两侧最高值，矮的一侧先结算。

先想清楚两个问题：

Q1：每一列的接水量怎么算？该列上方能接的水 = min(左侧最高柱, 右侧最高柱) - 自身高度。逐列向两侧扫描找最高值是 O(n²)，用双指针边走边维护两侧最高值可降到 O(n)。

Q2：为什么矮的一侧可以先结算？若 height[left] < height[right]，说明 left 右侧必有更高的柱子（至少 right 就是），min(leftMax, rightMax) 此时就等于 leftMax，left 处水量 = leftMax - height[left] 直接确定；反之对称地结算 right。

照着写的四步：

① left = 0、right = n-1、leftMax = rightMax = 0、ans = 0；
② 每轮先更新 leftMax = max(leftMax, height[left])、rightMax = max(rightMax, height[right])；
③ 哪侧矮就结算哪侧：ans += 该侧最大值 - 该侧高度，然后该侧指针内移；
④ left == right 时结束，返回 ans。

易错点：结算用「该侧最大值 - 该侧当前高度」，不是两侧最大值相减；决定动哪边时比较的是 height[left] 与 height[right]，不是 leftMax 与 rightMax；leftMax、rightMax 要先更新再结算，顺序不能反。

left==right 结束，ans = 6

代码（Java · 力扣官方题解写法）

class Solution {
    public int trap(int[] height) {
        int ans = 0;
        int left = 0, right = height.length - 1; // ① 对撞指针
        int leftMax = 0, rightMax = 0;           // ① 两侧历史最高
        while (left < right) {
            // ② 先更新两侧最大值
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);
            // ③ 哪侧矮，哪侧水量已由该侧最大值决定，先结算并内移
            if (height[left] < height[right]) {
                ans += leftMax - height[left];
                ++left;
            } else {
                ans += rightMax - height[right];
                --right;
            }
        }
        return ans; // ④
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
