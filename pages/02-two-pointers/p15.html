15. 三数之和 中等

标记本题：
给定数组 nums，返回所有满足 nums[i] + nums[j] + nums[k] = 0 且下标互不相同的三元组，答案中不能包含重复的三元组。
示例： 输入：nums = [-1,0,1,2,-1,-4] 输出：[[-1,-1,2],[-1,0,1]]

解题思路

先想清楚两个问题：

Q1：怎么把 O(n³) 的三重枚举降下来？先排序，固定第一个数 nums[i]，问题退化为「在 i 右侧的有序区间找两数之和 = -nums[i]」，用对撞双指针 O(n) 解决，整体 O(n²)。

Q2：答案不能含重复三元组，怎么去重？排序让相同值相邻，做两层去重：固定的 i 与前一个值相同就跳过；命中答案后，l、r 各自跳过所有重复值再内移。

照着写的五步：

① 排序，然后遍历固定数 i（只需到 n-3）；
② nums[i] 与前一个值相同 → continue，去重；
③ l = i+1、r = n-1 对撞：sum < 0 则 l++，sum > 0 则 r--；
④ sum == 0 记录三元组，l、r 各跳过重复值后再各内移一步；
⑤ 遍历结束返回结果集。

易错点：必须先排序，双指针的移动方向和去重都依赖有序；i 的去重判断是 i > 0 且 nums[i] == nums[i-1]，不是与 nums[i+1] 比；命中后是先跳重复、再 l++/r--，少了最后的内移会死循环。

nums = [-1,0,1,2,-1,-4] → 排序后 [-4,-1,-1,0,1,2]

i=0 (-4): 目标两数和 4，l=1(-1) r=5(2) sum=-3，l++ 到相遇，无解
i=1 (-1): 目标两数和 1，区间下标 2~5 [-1,0,1,2]
          l=2(-1) r=5(2): -1+2=1 ✓ 记录 [-1,-1,2]
          跳重复后 l=3(0) r=4(1): 0+1=1 ✓ 记录 [-1,0,1]
          再内移，l==r，本轮结束
i=2 (-1): nums[2]==nums[1] → 跳过（去重）
i=3 (0):  l=4(1) r=5(2)，sum=3 > 0，r--，l==r，无解

答案 = [[-1,-1,2], [-1,0,1]]

代码（Java）

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        Arrays.sort(nums); // ① 先排序
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) { // ① 固定第一个数
            if (i > 0 && nums[i] == nums[i - 1]) continue; // ② 固定数去重
            int l = i + 1, r = n - 1; // ③ 右侧区间对撞
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum == 0) {
                    // ④ 命中：记录后双指针各自跳重复再内移
                    ans.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    while (l < r && nums[l] == nums[l + 1]) l++;
                    while (l < r && nums[r] == nums[r - 1]) r--;
                    l++; r--;
                } else if (sum < 0) {
                    l++; // ③ 偏小，左指针右移
                } else {
                    r--; // ③ 偏大，右指针左移
                }
            }
        }
        return ans; // ⑤
    }
}

时间复杂度 O(n²) · 空间复杂度 O(log n)（排序递归栈，不计输出）
