11. 盛最多水的容器 中等

标记本题：
给定数组 height，每个元素代表一条竖线的高度。选两条线与 x 轴构成容器，使容器能盛的水最多，返回最大水量。
示例： 输入：height = [1,8,6,2,5,4,8,3,7] 输出：49 解释：选中下标 1（高 8）和下标 8（高 7），面积 = 7 × 7 = 49

解题思路

本页代码参照力扣官方题解的写法：对撞双指针，每步移动较矮一侧。

先想清楚两个问题：

Q1：怎么避免 O(n²) 枚举所有线对？对撞双指针从两端开始，每步排除一个「不可能更优」的选择，只扫一遍就结束。

Q2：每步移动哪一侧的指针？移动较矮一侧。面积由短板决定：若移动较高一侧，宽度变小且短板不变，面积必然更小，等于白走；只有动短板才可能遇到更高的板。

照着写的三步：

① l = 0、r = n - 1、ans = 0；
② 每轮算面积 min(height[l], height[r]) × (r - l)，刷新 ans；
③ 矮的一侧内移一格（左矮 l++，右矮 r--，相等走哪边都行），直到 l == r。

易错点：是移动「较矮一侧」不是「较高一侧」；宽度是下标差 r - l，不是 r - l + 1；循环条件是 l < r，不是 l <= r。

height = [1,8,6,2,5,4,8,3,7]
下标      0 1 2 3 4 5 6 7 8

 l   r   短板 min  宽 r-l  面积   操作
 0   8   1         8       8     左矮，l++
 1   8   7         7       49 ←  最大；右矮，r--
 1   7   3         6       18    右矮，r--
 1   6   8         5       40    相等，r--
 1   5   4         4       16    右矮，r--
 1   4   5         3       15    右矮，r--
 1   3   2         2       4     右矮，r--
 1   2   6         1       6     右矮，r--
 l==r 结束

ans = 49

代码（Java · 力扣官方题解写法）

class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, ans = 0; // ① 对撞指针从两端出发
        while (l < r) {
            // ② 面积 = 短板 × 宽度，刷新最大值
            int area = Math.min(height[l], height[r]) * (r - l);
            ans = Math.max(ans, area);
            // ③ 移动较矮一侧（动较高一侧面积只会更小）
            if (height[l] < height[r]) l++;
            else r--;
        }
        return ans;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
