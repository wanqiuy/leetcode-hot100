169. 多数元素 简单

标记本题：
给定大小为 n 的数组 nums，返回其中的多数元素（出现次数严格大于 ⌊n/2⌋ 的元素，题目保证其存在）。
示例：输入 nums = [3,2,3] → 输出 3 输入 nums = [2,2,1,1,1,2,2] → 输出 2

解题思路

先想清楚两个问题：

Q1：不统计次数，怎么找出过半的元素？摩尔投票法（Boyer-Moore）：多数元素超过一半，意味着它跟其余所有元素「一换一抵消」后仍有剩余。所以只维护候选人 candidate 和计数 count，让不同元素互相抵消。

Q2：抵消规则怎么定？遍历时：count 为 0 说明之前的候选人已被全部抵消，换当前数当新候选人；当前数等于候选人 count + 1，不同则 count - 1（抵消一票）。遍历结束时候选人必是多数元素（题目保证存在，无需二次校验）。

照着写的 4 步：

① candidate = 任意值，count = 0；
② 遍历每个数 x：若 count == 0，先令 candidate = x；
③ 再按 x == candidate 决定 count += 1 还是 count -= 1；
④ 遍历结束返回 candidate。

易错点：换候选人的时机是 count == 0 时且要先换再计票（顺序反了会给自己投反对票）；count 增减看的是 x 与当前 candidate 是否相等，不是与上一个元素比；此结论依赖「多数元素必存在」，不保证存在时需再扫一遍验证次数。

nums = [2, 2, 1, 1, 1, 2, 2]

操作          candidate   count   说明
读 2            2          1      count=0 → 换候选 2，再 +1
读 2            2          2      相同 +1
读 1            2          1      不同 -1（抵消一票）
读 1            2          0      不同 -1（候选人被清空）
读 1            1          1      count=0 → 换候选 1，再 +1
读 2            1          0      不同 -1（又被清空）
读 2            2          1      count=0 → 换候选 2，再 +1

最终候选人 = 2 → 即多数元素 ✓
（2 出现 4 次 ＞ 7/2，抵消所有对手后仍有盈余）

代码（Java）

class Solution {
    public int majorityElement(int[] nums) {
        // ① 候选人 + 剩余票数
        int candidate = 0, count = 0;
        for (int x : nums) {
            // ② 票数耗尽，换当前数为新候选人
            if (count == 0) {
                candidate = x;
            }
            // ③ 同则加一票，异则抵消一票
            count += (x == candidate) ? 1 : -1;
        }
        return candidate;   // ④ 题目保证多数元素存在
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
