75. 颜色分类 中等

标记本题：
给定只含 0、1、2 的数组 nums（分别代表红、白、蓝），原地排序使相同颜色相邻，顺序为 0、1、2。要求不使用库函数排序，一趟完成。
示例：输入 nums = [2,0,2,1,1,0] → 输出 [0,0,1,1,2,2] 输入 nums = [2,0,1] → 输出 [0,1,2]

解题思路

本页代码参照力扣官方题解的写法：单趟遍历三指针（荷兰国旗问题，p0/p2 夹逼）。

先想清楚两个问题：

Q1：一趟遍历怎么把数组分成三段？荷兰国旗三指针：p0 指向 0 区的下一个写入位置（左侧全 0），p2 指向 2 区的下一个写入位置（右侧全 2），cur 从左向右扫描未处理区。不变式：[0, p0) 全 0、[p0, cur) 全 1、(p2, n-1] 全 2。

Q2：遇到 0、1、2 各怎么动指针？遇 0：与 p0 交换，p0++ 且 cur++（p0 处换过来的必是 1，无需复检）；遇 2：与 p2 交换，只 p2--，cur 不动（p2 处换过来的可能是 0 或 2，必须复检）；遇 1：cur++ 直接跳过。cur 越过 p2 即结束。

照着写的 4 步：

① p0 = 0，cur = 0，p2 = n - 1；
② while (cur ≤ p2) 循环；
③ nums[cur] == 0 → swap(p0, cur)，p0++、cur++；== 2 → swap(cur, p2)，仅 p2--；== 1 → cur++；
④ 循环结束数组即有序。

易错点：换到 2 时 cur 不动不是 cur++（换过来的元素未检查）；换到 0 时 cur 要跟着 ++ 不是不动（p0 ≤ cur，p0 处只可能是 1）；循环条件是 cur <= p2 不是 cur < p2（cur == p2 时还有一个元素未处理）。

nums = [2, 0, 2, 1, 1, 0]   n=6
不变式：[0, p0) 全 0，[p0, cur) 全 1，(p2, 5] 全 2

操作                     数组                 p0  cur  p2
初始                     [2, 0, 2, 1, 1, 0]    0   0   5
cur=0 遇 2 → 换(0,5)    [0, 0, 2, 1, 1, 2]    0   0   4
  （cur 不动，复检 0）
cur=0 遇 0 → 换(0,0)    [0, 0, 2, 1, 1, 2]    1   1   4
cur=1 遇 0 → 换(1,1)    [0, 0, 2, 1, 1, 2]    2   2   4
cur=2 遇 2 → 换(2,4)    [0, 0, 1, 1, 2, 2]    2   2   3
  （cur 不动，复检 1）
cur=2 遇 1 → 跳过       [0, 0, 1, 1, 2, 2]    2   3   3
cur=3 ＞ p2=3 → 循环结束

结果: [0, 0, 1, 1, 2, 2] ✓

代码（Java · 力扣官方题解写法）

class Solution {
    public void sortColors(int[] nums) {
        // ① p0：0 区写入位；p2：2 区写入位；cur：扫描指针
        int p0 = 0, cur = 0, p2 = nums.length - 1;
        // ② cur 越过 p2 时三段拼接完成
        while (cur <= p2) {
            if (nums[cur] == 0) {
                swap(nums, p0++, cur++);   // ③ 换过来必是 1，双指针右移
            } else if (nums[cur] == 2) {
                swap(nums, cur, p2--);     // ③ 换过来未检查，cur 不动
            } else {
                cur++;                     // ③ 1 留在中段，跳过
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int t = nums[i];
        nums[i] = nums[j];
        nums[j] = t;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
