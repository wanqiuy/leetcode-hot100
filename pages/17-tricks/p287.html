287. 寻找重复数 中等

标记本题：
数组 nums 含 n+1 个整数，每个数都在 [1, n] 范围内，恰好只有一个数重复（可能重复多次）。找出这个重复的数。要求不修改数组、只用 O(1) 额外空间。
示例：输入 nums = [1,3,4,2,2] → 输出 2 输入 nums = [3,1,3,4,2] → 输出 3

解题思路

本页代码参照力扣官方题解的写法：Floyd 快慢指针（把数组看成隐式链表找环入口）。

先想清楚两个问题：

Q1：不能改数组、O(1) 空间，怎么定位重复数？把数组看成隐式链表：下标 i 的 next 就是 nums[i]。值域 [1,n] 共 n+1 个数，从 0 出发沿 next 走必成环；而重复数恰是环的入口——有两个不同下标指向它。问题等价于「找链表环入口」。

Q2：Floyd 快慢指针两个阶段各干什么？第一阶段：fast 每次两步、slow 每次一步，二者必在环内相遇；第二阶段：slow 放回起点 0，与 fast 改为同速各走一步，再次相遇的位置就是环入口。数学依据：起点到入口的距离 = 相遇点到入口绕环的剩余距离。

照着写的 4 步：

① slow = nums[0]，fast = nums[nums[0]]（先各走一步再进循环）；
② while (slow != fast)：slow 走一步 nums[slow]，fast 走两步 nums[nums[fast]]，直到环内相遇；
③ slow 重置为 0，fast 不动，改为同速各走一步，直到再次相遇；
④ 返回 slow（即环入口 = 重复数）。

易错点：两阶段初值是 slow=nums[0]、fast=nums[nums[0]] 不是都等于 0（都等于 0 时循环条件一开始就成立，进不了第一阶段）；第一阶段 fast 走两步 slow 走一步，第二阶段两者都走一步；数组元素是「值即下一跳下标」，全程只读不写，不能排序也不能标记。

nums = [1, 3, 4, 2, 2]（下标 0..4，值域 [1,4]）

隐式链表（i → nums[i]，值即下一跳的下标）：
  0 → 1 → 3 → 2 → 4 → 2 → 4 → 2 ...
                 ↑_________↓ 环
   环入口 = 2（下标 3 和 4 的值都是 2，两个位置指向它）

①② 第一阶段（slow 一步、fast 两步；初值 slow=1, fast=3）：
    轮次    slow    fast    结果
    初始     1       3      不等
     1       3       4      不等
     2       2       4      不等
     3       4       4      相遇 ✓（值 4，环内某点）

③ 第二阶段（slow 回 0，fast 停在 4，同速各走一步）：
    轮次    slow    fast    结果
    初始     0       4      不等
     1       1       2      不等
     2       3       4      不等
     3       2       2      相遇 ✓

④ 返回 2 → 即重复数 ✓

代码（Java · 力扣官方题解写法）

class Solution {
    public int findDuplicate(int[] nums) {
        // ① 先各走一步：slow 一步、fast 两步
        int slow = nums[0];
        int fast = nums[nums[0]];
        // ② 第一阶段：快慢指针必在环内相遇
        while (slow != fast) {
            slow = nums[slow];           // 一步
            fast = nums[nums[fast]];     // 两步
        }
        // ③ 第二阶段：slow 回起点，同速前进
        slow = 0;
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }
        return slow;                     // ④ 再次相遇处 = 环入口 = 重复数
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
