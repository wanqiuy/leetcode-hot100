136. 只出现一次的数字 简单

标记本题：
给定非空整数数组 nums，除某个元素只出现一次外，其余每个元素均出现两次。找出只出现一次的那个元素。要求线性时间、O(1) 额外空间。
示例：输入 nums = [4,1,2,1,2] → 输出 4 输入 nums = [2,2,1] → 输出 1

解题思路

本页代码参照力扣官方题解的写法：位运算（全部元素异或，成对抵消）。

先想清楚两个问题：

Q1：不用额外空间，怎么把成对的数「消掉」？用异或（XOR）。三条性质够用：a ⊕ a = 0（相同抵消）、a ⊕ 0 = a（与 0 异或不变）、异或满足交换律和结合律（顺序无所谓）。

Q2：为什么全部异或一遍结果就是答案？把数组所有元素依次异或：出现两次的数两两配对抵消为 0，0 再与只出现一次的那个数异或，留下的就是它本身。一趟扫描、一个变量，正好满足 O(n) 时间和 O(1) 空间。

照着写的 3 步：

① ans = 0（异或的单位元）；
② 遍历每个数 x：ans ^= x；
③ 遍历结束返回 ans。

易错点：初值是 0 不是任意数（0 是异或单位元，不影响结果）；用 ^= 累积异或不是 &= 或 +=（加法无法抵消成对元素）；不需要先排序，异或交换律保证任意顺序结果相同。

nums = [4, 1, 2, 1, 2]

逐步累积 ans（初值 0）：
  ans = 0 ⊕ 4 = 4
  ans = 4 ⊕ 1 = 5
  ans = 5 ⊕ 2 = 7
  ans = 7 ⊕ 1 = 6
  ans = 6 ⊕ 2 = 4   ← 落单的 4 留下

原理重排验证（交换律）：
  4 ⊕ 1 ⊕ 2 ⊕ 1 ⊕ 2
= 4 ⊕ (1 ⊕ 1) ⊕ (2 ⊕ 2)
= 4 ⊕ 0 ⊕ 0 = 4 ✓

按位示例（1 ⊕ 1 为什么抵消）：
  01
⊕ 01
----
  00  → 相同位全抵消为 0

代码（Java · 力扣官方题解写法）

class Solution {
    public int singleNumber(int[] nums) {
        // ① 0 是异或单位元：0 ⊕ x = x
        int ans = 0;
        // ② 全部异或：成对的数两两抵消，落单的留下
        for (int x : nums) {
            ans ^= x;
        }
        return ans;    // ③
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
