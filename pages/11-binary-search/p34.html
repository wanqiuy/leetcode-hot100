34. 在排序数组中查找元素的第一个和最后一个位置 中等

标记本题：
给定非递减排序数组 nums 和目标值 target，返回 target 在数组中的开始位置和结束位置（按升序返回）；若不存在返回 [-1, -1]。要求 O(log n)。
示例：输入 nums = [5,7,7,8,8,10], target = 8 → 输出 [3,4] 输入 nums = [5,7,7,8,8,10], target = 6 → 输出 [-1,-1]

解题思路

先想清楚两个问题：

Q1：普通二分命中就返回，怎么找「第一个」和「最后一个」？写两次边界二分：找左边界时即使 nums[mid] == target 也继续向左压（r = mid - 1），最终 l 停在第一个 ≥ target 的位置；找右边界时等于也继续向右扩（l = mid + 1），最终 r 停在最后一个 ≤ target 的位置。

Q2：怎么判断 target 不存在？先跑左边界二分，若结果越界（left == n）或 nums[left] ≠ target，说明 target 不在数组里，直接返回 [-1, -1]，右边界就不用找了。

照着写的 5 步：

① 调用边界二分（findLeft=true）求左边界 left；
② 校验 left 越界或 nums[left] ≠ target 则返回 [-1, -1]；
③ 再调用边界二分（findLeft=false）求右边界 right；
④ 返回 [left, right]；
⑤ 边界二分内部：闭区间循环，findLeft 时 nums[mid] ≥ target 就 r = mid - 1 否则 l = mid + 1；findRight 时 nums[mid] ＞ target 才 r = mid - 1 否则 l = mid + 1；结束时左边界返回 l、右边界返回 r。

易错点：两种边界的收缩条件差别只在「等于号归哪边」，写反会得到错误边界；左边界看 l 不是 r，右边界看 r 不是 l；找到左边界后必须先校验是否真等于 target 再求右边界。

nums = [5, 7, 7, 8, 8, 10]   target = 8
下标:    0   1   2   3   4   5

【找左边界：nums[mid] ≥ 8 → r = mid-1】
第1轮: L=0, R=5, mid=2 → nums[2]=7 ＜ 8 → L=3
第2轮: L=3, R=5, mid=4 → nums[4]=8 ≥ 8 → R=3
第3轮: L=3, R=3, mid=3 → nums[3]=8 ≥ 8 → R=2
结束: L=3 → 校验 nums[3]=8 ✓ → 左边界 = 3（第一个 8）

【找右边界：nums[mid] ＞ 8 → r = mid-1，否则 l = mid+1】
第1轮: L=0, R=5, mid=2 → nums[2]=7 ≤ 8 → L=3
第2轮: L=3, R=5, mid=4 → nums[4]=8 ≤ 8 → L=5
第3轮: L=5, R=5, mid=5 → nums[5]=10 ＞ 8 → R=4
结束: R=4 → 右边界 = 4（最后一个 8）

答案 = [3, 4]

代码（Java）

class Solution {
    public int[] searchRange(int[] nums, int target) {
        // ① 先找左边界（第一个 ≥ target 的下标）
        int left = binarySearch(nums, target, true);
        // ② 校验 target 是否真的存在
        if (left == nums.length || nums[left] != target) {
            return new int[]{-1, -1};
        }
        // ③ 再找右边界（最后一个 ≤ target 的下标）
        int right = binarySearch(nums, target, false);
        return new int[]{left, right};                 // ④
    }

    // ⑤ findLeft=true 找第一个 ≥ target 的下标；false 找最后一个 ≤ target 的下标
    private int binarySearch(int[] nums, int target, boolean findLeft) {
        int l = 0, r = nums.length - 1;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            // 关键差别：等于号归哪边，决定压向左边界还是右边界
            if (findLeft ? nums[mid] >= target : nums[mid] > target) {
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        }
        return findLeft ? l : r;           // 左边界看 l，右边界看 r
    }
}

时间复杂度 O(log n) · 空间复杂度 O(1)
