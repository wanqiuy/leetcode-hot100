4. 寻找两个正序数组的中位数 困难

标记本题：
给定两个升序数组 nums1 和 nums2，长度分别为 m 和 n，找出合并后中位数。要求时间复杂度 O(log(m+n))。
示例：输入 nums1 = [1,3], nums2 = [2] → 输出 2.0 输入 nums1 = [1,2], nums2 = [3,4] → 输出 2.5（(2+3)/2）

解题思路

先想清楚两个问题：

Q1：怎么把「找中位数」转化成可二分的问题？在两个数组中各切一刀：nums1 左半取 i 个、nums2 左半取 j 个，让左半元素总数 = (m+n+1)/2，且满足「左半最大值 ≤ 右半最小值」。满足时中位数直接由切点两侧得出：总长为奇数取左半最大值，偶数取（左半最大 + 右半最小）/2。i 定了 j 就被唯一确定为 (m+n+1)/2 - i，所以只需二分 i。

Q2：二分 i 时怎么判断该往哪边移？记 l1 = nums1[i-1]（nums1 左半最大）、r2 = nums2[j]（nums2 右半最小）等四个切点邻值。若 l1 ＞ r2 说明 nums1 左半取多了，i 左移；若 l2 ＞ r1 说明取少了，i 右移；两者都满足即为正确切分。在较短数组上二分，切点在两端时用 ±∞ 哨兵免特判。

照着写的 6 步：

① 保证 nums1 是较短数组（不够短就交换参数递归）；
② 在 i ∈ [0, m] 上二分：取 i = (l+r)/2，算 j = (m+n+1)/2 - i；
③ 取四个邻值 l1/r1/l2/r2，i 或 j 在边界时用 ∓∞ 哨兵代替；
④ 若 l1 ≤ r2 且 l2 ≤ r1：切分正确，按总长奇偶返回 max(l1,l2) 或 (max(l1,l2)+min(r1,r2))/2.0；
⑤ 否则 l1 ＞ r2 则 r = i - 1，否则 l = i + 1；
⑥ 循环兜底返回 0.0（不会走到）。

易错点：二分区间的右端是 m 不是 m - 1（i 表示左半元素个数，可以取 0..m 共 m+1 个切点）；j 的公式是 (m+n+1)/2 - i 不是 (m+n)/2 - i（+1 让奇数时左半多一个）；哨兵是 MIN_VALUE/MAX_VALUE 成对使用，漏一个边界就错。

nums1 = [1, 3]   nums2 = [2]   m=2, n=1
目标：左半共 (2+1+1)/2 = 2 个元素，i ∈ [0, 2]

第1轮: l=0, r=2 → i = 1（nums1 左半取 1 个）
       j = 2 - 1 = 1（nums2 左半取 1 个）
         nums1: [1 | 3]      l1=1,  r1=3
         nums2: [2 | ─]      l2=2,  r2=+∞(哨兵)
       校验: l1=1 ≤ r2=+∞ ✓ 且 l2=2 ≤ r1=3 ✓ → 切分正确

总长 3 为奇数 → 中位数 = 左半最大值 = max(l1, l2) = max(1, 2) = 2.0

【对照：错误切分长什么样】
若 i=0, j=2：nums1: [| 1, 3]   nums2: [2 | ─]（j=1 才对，j 超界说明 i 太小）
若 i=2, j=0：nums1: [1, 3 |]   nums2: [| 2]
       l1=3 ＞ r2=2 ✗ → i 太大，应左移

代码（Java）

class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // ① 保证 nums1 是较短的数组，二分复杂度降为 O(log min(m,n))
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }
        int m = nums1.length, n = nums2.length;
        // ② 在切点 i ∈ [0, m] 上二分（i 是 nums1 左半元素个数）
        int l = 0, r = m;
        while (l <= r) {
            int i = (l + r) / 2;
            int j = (m + n + 1) / 2 - i;      // ② j 由 i 唯一确定
            // ③ 切点在两端时用哨兵值，免去越界特判
            int l1 = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int r1 = (i == m) ? Integer.MAX_VALUE : nums1[i];
            int l2 = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int r2 = (j == n) ? Integer.MAX_VALUE : nums2[j];
            if (l1 <= r2 && l2 <= r1) {
                // ④ 找到正确切分：按总长奇偶取中位数
                if ((m + n) % 2 == 1) {
                    return Math.max(l1, l2);
                }
                return (Math.max(l1, l2) + Math.min(r1, r2)) / 2.0;
            } else if (l1 > r2) {
                r = i - 1;                    // ⑤ nums1 左半取多了，i 左移
            } else {
                l = i + 1;                    // ⑤ nums1 左半取少了，i 右移
            }
        }
        return 0.0;                           // ⑥ 兜底，不会走到
    }
}

时间复杂度 O(log min(m, n)) · 空间复杂度 O(1)
