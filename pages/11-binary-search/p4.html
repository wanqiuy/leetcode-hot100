4. 寻找两个正序数组的中位数 困难

标记本题：
给定两个升序数组 nums1 和 nums2，长度分别为 m 和 n，找出合并后中位数。要求时间复杂度 O(log(m+n))。
示例：输入 nums1 = [1,3], nums2 = [2] → 输出 2.0 输入 nums1 = [1,2], nums2 = [3,4] → 输出 2.5（(2+3)/2）

解题思路

本页代码参照力扣官方题解的写法：划分数组（在较短数组上二分切点，median1/median2 记录中位数候选）。

先想清楚两个问题：

Q1：怎么把「找中位数」转化成可二分的问题？在两个数组中各切一刀：nums1 左半取 i 个、nums2 左半取 j 个，让左半元素总数 = (m+n+1)/2，且满足「左半最大值 ≤ 右半最小值」。满足时中位数直接由切点两侧得出：median1 = 左半最大值，median2 = 右半最小值；总长为奇数取 median1，偶数取 (median1+median2)/2。i 定了 j 就被唯一确定为 (m+n+1)/2 - i，所以只需二分 i。

Q2：二分 i 时怎么判断该往哪边移？官方写法每轮只校验一个不等式 nums1[i-1] ≤ nums2[j]：成立说明 i 还能更大——先记录当前切分的中位数候选 median1/median2，再 left = i + 1；不成立说明 nums1 左半取多了，right = i - 1。循环结束时候选就对应最大合法 i 的切分（另一个不等式 nums2[j-1] ≤ nums1[i] 对最大合法 i 自动成立，因为 j 随 i 增大而减小）。切点在两端时用 ±∞ 哨兵免特判。

照着写的 5 步：

① 保证 nums1 是较短数组（不够短就交换参数递归）；
② 在 i ∈ [0, m] 上二分：取 i = (left+right)/2，算 j = (m+n+1)/2 - i；
③ 取四个邻值 nums_im1/nums_i/nums_jm1/nums_j，i 或 j 在边界时用 ∓∞ 哨兵代替；
④ 若 nums_im1 ≤ nums_j：记录 median1 = max(nums_im1, nums_jm1)、median2 = min(nums_i, nums_j)，并 left = i + 1 继续找更大的 i；否则 right = i - 1；
⑤ 循环结束按总长奇偶返回 median1 或 (median1+median2)/2.0。

易错点：二分区间的右端是 m 不是 m - 1（i 表示左半元素个数，可以取 0..m 共 m+1 个切点）；j 的公式是 (m+n+1)/2 - i 不是 (m+n)/2 - i（+1 让奇数时左半多一个）；满足条件后不能立即返回，要继续 left = i + 1 找最大合法 i（中位数候选在最后一次满足时刷新）；哨兵 MIN_VALUE/MAX_VALUE 成对使用，漏一个边界就错。

nums1 = [1, 3]   nums2 = [2]   m=2, n=1
目标：左半共 (2+1+1)/2 = 2 个元素，i ∈ [0, 2]

第1轮: left=0, right=2 → i = 1（nums1 左半取 1 个）
       j = 2 - 1 = 1（nums2 左半取 1 个）
         nums1: [1 | 3]      nums_im1=1, nums_i=3
         nums2: [2 | ─]      nums_jm1=2, nums_j=+∞(哨兵)
       校验: nums_im1=1 ≤ nums_j=+∞ ✓ → 切分可行
       记录: median1 = max(1, 2) = 2，median2 = min(3, +∞) = 3
       操作: left = i + 1 = 2（尝试更大的 i）

第2轮: left=2, right=2 → i = 2（nums1 全取）
       j = 2 - 2 = 0
         nums1: [1, 3 | ─]   nums_im1=3, nums_i=+∞
         nums2: [─ | 2]      nums_jm1=-∞, nums_j=2
       校验: nums_im1=3 ＞ nums_j=2 ✗ → right = i - 1 = 1

循环结束（left=2 ＞ right=1）
总长 3 为奇数 → 返回 median1 = 2.0 ✓

代码（Java · 力扣官方题解写法）

class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // ① 保证 nums1 是较短的数组，二分复杂度降为 O(log min(m,n))
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.length;
        int n = nums2.length;
        // ② 在切点 i ∈ [0, m] 上二分（i 是 nums1 左半元素个数）
        int left = 0, right = m;
        // median1：前一部分的最大值；median2：后一部分的最小值
        int median1 = 0, median2 = 0;

        while (left <= right) {
            int i = (left + right) / 2;
            int j = (m + n + 1) / 2 - i;      // ② j 由 i 唯一确定

            // ③ 切点在两端时用哨兵值，免去越界特判
            int nums_im1 = (i == 0 ? Integer.MIN_VALUE : nums1[i - 1]);
            int nums_i = (i == m ? Integer.MAX_VALUE : nums1[i]);
            int nums_jm1 = (j == 0 ? Integer.MIN_VALUE : nums2[j - 1]);
            int nums_j = (j == n ? Integer.MAX_VALUE : nums2[j]);

            if (nums_im1 <= nums_j) {
                // ④ 切分可行：记录中位数候选，继续找更大的 i
                median1 = Math.max(nums_im1, nums_jm1);
                median2 = Math.min(nums_i, nums_j);
                left = i + 1;
            } else {
                // ④ nums1 左半取多了，i 左移
                right = i - 1;
            }
        }

        // ⑤ 按总长奇偶取中位数
        return (m + n) % 2 == 0 ? (median1 + median2) / 2.0 : median1;
    }
}

时间复杂度 O(log min(m, n)) · 空间复杂度 O(1)
