33. 搜索旋转排序数组 中等

标记本题：
升序数组 nums（无重复元素）在某个未知下标处旋转过（如 [0,1,2,4,5,6,7] 变为 [4,5,6,7,0,1,2]）。在旋转后的数组中查找 target，找到返回下标，否则返回 -1。要求 O(log n)。
示例：输入 nums = [4,5,6,7,0,1,2], target = 0 → 输出 4 输入 nums = [4,5,6,7,0,1,2], target = 3 → 输出 -1

解题思路

先想清楚两个问题：

Q1：旋转后数组不再整体有序，二分为什么还能用？关键性质：任意切一刀，至少有一半是有序的。用 nums[mid] ≥ nums[l] 判断左半 [l..mid] 是否有序，否则右半 [mid..r] 有序。每轮都能确定一个有序半。

Q2：确定有序半后往哪边收缩？判断 target 是否落在有序半的取值范围内：左半有序时看 nums[l] ≤ target ＜ nums[mid]；右半有序时看 nums[mid] ＜ target ≤ nums[r]。在范围内就去该半精确收缩，不在就淘汰该半去另一边。每轮稳定淘汰一半，保持 O(log n)。

照着写的 5 步：

① 初始化 l = 0，r = nums.length - 1，闭区间循环；
② 取 mid，若 nums[mid] == target 直接返回 mid；
③ 若 nums[mid] ≥ nums[l] 说明左半有序：target 落在 [nums[l], nums[mid]) 内则 r = mid - 1，否则 l = mid + 1；
④ 否则右半有序：target 落在 (nums[mid], nums[r]] 内则 l = mid + 1，否则 r = mid - 1；
⑤ 循环结束返回 -1。

易错点：判断左半有序用 nums[mid] >= nums[l] 要带等号（l == mid 时左半只剩一个元素，必有序）；target 落在有序半的判定一端带等号一端不带，写反会漏解；命中判断要先于有序性判断。

nums = [4, 5, 6, 7, 0, 1, 2]   target = 0
下标:    0  1  2  3  4  5  6

第1轮: L=0, R=6, mid=3 → nums[3]=7 ≠ 0
       nums[3]=7 ≥ nums[0]=4 → 左半 [4,5,6,7] 有序
       操作: 0 ∉ [4, 7) → 淘汰左半，L = mid+1 = 4
       区间变为 [0, 1, 2]（下标 4..6）

第2轮: L=4, R=6, mid=5 → nums[5]=1 ≠ 0
       nums[5]=1 ≥ nums[4]=0 → 左半 [0,1] 有序
       操作: 0 ∈ [0, 1) → 去左半，R = mid-1 = 4

第3轮: L=4, R=4, mid=4 → nums[4]=0 = target → 返回 4

代码（Java）

class Solution {
    public int search(int[] nums, int target) {
        // ① 闭区间 [l, r]
        int l = 0, r = nums.length - 1;
        while (l <= r) {
            int mid = l + (r - l) / 2;
            if (nums[mid] == target) return mid;   // ② 命中直接返回
            if (nums[mid] >= nums[l]) {
                // ③ 左半 [l..mid] 有序，看 target 是否落在其取值范围内
                if (nums[l] <= target && target < nums[mid]) {
                    r = mid - 1;         // 在有序半内，精确收缩
                } else {
                    l = mid + 1;         // 不在，淘汰左半
                }
            } else {
                // ④ 右半 [mid..r] 有序，同理判断取值范围
                if (nums[mid] < target && target <= nums[r]) {
                    l = mid + 1;
                } else {
                    r = mid - 1;
                }
            }
        }
        return -1;                       // ⑤ 不存在
    }
}

时间复杂度 O(log n) · 空间复杂度 O(1)
