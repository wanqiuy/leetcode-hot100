74. 搜索二维矩阵 中等

标记本题：
m×n 矩阵满足：每行元素从左到右升序，且每行第一个元素大于上一行最后一个元素。判断目标值 target 是否在矩阵中，要求 O(log(m×n))。
示例：输入 matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3 → 输出 true 输入 target = 13 → 输出 false

解题思路

本页代码参照力扣官方题解的写法：一次二分查找（按行拉平成虚拟升序数组）。

先想清楚两个问题：

Q1：二维矩阵怎么做二分？题目保证「每行升序且每行首元素大于上一行末元素」，所以按行拉平就是一条长度为 m×n 的升序数组，直接对拉平后的虚拟下标做一次二分即可，不需要先行后列两次二分。

Q2：一维下标怎么映射回二维坐标？对 mid ∈ [0, m×n-1]：行 = mid / n，列 = mid % n（n 是列数）。取值后按普通二分规则收缩区间。

照着写的 4 步：

① 读出 m、n，令 low = 0，high = m × n - 1；
② while (low ≤ high) 循环：取 mid = (high - low) / 2 + low；
③ 用 x = matrix[mid / n][mid % n] 取中点值：等于 target 返回 true；偏小则 low = mid + 1；偏大则 high = mid - 1；
④ 循环结束返回 false。

易错点：映射时除和取模的都是列数 n 不是行数 m；右端点初始值是 m × n - 1 不是 m × n；循环条件是 low <= high 不是 low < high。

matrix = [[ 1,  3,  5,  7],
          [10, 11, 16, 20],
          [23, 30, 34, 60]]   m=3, n=4，target = 3

虚拟拉平: [1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]
           下标 0 ─────────────────────────────── 11

第1轮: L=0, R=11，mid = 5
       行 = 5/4 = 1, 列 = 5%4 = 1 → matrix[1][1] = 11
       操作: 11 ＞ 3 → 砍右半，R = 4

第2轮: L=0, R=4，mid = 2
       行 = 2/4 = 0, 列 = 2%4 = 2 → matrix[0][2] = 5
       操作: 5 ＞ 3 → 砍右半，R = 1

第3轮: L=0, R=1，mid = 0 → matrix[0][0] = 1
       操作: 1 ＜ 3 → 砍左半，L = 1

第4轮: L=R=1，mid = 1 → matrix[0][1] = 3 = target → 返回 true

代码（Java · 力扣官方题解写法）

class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        // ① 把矩阵按行拉平成升序数组，对虚拟下标二分
        int m = matrix.length, n = matrix[0].length;
        int low = 0, high = m * n - 1;
        while (low <= high) {
            int mid = (high - low) / 2 + low;  // ② 取中点
            int x = matrix[mid / n][mid % n];   // ③ 一维下标映射回二维
            if (x < target) {
                low = mid + 1;                 // ③ 偏小砍左半
            } else if (x > target) {
                high = mid - 1;                // ③ 偏大砍右半
            } else {
                return true;                   // ③ 命中
            }
        }
        return false;                          // ④ 不存在
    }
}

时间复杂度 O(log(m×n)) · 空间复杂度 O(1)
