238. 除自身以外数组的乘积 中等

标记本题：
给定整数数组 nums，返回数组 answer，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积。不能使用除法，要求 O(n)。
示例： 输入：nums = [1,2,3,4] 输出：[24,12,8,6]

解题思路

本页代码参照力扣官方题解的写法：左右乘积列表——左积直接写进输出数组，右积用滚动变量 R 顺带乘上，空间 O(1)。

先想清楚两个问题：

Q1：不能用除法，「除自身外的乘积」怎么拆？拆成「i 左侧所有元素之积」×「i 右侧所有元素之积」，两遍扫描分别累积即可，O(n) 且不用除法。

Q2：怎么做到额外 O(1) 空间？左侧乘积直接写进输出数组 answer；右侧乘积用一个滚动变量 R 从右往左累乘，顺手乘到 answer[i] 上，不再开第二个数组。

照着写的四步：

① answer[0] = 1（0 号左侧为空，乘积为 1）；
② 从左往右：answer[i] = answer[i-1] × nums[i-1]，即 i 左侧之积；
③ 从右往左维护滚动值 R（i 右侧之积，初值 1）；
④ 每步先 answer[i] *= R，再 R *= nums[i]，把 nums[i] 并入右积供左侧位置用。

易错点：左扫时 answer[i] 用的是 nums[i-1] 不是 nums[i]，下标偏移一位；第二遍是先 answer[i] *= R 再 R *= nums[i]，顺序反了会把自己乘进去；R 初值是 1，因为最右元素右侧为空。

nums = [1, 2, 3, 4]

①② 左扫（answer[i] = i 左侧之积）:
     answer = [1, 1, 2, 6]
③④ 右扫（R = i 右侧之积，滚动）:
     i=3: answer[3] = 6 × 1  = 6    R = 1×4  = 4
     i=2: answer[2] = 2 × 4  = 8    R = 4×3  = 12
     i=1: answer[1] = 1 × 12 = 12   R = 12×2 = 24
     i=0: answer[0] = 1 × 24 = 24   R = 24×1 = 24

结果: [24, 12, 8, 6]

代码（Java · 力扣官方题解写法）

class Solution {
    public int[] productExceptSelf(int[] nums) {
        int length = nums.length;
        int[] answer = new int[length];

        // ① answer[i] 表示索引 i 左侧所有元素的乘积
        // 因为索引为 '0' 的元素左侧没有元素，所以 answer[0] = 1
        answer[0] = 1;
        for (int i = 1; i < length; i++) {
            // ② 左积：answer[i] = 左邻左积 × 左邻元素（注意取 nums[i-1]）
            answer[i] = nums[i - 1] * answer[i - 1];
        }

        // ③ R 为右侧所有元素的乘积（滚动变量）
        // 刚开始右边没有元素，所以 R = 1
        int R = 1;
        for (int i = length - 1; i >= 0; i--) {
            // ④ 对于索引 i，左边的乘积为 answer[i]，右边的乘积为 R
            answer[i] = answer[i] * R;
            // ④ 把 nums[i] 并入右积，供左侧位置用
            R *= nums[i];
        }
        return answer;
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)（输出数组不计入）
