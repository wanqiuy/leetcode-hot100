56. 合并区间 中等

标记本题：
给定区间集合 intervals，合并所有重叠的区间，返回互不重叠的区间数组。
示例： 输入：intervals = [[1,3],[2,6],[8,10],[15,18]] 输出：[[1,6],[8,10],[15,18]] 解释：[1,3] 和 [2,6] 重叠，合并为 [1,6]

解题思路

先想清楚两个问题：

Q1：为什么要先排序？按左端点排序后，所有可能重叠的区间必然相邻，每个区间只需与「结果末尾的区间」比一次，不用两两比较。

Q2：怎么判断重叠并合并？当前区间左端点 ≤ 结果末尾区间的右端点即重叠，合并只需把末尾右端点更新为两者较大值（左端点不用动，因为已按左端点有序）；否则直接追加。

照着写的三步：

① 按左端点升序排序；
② 逐个扫描：与结果末尾区间不重叠（当前左端点 > 末尾右端点）→ 直接追加；
③ 重叠 → 合并：末尾右端点 = max(末尾右端点, 当前右端点)。

易错点：合并时右端点是取 max，不是直接用当前区间的右端点（如 [1,4] 与 [2,3]，当前区间反而更短）；判不重叠的条件是 cur[0] > last[1]，相等算重叠；第一个区间要先放入结果（或判 ans 为空）。

intervals = [[1,3],[2,6],[8,10],[15,18]]
① 按左端点排序后: [1,3] [2,6] [8,10] [15,18]

扫描     结果末尾   判断                      结果集
[1,3]    空         直接加入                  [1,3]
[2,6]    [1,3]      2 ≤ 3 重叠 → 右端取 max   [1,6]
[8,10]   [1,6]      8 > 6 不重叠 → 追加       [1,6] [8,10]
[15,18]  [8,10]     15 > 10 不重叠 → 追加     [1,6] [8,10] [15,18]

结果: [[1,6],[8,10],[15,18]]

代码（Java）

class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]); // ① 按左端点排序
        List<int[]> ans = new ArrayList<>();
        for (int[] cur : intervals) {
            // ② 与结果末尾区间不重叠 → 直接追加
            if (ans.isEmpty() || cur[0] > ans.get(ans.size() - 1)[1]) {
                ans.add(cur);
            } else {
                // ③ 重叠 → 合并：末尾右端点取两者最大
                int[] last = ans.get(ans.size() - 1);
                last[1] = Math.max(last[1], cur[1]);
            }
        }
        return ans.toArray(new int[0][]);
    }
}

时间复杂度 O(n log n) · 空间复杂度 O(log n)（排序递归栈，不计输出）
