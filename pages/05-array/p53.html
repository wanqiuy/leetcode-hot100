53. 最大子数组和 中等

标记本题：
给定整数数组 nums，找一个具有最大和的连续子数组（至少包含一个元素），返回其最大和。
示例： 输入：nums = [-2,1,-3,4,-1,2,1,-5,4] 输出：6 解释：连续子数组 [4,-1,2,1] 的和最大，为 6

解题思路

先想清楚两个问题：

Q1：为什么可以一遍扫描而不必枚举所有子数组？定义 cur 为「以 i 结尾的最大子数组和」，它对前面只有一条路：要么续接前段，要么从 nums[i] 重启。若 cur + nums[i] 还不如 nums[i]，说明前段是负资产，果断抛弃。

Q2：状态怎么维护？两个变量：cur 每步更新为 max(nums[i], cur + nums[i])；ans（全局最大）每步用 cur 刷新。子数组起点不用记，因为只要最大和。

照着写的三步：

① cur 和 ans 都初始化为 nums[0]；
② 从 i = 1 起，cur = max(nums[i], cur + nums[i])，二选一：重启或续接；
③ 每步 ans = max(ans, cur)，遍历完返回 ans。

易错点：初值是 nums[0] 不是 0（全负数组会错把「一个都不选」当答案）；比较的是 cur + nums[i] 与 nums[i]，不是 cur 与 0；本题必须至少选一个元素，不能返回 0。

nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

 i   num   cur+num 与 num 比较 → cur   操作    ans
 0   -2    初值 = -2                   启动    -2
 1    1    -2+1=-1 < 1   → 1          重启    1
 2   -3    1-3=-2  ≥ -3  → -2         续接    1
 3    4    -2+4=2  < 4   → 4          重启    4
 4   -1    4-1=3   ≥ -1  → 3          续接    4
 5    2    3+2=5   ≥ 2   → 5          续接    5
 6    1    5+1=6   ≥ 1   → 6          续接    6 ← 对应子数组 [4,-1,2,1]
 7   -5    6-5=1   ≥ -5  → 1          续接    6
 8    4    1+4=5   ≥ 4   → 5          续接    6

ans = 6

代码（Java）

class Solution {
    public int maxSubArray(int[] nums) {
        int cur = nums[0], ans = nums[0]; // ① 以首元素结尾的和 + 全局最大
        for (int i = 1; i < nums.length; i++) {
            // ② 二选一：重启（只取自己）或续接（接在前段后面）
            cur = Math.max(nums[i], cur + nums[i]);
            ans = Math.max(ans, cur); // ③ 刷新全局最大
        }
        return ans;
    }
}
