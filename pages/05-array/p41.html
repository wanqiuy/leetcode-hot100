41. 缺失的第一个正数 困难

标记本题：
给定未排序的整数数组 nums，找出其中没有出现的最小的正整数，要求 O(n) 时间、O(1) 空间。
示例： 输入：nums = [3,4,-1,1] 输出：2

解题思路

本页代码参照力扣官方题解的写法：原地哈希打标记——先统一非正数，再用「取负」标记出现过的正数。

先想清楚两个问题：

Q1：不能排序、不能开哈希表，怎么 O(n) 找到缺失值？长度为 n 的数组，答案一定落在 [1, n+1]。用数组自身当下标哈希：如果正数 x 出现过，就把下标 x-1 处的值变成负数；最后第一个仍是正数的位置，就是缺失的正数。

Q2：数组里有非正数和大于 n 的数，怎么排除干扰？第一遍把它们全部改成 n+1（超出 [1,n] 的占位值），这样数组里只剩 [1, n+1] 的数，第二遍打标记时下标访问永不越界，非正干扰也被清掉。

照着写的五步：

① 第一遍：所有 ≤ 0 的数统一改成 n+1；
② 第二遍：对每个数取绝对值 num = |nums[i]|，若 num ≤ n，把下标 num-1 处的值置为负（取负前先套 abs，防重复打标打回正数）；
③ 取负表示「num 这个正数出现过」，值本身用绝对值保留，不破坏信息；
④ 第三遍扫描：第一个 nums[i] > 0 的位置，答案就是 i+1；
⑤ 若全为负，答案是 n+1。

易错点：映射下标是 num-1 不是 num，因为正数从 1 开始；置负必须是 nums[num-1] = -|nums[num-1]|（不是直接取反），否则重复值会负负得正、标记失效；取 num 时要用绝对值，因为该位置的值可能已被之前的打标变负。

nums = [3,4,-1,1]，n = 4

① 非正数统一改 n+1:     [3,4,5,1]   （-1 → 5）
② 打标记（把 |x|-1 处取负）:
   |3|≤4 → 下标 2 取负   [3,4,-5,1]
   |4|≤4 → 下标 3 取负   [3,4,-5,-1]
   |-5|=5 > 4，跳过
   |-1|=1 ≤ 4 → 下标 0 取负 [-3,4,-5,-1]
④ 扫描：i=1 处为 4 > 0，第一个正数位置
→ 缺失的第一个正数 = 2

代码（Java · 力扣官方题解写法）

class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        // ① 非正数统一改成 n+1（超出 [1,n] 的占位值）
        for (int i = 0; i < n; ++i) {
            if (nums[i] <= 0) {
                nums[i] = n + 1;
            }
        }
        // ②③ 打标记：num 出现过，就把下标 num-1 处的值取负
        for (int i = 0; i < n; ++i) {
            int num = Math.abs(nums[i]);
            if (num <= n) {
                nums[num - 1] = -Math.abs(nums[num - 1]);
            }
        }
        // ④ 第一个仍为正值的位置，缺失的正数就是 i+1
        for (int i = 0; i < n; ++i) {
            if (nums[i] > 0) {
                return i + 1;
            }
        }
        return n + 1; // ⑤ 全部出现过，缺的是 n+1
    }
}

时间复杂度 O(n) · 空间复杂度 O(1)
